# إشعار نقل البيانات الدولي

تاريخ السريان: 23 يونيو 2026  
آخر تحديث: 23 يونيو 2026

FileGuard لا يرسل الملفات المخزنة في مخزنك أو محتويات الملف أو كلمات المرور أو أسماء المخزن أو سجل النشاط إلى خادم يديره المطور.

ومع ذلك، قد تتم معالجة بعض المعلومات خارج بلدك أو منطقتك عندما Android يتم استخدام ميزات الإعلان أو الموافقة أو عند تحديد خدمة سحابية خارجية مباشرةً كوجهة احتياطية.

## 1. خدمات الإعلانات والموافقة من Google

| البند | التفاصيل |
|---|---|
| **المستلمون** | Google LLCوالشركات التابعة لشركة Google، والمعالجون الذين تستخدمهم Google للإعلان، وإدارة الموافقات، والقياس، والأمان، وتشغيل الخدمة، وموفري تكنولوجيا الإعلان الذين تم ضبطهم |
| **الاتصال والسياسات** | [سياسة خصوصية جوجل](https://policies.google.com/privacy), [معلومات عن تقنيات الإعلان في Google](https://policies.google.com/technologies/ads) |
| **البلدان** | الولايات المتحدة والدول الأخرى حيث تقوم Google أو معالجاتها بتشغيل الخوادم والبنية التحتية. قد تختلف المواقع الفعلية بناءً على توجيه الشبكة وتكوين الخدمة والمعالجات. |
| **التوقيت** | عندما Android يقوم التطبيق بتحديث معلومات الموافقة أو يعرض خيارات الخصوصية أو يطلب الإعلانات أو يعرضها أو يقيسها |
| **الطريقة** | اتصالات الإنترنت المشفرة بين التطبيق أو Google SDKs والخوادم الخارجية |
| **معلومات** | الإعلان أو مثيل التطبيق أو معرفات الجهاز؛ عنوان IP؛ الموقع التقريبي طراز الجهاز نظام التشغيل إصدار التطبيق؛ لغة؛ معلومات الشبكة؛ معلومات طلب الإعلان والظهور والنقر والتفاعل والتشخيص؛ حالة الموافقة وخيارات الخصوصية |
| **الأغراض** | تسليم الإعلانات، والإعلانات غير المخصصة، وتحديد عدد مرات الظهور، والقياس، والتحليلات، ومنع الاحتيال، وإدارة الموافقة واختيار الخصوصية، وأمن الخدمة، والامتثال للسياسات والقوانين |
| **الاحتفاظ** | بموجب سياسات الخصوصية والالتزامات التعاقدية والقوانين المعمول بها لدى Google وكل معالج |

لا يوفر المطور ملفات Vault أو محتويات الملفات أو أسماء الملفات أو كلمات مرور Vault أو كلمات مرور النسخ الاحتياطي أو سجل النشاط لخدمات Google الإعلانية.

## 2. التخزين الخارجي أو الخدمات السحابية التي تختارها

FileGuard يتم تشفير ملفات النسخ الاحتياطي بكلمة مرور وحفظها في الموقع الذي تحدده. إذا قمت بتحديد Google Drive, iCloud Drive, OneDrive, Dropboxأو خدمة مزامنة أو موفر مستندات أخرى، قد يتم نقل ملف النسخ الاحتياطي المشفر والمعلومات ذات الصلة التي يعالجها هذا الموفر - مثل اسم الملف ووقت التخزين - إلى خوادم خارج بلدك.

| البند | التفاصيل |
|---|---|
| **المستلمون** | الملف أو المستند أو موفر التخزين السحابي الذي حددته أنت ومعالجاته |
| **البلدان** | كما هو موضح في سياسة الخصوصية ومعلومات البنية التحتية الخاصة بالموفر المحدد |
| **التوقيت والطريقة** | عند تحديد الخدمة كموقع تخزين وإنشاء نسخة احتياطية أو تحديثها، من خلال النقل عبر الشبكة بواسطة نظام التشغيل أو تطبيق الموفر |
| **معلومات** | حزمة النسخ الاحتياطي المشفرة بكلمة مرور، واسم الملف الذي حددته، وأوقات التخزين والتعديل، ومعلومات الحساب أو الجهاز أو الشبكة التي تتم معالجتها تلقائيًا بواسطة الموفر |
| **الأغراض** | تخزين النسخ الاحتياطية والمزامنة والاسترداد والوصول عبر الأجهزة التي طلبتها |
| **الاحتفاظ** | حتى تقوم بحذف الملف أو للمدة المحددة من قبل الموفر المحدد |

اخترت الخدمة الخارجية مباشرة. لا يتحكم المطور في حساب الخدمة أو خوادمها أو ممارسات الاحتفاظ بها. إذا فقدت كلمة المرور الاحتياطية، فلن يتمكن المطور من استعادة النسخة الاحتياطية المشفرة.

## 3. الاختيارات والعواقب

يمكنك تقييد المعالجة الدولية عن طريق:

- تغيير الموافقة من خلال خيارات خصوصية إعلانات Google حيثما كان ذلك متاحًا
- تحديد الإعلانات غير المخصصة أو معالجة البيانات المقيدة حيثما كان ذلك متاحًا
- حذف أو إعادة تعيين معرف الإعلان أو الحد من تخصيص الإعلان في إعدادات الجهاز
- قطع الاتصال بالشبكة، أو إيقاف استخدام التطبيق، أو إلغاء تثبيته
- تحديد وجهة النسخ الاحتياطي المحلية للجهاز بدلاً من خدمة سحابية خارجية
- حذف ملفات النسخ الاحتياطي الموجودة من خدمة خارجية وتعطيل المزامنة

قد يؤدي رفض المعالجة المتعلقة بالإعلانات إلى الحد من الإعلانات المخصصة، أو يؤدي إلى إعلانات غير مخصصة أو محدودة، أو منع بعض الميزات الإعلانية. يمكنك استخدام المخزن المحلي دون اختيار التخزين السحابي، ولكن المزامنة والاسترداد عن بعد من خلال هذا الموفر لن تكون متاحة.

## 4. الضمانات

تنص Google على أنها تستخدم التشفير أثناء النقل والأطر القانونية لنقل البيانات الدولية، وقد تتم معالجة هذه المعلومات على خوادم حول العالم.

FileGuard يقوم بتشفير حزم النسخ الاحتياطي باستخدام كلمة المرور الاحتياطية قبل كتابتها إلى الموقع المحدد. لا يزال بإمكان موفر خارجي معالجة الملف المشفر نفسه واسم الملف الخاص به والحساب أو المعلومات المتعلقة بالشبكة. حدد موفرًا موثوقًا به واستخدم كلمة مرور احتياطية قوية وفريدة من نوعها.
