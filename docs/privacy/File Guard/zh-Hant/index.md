## 1. 範圍和目的

FileGuard 是一款安全工具，可让您在裝置上的加密保險庫中保存所选檔案、拍摄的媒体、笔记和剪貼簿文本，并建立加密備份檔案。

本應用程式无需注册或登录。開發者不运营接收您的保險庫檔案、檔案内容、密码、保險庫名称或活动历史紀錄的伺服器。不过，在 Android 上，本應用程式可能会使用 Google AdMob 和 Google User Messaging Platform（UMP）用于廣告和隱私選擇。

## 2. 處理的資訊

### 2.1 您選擇或建立的保險庫資料

本應用程式可能在您的裝置上處理以下資訊：

- 您通过系统檔案選擇器選擇的照片、影片、文件和其他檔案
- 使用本應用程式拍摄的照片或影片，包括随影片录制的音频
- 您手动保存的剪貼簿文本，或在啟用自動剪貼簿保護时检测到的剪貼簿文本
- 檔案名、MIME 类型、大小、建立时间、标题说明以及与预览相关的資訊
- 保險庫名称和識別碼、安全分类、原始檔案狀態以及原始檔案引用
- 您建立的加密匯出、傳輸或備份包

这些資訊在您的裝置上處理，用于提供本應用程式的功能。開發者不会将其上傳到由開發者运营的伺服器。

### 2.2 身分驗證和安全資訊

本應用程式可能在您裝置上的安全儲存中處理以下資訊：

- 用于派生或保護加密金鑰的盐值、金鑰派生設定和加密金鑰包
- 为生物辨識存取而由裝置绑定金鑰保護的保險庫存取凭据和本機金鑰
- 屏幕截图保護、剪貼簿清除、生物辨識重新认证和自動保護等安全偏好設定

您的明文密码不会发送给開發者。生物辨識身分驗證由作業系統执行。本應用程式不会蒐集指纹或面部图像，也不会蒐集生物辨識模板；它只接收身分驗證结果。

### 2.3 本機活动和備份資訊

本應用程式可能在本機儲存：

- 与保護、锁定、刪除、原始檔案刪除、備份和還原事件相关的类型、描述、时间和相关项目識別碼
- 最多 500 条活动日志紀錄
- 備份目标、上次備份时间、项目数量以及成功或失败狀態
- 是否啟用自動備份以及更新该備份所需的密码
- 廣告隱私選擇、受限資料處理選擇，以及用于廣告頻率的受保護项目数量

包括備份狀態和自動備份密码在内的敏感設定儲存在由裝置金鑰加密的本機儲存中。您有责任确保備份密码安全。

### 2.4 廣告和同意期间處理的資訊

在受支持的廣告平台（目前为 Android）上，本應用程式可能使用 Google AdMob 和 UMP。Google 以及廣告技术供應商可能處理：

- 廣告、應用程式实例或裝置相关識別碼
- IP 地址以及根据 IP 地址等資訊推断的大致位置
- 裝置型号、作業系統、應用程式版本、语言和网络資訊
- 廣告請求、曝光、點擊、互動和诊断資訊
- 同意狀態和地區隱私選擇

这些資訊可能用于廣告放送、非个性化廣告、頻率控制、評估、詐欺防范、同意管理、安全和法律合规。本應用程式的實作方式是在 UMP 指示可以請求廣告之后才初始化 Google Mobile Ads SDK。

请参阅 [Google 隱私权政策](https://policies.google.com/privacy)和 [Google 廣告技术資訊](https://policies.google.com/technologies/ads)。

## 3. 處理目的

FileGuard 處理資訊的目的包括：

- 在加密保險庫中儲存并顯示所选或拍摄的内容
- 通过锁定、密码和生物辨識身分驗證控制保險庫存取
- 匯入、匯出、移動、刪除内容并跟踪其原始檔案狀態
- 在您選擇的位置建立和還原加密備份
- 维护安全偏好設定，并清除暫時解密檔案和剪貼簿内容
- 顯示本機安全活动和错误狀態
- 放送 Android 廣告、控制廣告頻率并提供隱私選擇
- 防止滥用、保護服務并履行法律义务

## 4. 儲存和保留

| 類別 | 儲存和保留 | 如何刪除 |
|---|---|---|
| 加密保險庫檔案和元資料 | 儲存在應用程式专用本機儲存中，直到您刪除 | 在應用程式中刪除项目或保險庫、清除應用程式資料或卸载 |
| 凭据和安全設定 | 儲存在作業系統安全儲存和裝置金鑰加密儲存中，直到被更改或應用程式資料被移除 | 停用相关功能、清除應用程式資料或卸载 |
| 活动历史紀錄 | 加密本機儲存中最多 500 条紀錄 | 清除應用程式資料或卸载 |
| 暫時解密檔案 | 暫時写入應用程式快取，并在启动、进入后台或功能完成时尽力清除 | 关闭應用程式或清除其快取/資料 |
| 剪貼簿内容 | 在使用复制或自動保護时通过作業系統剪貼簿處理 | 尽力自動清除、复制其他内容或重启裝置 |
| 加密備份檔案 | 儲存在您選擇的裝置檔案夹、文件供應商或雲端同步位置，直到您刪除 | 通过相关檔案管理器或儲存服務刪除 |
| Google 廣告資料 | 根据 Google 和處理方政策以及法律义务保留 | 更改應用程式/裝置廣告設定或使用 Google 隱私控制 |

作業系統、裝置製造商、文件供應商或雲端備份供應商可能会保留應用程式資料或您建立的備份檔案的單獨副本。这些副本受相关供應商政策约束。

## 7. 權限

当您使用相关功能时，本應用程式可能使用以下權限或系统功能：

- **檔案和照片：** 仅匯入您選擇的内容
- **相機：** 为保險庫拍摄照片或影片
- **麥克風：** 录制影片时包含音频
- **生物辨識：** 确认保險庫存取或敏感設定更改
- **Android 上的互联网和网络狀態：** 請求 AdMob 廣告和 UMP 同意資訊
- **Android 上的廣告 ID：** 支持 Google 廣告功能

拒绝某项權限可能只会停用相关功能。使用系统檔案選擇器时，存取通常限于您選擇的项目。

## 8. 安全措施和限制

目前實作使用的措施包括：

- 对保險庫内容和保險庫索引使用 AES-256-GCM 加密
- 对基于密码的金鑰使用 PBKDF2-HMAC-SHA256 金鑰派生
- 在受支持的 Android 裝置上使用 Android Keystore 或 StrongBox 保護本機金鑰
- 对敏感設定和活动历史紀錄使用裝置金鑰加密
- 当應用程式进入后台时，尽力执行保險庫锁定以及暫時檔案和剪貼簿清理
- 選用的屏幕截图保護和生物辨識重新认证
- 使用密码加密的便携式備份包

没有任何安全方法能够消除所有風險。裝置被盗、惡意軟體、作業系統弱點、弱密码、您共享的檔案或外部儲存供應商的安全问题都可能导致資訊曝露。

将解密内容打开或匯出到其他應用程式可能会建立單獨副本。原始檔案刪除以及暫時檔案或剪貼簿清理可能受作業系統限制，因此您应核实敏感内容是否已移除。

- 清除應用程式資料或快取，或卸载應用程式
- 从其儲存位置刪除備份和匯出檔案
- 在可用的情况下，通过應用程式内 Google 廣告隱私选项更改同意
- 在裝置設定中刪除或重置廣告識別碼，或限制廣告个性化
