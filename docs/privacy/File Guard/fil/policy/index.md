# Paunawa sa International Data Transfer

Petsa ng bisa: Hunyo 23, 2026  
Huling na-update: Hunyo 23, 2026

FileGuard ay hindi nagpapadala ng mga file na nakaimbak sa iyong vault, mga nilalaman ng file, mga password, pangalan ng vault, o kasaysayan ng aktibidad sa isang server na pinapatakbo ng developer.

Gayunpaman, maaaring maproseso ang ilang impormasyon sa labas ng iyong bansa o rehiyon kung kailan Android ginagamit ang mga feature sa advertising o pahintulot o kapag direkta kang pumili ng serbisyo sa cloud sa ibang bansa bilang backup na destinasyon.

## 1. Google advertising at mga serbisyo ng pagpapahintulot

| item | Mga Detalye |
|---|---|
| **Mga tatanggap** | Google LLC, mga kaakibat ng Google, mga processor na ginagamit ng Google para sa advertising, pamamahala ng pahintulot, pagsukat, seguridad, at pagpapatakbo ng serbisyo, at mga naka-configure na provider ng teknolohiya sa pag-advertise |
| **Makipag-ugnayan at mga patakaran** | [Patakaran sa Privacy ng Google](https://policies.google.com/privacy), [Impormasyon sa mga teknolohiya sa advertising ng Google](https://policies.google.com/technologies/ads) |
| **Mga bansa** | Ang United States at iba pang mga bansa kung saan ang Google o ang mga processor nito ay nagpapatakbo ng mga server at imprastraktura. Maaaring mag-iba ang aktwal na lokasyon batay sa pagruruta ng network, configuration ng serbisyo, at mga processor. |
| **Timing** | Kapag ang Android ina-update ng app ang impormasyon ng pahintulot, nagpapakita ng mga opsyon sa privacy, o humihiling, nagpapakita, o sumusukat ng mga ad |
| **Pamamaraan** | Mga naka-encrypt na komunikasyon sa internet sa pagitan ng app o Google SDKs at mga panlabas na server |
| **Impormasyon** | Advertising, app-instance, o mga identifier ng device; IP address; tinatayang lokasyon; modelo ng aparato; operating system; bersyon ng app; wika; impormasyon sa network; kahilingan sa ad, impression, pag-click, pakikipag-ugnayan, at impormasyon sa diagnostic; katayuan ng pahintulot at mga pagpipilian sa privacy |
| **Mga layunin** | Paghahatid ng ad, hindi naka-personalize na mga ad, frequency capping, pagsukat, analytics, pag-iwas sa panloloko, pahintulot at pamamahala sa pagpili sa privacy, seguridad ng serbisyo, at pagsunod sa mga patakaran at batas |
| **Pagpapanatili** | Sa ilalim ng mga patakaran sa privacy, mga obligasyong kontraktwal, at mga naaangkop na batas ng Google at ng bawat processor |

Hindi nagbibigay ang developer ng mga vault na file, nilalaman ng file, pangalan ng file, password ng vault, backup na password, o history ng aktibidad sa mga serbisyo sa advertising ng Google.

## 2. Panlabas na storage o mga serbisyo sa cloud na pinili mo

FileGuard Ang mga backup na file ay naka-encrypt gamit ang isang password at nai-save sa isang lokasyong pinili mo. Kung pipiliin mo Google Drive, iCloud Drive, OneDrive, Dropbox, o isa pang serbisyo ng pag-synchronize o tagapagbigay ng dokumento, ang naka-encrypt na backup na file at kaugnay na impormasyong naproseso ng provider na iyon—gaya ng pangalan ng file at oras ng storage—ay maaaring ilipat sa mga server sa labas ng iyong bansa.

| item | Mga Detalye |
|---|---|
| **Mga tatanggap** | Ang file, dokumento, o provider ng cloud storage na pinili mo at ng mga processor nito |
| **Mga bansa** | Gaya ng inilarawan sa patakaran sa privacy at impormasyon sa imprastraktura ng napiling provider |
| **Oras at pamamaraan** | Kapag pinili mo ang serbisyo bilang lokasyon ng storage at gumawa o nag-update ng backup, sa pamamagitan ng paglipat ng network ng operating system o provider app |
| **Impormasyon** | Ang backup na package na naka-encrypt ng password, pangalan ng file na pinili mo, oras ng imbakan at pagbabago, at impormasyon ng account, device, o network na awtomatikong pinoproseso ng provider |
| **Mga layunin** | Imbakan ng backup, pag-synchronize, pagbawi, at cross-device na access na hiniling mo |
| **Pagpapanatili** | Hanggang sa tanggalin mo ang file o para sa panahong tinukoy ng napiling provider |

Direktang pipiliin mo ang panlabas na serbisyo. Hindi kinokontrol ng developer ang account, mga server, o mga kasanayan sa pagpapanatili ng serbisyo. Kung nawala mo ang backup na password, hindi mababawi ng developer ang naka-encrypt na backup.

## 3. Mga pagpipilian at kahihinatnan

Maaari mong limitahan ang internasyonal na pagproseso sa pamamagitan ng:

- Pagbabago ng pahintulot sa pamamagitan ng mga opsyon sa privacy ng ad ng Google kung saan available
- Pagpili ng mga hindi naka-personalize na ad o pinaghihigpitang pagproseso ng data kung saan available
- Pagtanggal o pag-reset ng identifier ng advertising o paglilimita sa pag-personalize ng ad sa mga setting ng device
- Pagdiskonekta mula sa network, paghinto sa paggamit ng app, o pag-uninstall nito
- Pagpili ng lokal na backup na destinasyon ng device sa halip na isang serbisyo sa cloud sa ibang bansa
- Pagtanggal ng mga umiiral nang backup na file mula sa isang panlabas na serbisyo at hindi pagpapagana ng pag-synchronize

Ang pagtanggi sa pagproseso na nauugnay sa advertising ay maaaring limitahan ang personalized na advertising, magresulta sa hindi personalized o limitadong mga ad, o maiwasan ang ilang mga tampok sa advertising. Maaari mong gamitin ang lokal na vault nang hindi pumipili ng cloud storage, ngunit hindi magiging available ang pag-synchronize at malayuang pagbawi sa pamamagitan ng provider na iyon.

## 4. Mga pananggalang

Sinasabi ng Google na gumagamit ito ng encryption sa transit at mga legal na framework para sa mga internasyonal na paglilipat ng data at ang impormasyong iyon ay maaaring maproseso sa mga server sa buong mundo.

FileGuard ine-encrypt ang mga backup na pakete gamit ang iyong backup na password bago isulat ang mga ito sa napiling lokasyon. Maaari pa ring iproseso ng isang external na provider ang mismong naka-encrypt na file, ang pangalan ng file nito, at impormasyong nauugnay sa account o network. Pumili ng pinagkakatiwalaang provider at gumamit ng malakas at natatanging backup na password.
