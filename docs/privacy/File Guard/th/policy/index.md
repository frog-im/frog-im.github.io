# ประกาศการถ่ายโอนข้อมูลระหว่างประเทศ

วันที่มีผลบังคับใช้: 23 มิถุนายน 2569  
อัปเดตล่าสุด: 23 มิถุนายน 2569

FileGuard ไม่ส่งไฟล์ที่จัดเก็บไว้ในตู้นิรภัย เนื้อหาไฟล์ รหัสผ่าน ชื่อตู้นิรภัย หรือประวัติกิจกรรมไปยังเซิร์ฟเวอร์ที่ดำเนินการโดยนักพัฒนา

ข้อมูลบางอย่างอาจถูกประมวลผลนอกประเทศหรือภูมิภาคของคุณเมื่อใด Android คุณลักษณะการโฆษณาหรือการยินยอมจะถูกใช้ หรือเมื่อคุณเลือกบริการคลาวด์ในต่างประเทศโดยตรงเป็นปลายทางการสำรองข้อมูล

## 1. บริการโฆษณาและการยินยอมของ Google

| รายการ | รายละเอียด |
|---|---|
| **ผู้รับ** | Google LLC, บริษัทในเครือของ Google, ผู้ประมวลผลที่ Google ใช้สำหรับการโฆษณา, การจัดการความยินยอม, การวัดผล, ความปลอดภัย และการดำเนินการบริการ และผู้ให้บริการเทคโนโลยีการโฆษณาที่กำหนดค่า |
| **ติดต่อและนโยบาย** | [นโยบายความเป็นส่วนตัวของ Google](https://policies.google.com/privacy), [ข้อมูลเทคโนโลยีการโฆษณาของ Google](https://policies.google.com/technologies/ads) |
| **ประเทศต่างๆ** | สหรัฐอเมริกาและประเทศอื่นๆ ที่ Google หรือผู้ประมวลผลดำเนินการเซิร์ฟเวอร์และโครงสร้างพื้นฐาน ตำแหน่งจริงอาจแตกต่างกันไปตามเส้นทางเครือข่าย การกำหนดค่าบริการ และโปรเซสเซอร์ |

| **ข้อมูล** | การโฆษณา อินสแตนซ์ของแอป หรือตัวระบุอุปกรณ์ ที่อยู่ IP; ตำแหน่งโดยประมาณ รุ่นอุปกรณ์ ระบบปฏิบัติการ เวอร์ชันแอป ภาษา; ข้อมูลเครือข่าย คำขอโฆษณา การแสดงผล การคลิก การโต้ตอบ และข้อมูลการวินิจฉัย สถานะความยินยอมและตัวเลือกความเป็นส่วนตัว |
| **วัตถุประสงค์** | การแสดงโฆษณา โฆษณาที่ไม่ได้ปรับตามโปรไฟล์ของผู้ใช้ การกำหนดความถี่สูงสุด การวัดผล การวิเคราะห์ การป้องกันการฉ้อโกง การจัดการความยินยอมและตัวเลือกความเป็นส่วนตัว ความปลอดภัยของบริการ และการปฏิบัติตามนโยบายและกฎหมาย |

นักพัฒนาซอฟต์แวร์ไม่ได้จัดเตรียมไฟล์ห้องนิรภัย เนื้อหาไฟล์ ชื่อไฟล์ รหัสผ่านห้องนิรภัย รหัสผ่านสำรอง หรือประวัติกิจกรรมให้กับบริการโฆษณาของ Google

## 2. ที่จัดเก็บข้อมูลภายนอกหรือบริการคลาวด์ที่คุณเลือก

FileGuard ไฟล์สำรองจะถูกเข้ารหัสด้วยรหัสผ่านและบันทึกลงในตำแหน่งที่คุณเลือก หากคุณเลือก Google Drive, iCloud Drive, OneDrive, Dropboxหรือบริการซิงโครไนซ์หรือผู้ให้บริการเอกสารอื่น ไฟล์สำรองข้อมูลที่เข้ารหัสและข้อมูลที่เกี่ยวข้องซึ่งประมวลผลโดยผู้ให้บริการรายนั้น เช่น ชื่อไฟล์และเวลาที่จัดเก็บ อาจถูกถ่ายโอนไปยังเซิร์ฟเวอร์นอกประเทศของคุณ

| รายการ | รายละเอียด |
|---|---|
| **ผู้รับ** | ผู้ให้บริการไฟล์ เอกสาร หรือที่เก็บข้อมูลบนคลาวด์ที่คุณเลือกและผู้ประมวลผล |
| **ประเทศต่างๆ** | ตามที่อธิบายไว้ในนโยบายความเป็นส่วนตัวและข้อมูลโครงสร้างพื้นฐานของผู้ให้บริการที่เลือก |
| **เวลาและวิธีการ** | เมื่อคุณเลือกบริการเป็นสถานที่จัดเก็บข้อมูลและสร้างหรืออัปเดตข้อมูลสำรองผ่านการถ่ายโอนเครือข่ายโดยระบบปฏิบัติการหรือแอปของผู้ให้บริการ |
| **ข้อมูล** | แพ็คเกจสำรองข้อมูลที่เข้ารหัสด้วยรหัสผ่าน ชื่อไฟล์ที่คุณเลือก เวลาจัดเก็บและแก้ไข และข้อมูลบัญชี อุปกรณ์ หรือเครือข่ายที่ผู้ให้บริการประมวลผลโดยอัตโนมัติ |
| **วัตถุประสงค์** | พื้นที่เก็บข้อมูลสำรอง การซิงโครไนซ์ การกู้คืน และการเข้าถึงข้ามอุปกรณ์ที่คุณร้องขอ |
| **การเก็บรักษา** | จนกว่าคุณจะลบไฟล์หรือตามระยะเวลาที่ผู้ให้บริการเลือก |

คุณเลือกบริการภายนอกโดยตรง นักพัฒนาไม่ได้ควบคุมบัญชี เซิร์ฟเวอร์ หรือหลักปฏิบัติในการเก็บรักษาของบริการ หากคุณทำรหัสผ่านสำรองหาย นักพัฒนาจะไม่สามารถกู้คืนข้อมูลสำรองที่เข้ารหัสได้

## 3. ทางเลือกและผลที่ตามมา

คุณสามารถจำกัดการประมวลผลระหว่างประเทศได้โดย:

- การเปลี่ยนแปลงความยินยอมผ่านตัวเลือกความเป็นส่วนตัวของโฆษณาของ Google หากมี
- การเลือกโฆษณาที่ไม่ได้ปรับตามโปรไฟล์ของผู้ใช้หรือการประมวลผลข้อมูลแบบจำกัด หากมี
- การลบหรือรีเซ็ตตัวระบุโฆษณาหรือการจำกัดการปรับเปลี่ยนโฆษณาส่วนบุคคลในการตั้งค่าอุปกรณ์
- การตัดการเชื่อมต่อจากเครือข่าย หยุดการใช้งานแอป หรือถอนการติดตั้ง
- การเลือกปลายทางการสำรองข้อมูลในอุปกรณ์แทนบริการคลาวด์ในต่างประเทศ
- การลบไฟล์สำรองข้อมูลที่มีอยู่ออกจากบริการภายนอกและปิดใช้งานการซิงโครไนซ์

การปฏิเสธการประมวลผลที่เกี่ยวข้องกับการโฆษณาอาจจำกัดการโฆษณาที่ปรับตามโปรไฟล์ของผู้ใช้ ส่งผลให้มีโฆษณาที่ไม่ได้ปรับตามโปรไฟล์ของผู้ใช้หรือถูกจำกัด หรือทำให้ฟีเจอร์การโฆษณาบางอย่างขัดขวาง คุณสามารถใช้ vault ภายในเครื่องได้โดยไม่ต้องเลือกที่เก็บข้อมูลบนคลาวด์ แต่การซิงโครไนซ์และการกู้คืนระยะไกลผ่านผู้ให้บริการนั้นจะไม่สามารถใช้งานได้
