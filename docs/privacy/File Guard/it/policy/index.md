# Avviso sul trasferimento internazionale dei dati

Data di entrata in vigore: 23 giugno 2026  
Ultimo aggiornamento: 23 giugno 2026

FileGuard non invia file archiviati nel tuo deposito, contenuto di file, password, nomi di deposito o cronologia delle attività a un server gestito dallo sviluppatore.

Alcune informazioni potrebbero tuttavia essere elaborate al di fuori del tuo Paese o regione quando Android vengono utilizzate funzionalità pubblicitarie o di consenso o quando si seleziona direttamente un servizio cloud estero come destinazione di backup.

## 1. Servizi di pubblicità e consenso di Google

| Articolo | Dettagli |
|---|---|
| **Destinatari** | Google LLC, affiliati di Google, responsabili del trattamento utilizzati da Google per la pubblicità, la gestione del consenso, la misurazione, la sicurezza e il funzionamento dei servizi e fornitori di tecnologia pubblicitaria configurati |
| **Contatti e politiche** | [Informativa sulla privacy di Google](https://policies.google.com/privacy), [Informazioni sulle tecnologie pubblicitarie di Google](https://policies.google.com/technologies/ads) |
| **Paesi** | Gli Stati Uniti e altri paesi in cui Google o i suoi responsabili del trattamento gestiscono server e infrastrutture. Le posizioni effettive possono variare in base al routing della rete, alla configurazione del servizio e ai processori. |
| **Tempistica** | Quando il Android l'app aggiorna le informazioni sul consenso, visualizza le opzioni sulla privacy o richiede, visualizza o misura annunci pubblicitari |
| **Metodo** | Comunicazioni Internet crittografate tra l'app o Google SDKs e server esterni |
| **Informazioni** | Pubblicità, istanze dell'app o identificatori di dispositivo; indirizzo IP; posizione approssimativa; modello del dispositivo; sistema operativo; versione dell'app; lingua; informazioni di rete; richiesta di annuncio, impressione, clic, interazione e informazioni diagnostiche; stato del consenso e scelte sulla privacy |
| **Scopi** | Pubblicazione di annunci, annunci non personalizzati, limiti di frequenza, misurazione, analisi, prevenzione delle frodi, gestione del consenso e delle scelte sulla privacy, sicurezza del servizio e conformità con politiche e leggi |
| **Conservazione** | Ai sensi delle norme sulla privacy, degli obblighi contrattuali e delle leggi applicabili di Google e di ciascun responsabile del trattamento |

Lo sviluppatore non fornisce file del vault, contenuti dei file, nomi di file, password del vault, password di backup o cronologia delle attività ai servizi pubblicitari di Google.

## 2. Archiviazione esterna o servizi cloud selezionati da te

FileGuard i file di backup vengono crittografati con una password e salvati in una posizione selezionata da te. Se selezioni Google Drive, iCloud Drive, OneDrive, Dropboxo un altro servizio di sincronizzazione o fornitore di documenti, il file di backup crittografato e le informazioni correlate elaborate da tale fornitore, come il nome del file e il tempo di archiviazione, potrebbero essere trasferiti a server al di fuori del tuo Paese.

| Articolo | Dettagli |
|---|---|
| **Destinatari** | Il fornitore di file, documenti o archiviazione cloud selezionato da te e dai suoi processori |
| **Paesi** | Come descritto nella politica sulla privacy e nelle informazioni sull'infrastruttura del fornitore selezionato |
| **Tempi e metodo** | Quando selezioni il servizio come posizione di archiviazione e crei o aggiorni un backup, tramite trasferimento di rete da parte del sistema operativo o dell'app del provider |
| **Informazioni** | Il pacchetto di backup crittografato con password, il nome del file selezionato dall'utente, i tempi di archiviazione e modifica e le informazioni sull'account, sul dispositivo o sulla rete elaborati automaticamente dal provider |
| **Scopi** | Archiviazione di backup, sincronizzazione, ripristino e accesso tra dispositivi richiesti dall'utente |
| **Conservazione** | Fino all'eliminazione del file o per il periodo specificato dal fornitore selezionato |

Scegli direttamente il servizio esterno. Lo sviluppatore non controlla l'account, i server o le pratiche di conservazione del servizio. Se perdi la password di backup, lo sviluppatore non potrà ripristinare il backup crittografato.

## 3. Scelte e conseguenze

È possibile limitare l'elaborazione internazionale tramite:

- Modifica del consenso tramite le opzioni sulla privacy degli annunci di Google, ove disponibili
- Selezione di annunci non personalizzati o trattamento dati limitato ove disponibile
- Eliminazione o reimpostazione dell'identificatore pubblicitario o limitazione della personalizzazione degli annunci nelle impostazioni del dispositivo
- Disconnessione dalla rete, interruzione dell'uso dell'app o disinstallazione della stessa
- Selezione di una destinazione di backup locale del dispositivo anziché di un servizio cloud estero
- Eliminazione dei file di backup esistenti da un servizio esterno e disabilitazione della sincronizzazione

Il rifiuto del trattamento relativo alla pubblicità può limitare la pubblicità personalizzata, comportare annunci non personalizzati o limitati o impedire alcune funzionalità pubblicitarie. È possibile utilizzare il deposito locale senza scegliere l'archiviazione nel cloud, ma la sincronizzazione e il ripristino remoto tramite quel provider non saranno disponibili.

## 4. Garanzie

Google afferma di utilizzare la crittografia in transito e quadri legali per i trasferimenti internazionali di dati e che le informazioni potrebbero essere elaborate su server in tutto il mondo.

FileGuard crittografa i pacchetti di backup con la password di backup prima di scriverli nella posizione selezionata. Un provider esterno potrebbe comunque elaborare il file crittografato stesso, il suo nome file e le informazioni relative all'account o alla rete. Seleziona un fornitore affidabile e utilizza una password di backup complessa e univoca.
