## 1. 范围和目的

FileGuard 是一款安全工具，可让您在设备上的加密保险库中保存所选文件、拍摄的媒体、笔记和剪贴板文本，并创建加密备份文件。

本应用无需注册或登录。开发者不运营接收您的保险库文件、文件内容、密码、保险库名称或活动历史记录的服务器。不过，在 Android 上，本应用可能会使用 Google AdMob 和 Google User Messaging Platform（UMP）用于广告和隐私选择。

## 2. 处理的信息

### 2.1 您选择或创建的保险库数据

本应用可能在您的设备上处理以下信息：

- 您通过系统文件选择器选择的照片、视频、文档和其他文件
- 使用本应用拍摄的照片或视频，包括随视频录制的音频
- 您手动保存的剪贴板文本，或在启用自动剪贴板保护时检测到的剪贴板文本
- 文件名、MIME 类型、大小、创建时间、标题说明以及与预览相关的信息
- 保险库名称和标识符、安全分类、原始文件状态以及原始文件引用
- 您创建的加密导出、传输或备份包

这些信息在您的设备上处理，用于提供本应用的功能。开发者不会将其上传到由开发者运营的服务器。

### 2.2 身份验证和安全信息

本应用可能在您设备上的安全存储中处理以下信息：

- 用于派生或保护加密密钥的盐值、密钥派生设置和加密密钥包
- 为生物识别访问而由设备绑定密钥保护的保险库访问凭据和本地密钥
- 屏幕截图保护、剪贴板清除、生物识别重新认证和自动保护等安全偏好设置

您的明文密码不会发送给开发者。生物识别身份验证由操作系统执行。本应用不会收集指纹或面部图像，也不会收集生物识别模板；它只接收身份验证结果。

### 2.3 本地活动和备份信息

本应用可能在本地存储：

- 与保护、锁定、删除、原始文件删除、备份和恢复事件相关的类型、描述、时间和相关项目标识符
- 最多 500 条活动日志记录
- 备份目标、上次备份时间、项目数量以及成功或失败状态
- 是否启用自动备份以及更新该备份所需的密码
- 广告隐私选择、受限数据处理选择，以及用于广告频次的受保护项目数量

包括备份状态和自动备份密码在内的敏感设置存储在由设备密钥加密的本地存储中。您有责任确保备份密码安全。

### 2.4 广告和同意期间处理的信息

在受支持的广告平台（目前为 Android）上，本应用可能使用 Google AdMob 和 UMP。Google 以及广告技术提供商可能处理：

- 广告、应用实例或设备相关标识符
- IP 地址以及根据 IP 地址等信息推断的大致位置
- 设备型号、操作系统、应用版本、语言和网络信息
- 广告请求、展示、点击、互动和诊断信息
- 同意状态和地区隐私选择

这些信息可能用于广告投放、非个性化广告、频次控制、衡量、欺诈防范、同意管理、安全和法律合规。本应用的实现方式是在 UMP 指示可以请求广告之后才初始化 Google Mobile Ads SDK。

请参阅 [Google 隐私权政策](https://policies.google.com/privacy)和 [Google 广告技术信息](https://policies.google.com/technologies/ads)。

## 3. 处理目的

FileGuard 处理信息的目的包括：

- 在加密保险库中存储并显示所选或拍摄的内容
- 通过锁定、密码和生物识别身份验证控制保险库访问
- 导入、导出、移动、删除内容并跟踪其原始文件状态
- 在您选择的位置创建和恢复加密备份
- 维护安全偏好设置，并清除临时解密文件和剪贴板内容
- 显示本地安全活动和错误状态
- 投放 Android 广告、控制广告频次并提供隐私选择
- 防止滥用、保护服务并履行法律义务

## 4. 存储和保留

| 类别 | 存储和保留 | 如何删除 |
|---|---|---|
| 加密保险库文件和元数据 | 存储在应用专用本地存储中，直到您删除 | 在应用中删除项目或保险库、清除应用数据或卸载 |
| 凭据和安全设置 | 存储在操作系统安全存储和设备密钥加密存储中，直到被更改或应用数据被移除 | 停用相关功能、清除应用数据或卸载 |
| 活动历史记录 | 加密本地存储中最多 500 条记录 | 清除应用数据或卸载 |
| 临时解密文件 | 临时写入应用缓存，并在启动、进入后台或功能完成时尽力清除 | 关闭应用或清除其缓存/数据 |
| 剪贴板内容 | 在使用复制或自动保护时通过操作系统剪贴板处理 | 尽力自动清除、复制其他内容或重启设备 |
| 加密备份文件 | 存储在您选择的设备文件夹、文档提供商或云同步位置，直到您删除 | 通过相关文件管理器或存储服务删除 |
| Google 广告数据 | 根据 Google 和处理方政策以及法律义务保留 | 更改应用/设备广告设置或使用 Google 隐私控制 |

操作系统、设备制造商、文档提供商或云备份提供商可能会保留应用数据或您创建的备份文件的单独副本。这些副本受相关提供商政策约束。

## 5. 第三方、服务提供商和出售

开发者不会出售保险库内容、密码或应用内活动历史记录，也不会通过开发者运营的服务器向第三方提供这些信息。

当 Android 广告或同意功能运行时，Google LLC、Google 关联公司、广告技术提供商以及相关处理方可能会处理第 2.4 节所述信息。请参阅单独的[国际数据传输通知](policy/)。

如果您通过文件选择器、共享功能或备份目标直接选择外部应用或云服务，该提供商可能会根据您的指示处理文件。其隐私政策和安全设置适用，开发者不控制该提供商的做法。

## 6. 国际数据传输

保险库内容不会传输到由开发者运营的服务器。广告和同意信息可能由 Google 及相关处理方在美国以及其运营基础设施的其他国家处理。

如果您选择海外云服务作为加密备份的位置，该文件可能会根据您的指示同步到您所在国家以外的服务器。详情请参阅[国际数据传输通知](policy/)。

## 7. 权限

当您使用相关功能时，本应用可能使用以下权限或系统功能：

- **文件和照片：** 仅导入您选择的内容
- **相机：** 为保险库拍摄照片或视频
- **麦克风：** 录制视频时包含音频
- **生物识别：** 确认保险库访问或敏感设置更改
- **Android 上的互联网和网络状态：** 请求 AdMob 广告和 UMP 同意信息
- **Android 上的广告 ID：** 支持 Google 广告功能
- **剪贴板：** 在您明确启用自动保护时复制内容或保护剪贴板文本

拒绝某项权限可能只会停用相关功能。使用系统文件选择器时，访问通常限于您选择的项目。

## 8. 安全措施和限制

当前实现使用的措施包括：

- 对保险库内容和保险库索引使用 AES-256-GCM 加密
- 对基于密码的密钥使用 PBKDF2-HMAC-SHA256 密钥派生
- 在受支持的 Android 设备上使用 Android Keystore 或 StrongBox 保护本地密钥
- 对敏感设置和活动历史记录使用设备密钥加密
- 当应用进入后台时，尽力执行保险库锁定以及临时文件和剪贴板清理
- 可选的屏幕截图保护和生物识别重新认证
- 使用密码加密的便携式备份包

没有任何安全方法能够消除所有风险。设备被盗、恶意软件、操作系统漏洞、弱密码、您共享的文件或外部存储提供商的安全问题都可能导致信息暴露。

将解密内容打开或导出到其他应用可能会创建单独副本。原始文件删除以及临时文件或剪贴板清理可能受操作系统限制，因此您应核实敏感内容是否已移除。

## 9. 您的权利和选择

大多数信息仅保留在您的设备上，因此开发者无法远程访问、纠正或删除这些信息。您可以：

- 在应用中删除保险库项目或保险库
- 更改安全、生物识别、自动保护、剪贴板和自动备份设置
- 清除应用数据或缓存，或卸载应用
- 从其存储位置删除备份和导出文件
- 在可用的情况下，通过应用内 Google 广告隐私选项更改同意
- 在设备设置中删除或重置广告标识符，或限制广告个性化

您可以就您直接提供给开发者的信息（例如咨询电子邮件）与我们联系。在适用情况下，当地法律可能赋予您访问、更正、删除、限制处理、撤回同意以及向监管机构投诉的权利。
