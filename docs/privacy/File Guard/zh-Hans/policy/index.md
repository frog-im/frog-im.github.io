# 国际数据传输通知

生效日期：2026 年 6 月 23 日  
最后更新时间：2026 年 6 月 23 日

FileGuard 不会将存储在您的保管库中的文件、文件内容、密码、保管库名称或活动历史记录发送到开发人员操作的服务器。

尽管如此，某些信息可能会在您所在国家或地区之外进行处理： Android 使用广告或同意功能，或者当您直接选择海外云服务作为备份目的地时。

## 1. Google 广告和同意服务

| 项目 | 详情 |
|---|---|
| **收件人** | Google LLC、Google 附属公司、Google 用于广告、同意管理、测量、安全和服务运营的处理器以及配置的广告技术提供商 |
| **联系方式和政策** | [谷歌隐私政策](https://policies.google.com/privacy), [Google 广告技术信息](https://policies.google.com/technologies/ads) |
| **国家** | 美国以及 Google 或其处理器运营服务器和基础设施的其他国家/地区。实际位置可能因网络路由、服务配置和处理器而异。 |
| **时机** | 当 Android 应用程序更新同意信息，显示隐私选项，或请求、显示或测量广告 |
| **方法** | 应用程序之间的加密互联网通信或 Google SDKs 和外部服务器 |
| **信息** | 广告、应用实例或设备标识符； IP地址；大概位置；设备型号；操作系统;应用程序版本；语言;网络信息；广告请求、展示、点击、互动和诊断信息；同意状态和隐私选择 |
| **目的** | 广告投放、非个性化广告、频率上限、测量、分析、欺诈预防、同意和隐私选择管理、服务安全以及政策和法律合规性 |
| **保留率** | 根据 Google 和每个处理者的隐私政策、合同义务和适用法律 |

开发者不会向 Google 广告服务提供保管库文件、文件内容、文件名、保管库密码、备份密码或活动历史记录。

## 2. 您选择的外部存储或云服务

FileGuard 备份文件使用密码加密并保存到您选择的位置。如果您选择 Google Drive, iCloud Drive, OneDrive, Dropbox或其他同步或文档提供商服务，该提供商处理的加密备份文件和相关信息（例如文件名和存储时间）可能会传输到您所在国家/地区之外的服务器。

| 项目 | 详情 |
|---|---|
| **收件人** | 您及其处理者选择的文件、文档或云存储提供商 |
| **国家** | 如所选提供商的隐私政策和基础设施信息中所述 |
| **时间和方法** | 当您选择服务作为存储位置并创建或更新备份时，通过操作系统或提供商应用程序的网络传输 |
| **信息** | 密码加密的备份包、您选择的文件名、存储和修改时间以及提供商自动处理的帐户、设备或网络信息 |
| **目的** | 您请求的备份存储、同步、恢复和跨设备访问 |
| **保留率** | 直到您删除文件或在所选提供商指定的期限内 |

您直接选择外部服务。开发人员不控制服务的帐户、服务器或保留实践。如果您丢失备份密码，开发人员将无法恢复加密备份。

## 3. 选择和后果

您可以通过以下方式限制国际处理：

- 通过 Google 的广告隐私选项（如果有）更改同意
- 选择非个性化广告或限制数据处理（如果适用）
- 删除或重置广告标识符或限制设备设置中的广告个性化
- 断开网络连接、停止使用应用程序或卸载应用程序
- 选择设备本地备份目的地而不是海外云服务
- 从外部服务删除现有备份文件并禁用同步

拒绝与广告相关的处理可能会限制个性化广告，导致非个性化或有限的广告，或者阻止某些广告功能。您可以使用本地保管库而不选择云存储，但无法通过该提供商进行同步和远程恢复。

## 4. 保障措施

谷歌表示，它使用传输加密和国际数据传输的法律框架，并且信息可能在世界各地的服务器上进行处理。

FileGuard 在将备份包写入所选位置之前，使用您的备份密码对其进行加密。外部提供商仍可以处理加密文件本身、其文件名以及帐户或网络相关信息。选择值得信赖的提供商并使用强大且唯一的备份密码。
