# 国際データ転送に関する通知

発効日：2026年6月23日  
最終更新日: 2026 年 6 月 23 日

FileGuard ボールトに保存されているファイル、ファイルの内容、パスワード、ボールト名、またはアクティビティ履歴を開発者が運営するサーバーに送信しません。

ただし、一部の情報は、お住まいの国または地域外で処理される場合があります。 Android 広告機能や同意機能を使用する場合、または海外のクラウドサービスをバックアップ先として直接選択する場合。

## 1. Googleの広告および同意サービス

| アイテム | 詳細 |
|---|---|
| **受信者** | Google LLC、Google の関連会社、広告、同意管理、測定、セキュリティ、サービス運用のために Google が使用する処理業者、および設定された広告技術プロバイダー |
| **連絡先とポリシー** | [Google プライバシー ポリシー](https://policies.google.com/privacy)、 [Googleの広告技術情報](https://policies.google.com/technologies/ads) |
| **国** | Google またはそのプロセッサーがサーバーとインフラストラクチャを運用している米国およびその他の国。実際の場所は、ネットワーク ルーティング、サービス構成、プロセッサによって異なる場合があります。 |
| **タイミング** | とき Android アプリが同意情報を更新したり、プライバシー オプションを表示したり、広告をリクエスト、表示、測定したりする |
| **方法** | アプリ間の暗号化されたインターネット通信または Google SDKs および外部サーバー |
| **情報** | 広告、アプリインスタンス、またはデバイスの識別子。 IPアドレス。おおよその位置。デバイスモデル。オペレーティング·システム;アプリのバージョン。言語;ネットワーク情報。広告リクエスト、インプレッション、クリック、インタラクション、診断情報。同意ステータスとプライバシーの選択 |
| **目的** | 広告配信、パーソナライズされていない広告、フリークエンシー キャップ、測定、分析、不正防止、同意とプライバシーの選択の管理、サービスのセキュリティ、ポリシーと法律の遵守 |
| **保持** | Google および各処理者のプライバシー ポリシー、契約上の義務、適用法に基づく |

開発者は、Vault ファイル、ファイルの内容、ファイル名、Vault パスワード、バックアップ パスワード、またはアクティビティ履歴を Google 広告サービスに提供しません。

## 2. お客様が選択した外部ストレージまたはクラウド サービス

FileGuard バックアップ ファイルはパスワードで暗号化され、選択した場所に保存されます。選択した場合 Google Drive、 iCloud Drive、 OneDrive、 Dropbox、または別の同期サービスまたはドキュメント プロバイダー サービスを利用すると、暗号化されたバックアップ ファイルおよびそのプロバイダーによって処理された関連情報 (ファイル名や保存時間など) が国外のサーバーに転送される可能性があります。

| アイテム | 詳細 |
|---|---|
| **受信者** | あなたとその処理者が選択したファイル、ドキュメント、またはクラウド ストレージ プロバイダー |
| **国** | 選択したプロバイダーのプライバシー ポリシーとインフラストラクチャ情報に記載されているとおり |
| **タイミングと方法** | ストレージの場所としてサービスを選択し、オペレーティング システムまたはプロバイダー アプリによるネットワーク転送を通じてバックアップを作成または更新するとき |
| **情報** | パスワードで暗号化されたバックアップ パッケージ、ユーザーが選択したファイル名、保存時間と変更時間、プロバイダーによって自動的に処理されたアカウント、デバイス、またはネットワーク情報 |
| **目的** | お客様がリクエストしたバックアップストレージ、同期、リカバリ、クロスデバイスアクセス |
| **保持** | ファイルを削除するまで、または選択したプロバイダーが指定した期間 |

外部サービスを直接選択します。開発者は、サービスのアカウント、サーバー、保持方法を制御しません。バックアップ パスワードを紛失した場合、開発者は暗号化されたバックアップを回復できません。

## 3. 選択と結果

次の方法で国際処理を制限できます。

- 利用可能な場合は、Google の広告プライバシー オプションを介して同意を変更する
- パーソナライズされていない広告を選択するか、可能な場合はデータ処理が制限されます
- 広告識別子の削除またはリセット、またはデバイス設定での広告のパーソナライゼーションの制限
- ネットワークからの切断、アプリの使用停止、アンインストール
- 海外のクラウドサービスではなくデバイスローカルのバックアップ先を選択する
- 外部サービスから既存のバックアップ ファイルを削除し、同期を無効にする

広告関連の処理を拒否すると、パーソナライズされた広告が制限されたり、パーソナライズされなかった広告や制限された広告が表示されたり、一部の広告機能が使用できなくなったりする場合があります。クラウド ストレージを選択せず​​にローカル コンテナーを使用することはできますが、そのプロバイダーを介した同期とリモート回復は利用できません。

## 4. 安全対策

Googleは、国際データ転送には転送中の暗号化と法的枠組みを使用しており、情報は世界中のサーバーで処理される可能性があると述べています。

FileGuard バックアップ パッケージを選択した場所に書き込む前に、バックアップ パスワードを使用してバックアップ パッケージを暗号化します。外部プロバイダーは、暗号化されたファイル自体、そのファイル名、アカウントまたはネットワーク関連の情報を処理する場合があります。信頼できるプロバイダーを選択し、強力で固有のバックアップ パスワードを使用してください。
