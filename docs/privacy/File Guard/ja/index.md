## 1. 適用範囲および目的

FileGuardは、選択したファイル、撮影したメディア、メモ、クリップボードのテキストを端末上の暗号化された保管庫に保存し、暗号化されたバックアップファイルを作成できるセキュリティユーティリティです。

本アプリは登録またはサインインを必要としません。開発者は、お客様の保管庫ファイル、ファイル内容、パスワード、保管庫名、またはアクティビティ履歴を受信するサーバーを運用していません。ただしAndroidでは、広告およびプライバシー選択のためにGoogle AdMobおよびGoogle User Messaging Platform（UMP）を使用する場合があります。

## 2. 処理される情報

### 2.1 お客様が選択または作成した保管庫データ

本アプリは、お客様の端末上で以下の情報を処理する場合があります。

- システムのファイルピッカーを通じて選択した写真、動画、文書、その他のファイル
- 本アプリで撮影した写真または動画（動画とともに録音された音声を含む）
- 手動で保存したクリップボードのテキスト、または自動クリップボード保護を有効にしたときに検出されるテキスト
- ファイル名、MIMEタイプ、サイズ、作成日時、キャプション、プレビュー関連情報
- 保管庫名および識別子、セキュリティ分類、元ファイルの状態、元ファイルへの参照
- お客様が作成する暗号化されたエクスポート、転送、またはバックアップパッケージ

これらの情報は、本アプリの機能を提供するためにお客様の端末上で処理されます。開発者は、これらを開発者が運用するサーバーへアップロードしません。

### 2.2 認証およびセキュリティ情報

本アプリは、お客様の端末上の安全なストレージで以下の情報を処理する場合があります。

- 暗号鍵を導出または保護するために使用されるソルト、鍵導出設定、暗号化された鍵バンドル
- 生体認証アクセスのために端末に紐づく鍵で保護された保管庫アクセス認証情報およびローカル鍵
- スクリーンショット保護、クリップボード消去、生体再認証、自動保護などのセキュリティ設定

お客様の平文パスワードは開発者に送信されません。生体認証はオペレーティングシステムによって実行されます。本アプリは指紋画像、顔画像、または生体認証テンプレートを収集せず、認証結果のみを受け取ります。

### 2.3 ローカルのアクティビティおよびバックアップ情報

本アプリは、以下をローカルに保存する場合があります。

- 保護、ロック、削除、元ファイル削除、バックアップ、復元イベントの種類、説明、時刻、および関連アイテム識別子
- 最大500件のアクティビティログ項目
- バックアップ先、最終バックアップ時刻、アイテム数、成功または失敗の状態
- 自動バックアップが有効かどうか、およびそのバックアップを更新するために必要なパスワード
- 広告のプライバシー選択、制限付きデータ処理の選択、および広告頻度に使用される保護済みアイテム数

バックアップ状態および自動バックアップ用パスワードを含む機微な設定は、端末鍵で暗号化されたローカルストアに保存されます。バックアップパスワードを安全に管理する責任はお客様にあります。

### 2.4 広告および同意において処理される情報

現在Androidである対応広告プラットフォームでは、本アプリがGoogle AdMobおよびUMPを使用する場合があります。Googleおよび広告技術プロバイダーは、以下を処理する場合があります。

- 広告、アプリインスタンス、または端末関連の識別子
- IPアドレス、およびIPアドレスなどの情報から推定されるおおよその位置情報
- 端末モデル、オペレーティングシステム、アプリバージョン、言語、ネットワーク情報
- 広告リクエスト、インプレッション、クリック、インタラクション、診断情報
- 同意状態および地域別のプライバシー選択

これらの情報は、広告配信、非パーソナライズド広告、頻度制限、測定、不正防止、同意管理、セキュリティ、および法令遵守のために使用される場合があります。本アプリは、UMPが広告をリクエスト可能であることを示した後にのみGoogle Mobile Ads SDKを初期化するよう実装されています。

[Googleプライバシーポリシー](https://policies.google.com/privacy)および[Googleの広告技術に関する情報](https://policies.google.com/technologies/ads)をご覧ください。

## 3. 処理の目的

FileGuardは、以下の目的で情報を処理します。

- 選択または撮影したコンテンツを暗号化された保管庫に保存し表示するため
- ロック、パスワード、生体認証により保管庫アクセスを制御するため
- コンテンツのインポート、エクスポート、移動、削除、および元ファイル状態の追跡を行うため
- お客様が選択した場所に暗号化バックアップを作成および復元するため
- セキュリティ設定を維持し、一時的に復号されたファイルおよびクリップボード内容を消去するため
- ローカルのセキュリティアクティビティおよびエラー状態を表示するため
- Android広告を配信し、広告頻度を制御し、プライバシー選択を提供するため
- 不正利用を防止し、サービスを保護し、法的義務を遵守するため

## 4. 保存および保持

| カテゴリ | 保存および保持 | 削除方法 |
|---|---|---|
| 暗号化された保管庫ファイルおよびメタデータ | お客様が削除するまで、アプリ専用のローカルストレージに保存されます | アプリ内でアイテムまたは保管庫を削除する、アプリデータを消去する、またはアンインストールする |
| 認証情報およびセキュリティ設定 | 変更されるかアプリデータが削除されるまで、OSの安全なストレージおよび端末鍵で暗号化されたストレージに保存されます | 関連機能を無効にする、アプリデータを消去する、またはアンインストールする |
| アクティビティ履歴 | 暗号化されたローカルストレージに最大500件保存されます | アプリデータを消去する、またはアンインストールする |
| 一時的に復号されたファイル | アプリキャッシュに一時的に書き込まれ、起動時、バックグラウンド移行時、または機能完了時にベストエフォートで消去されます | アプリを閉じる、またはキャッシュ/データを消去する |
| クリップボード内容 | コピーまたは自動保護が使用される際に、OSのクリップボードを通じて処理されます | ベストエフォートによる自動消去、別の内容をコピーする、または端末を再起動する |
| 暗号化バックアップファイル | お客様が削除するまで、選択した端末フォルダ、ドキュメントプロバイダー、またはクラウド同期場所に保存されます | 関連するファイルマネージャーまたはストレージサービスから削除する |
| Google広告データ | Googleおよび処理者のポリシーならびに法的義務に従って保持されます | アプリ/端末の広告設定を変更する、またはGoogleのプライバシー管理を使用する |

オペレーティングシステム、端末メーカー、ドキュメントプロバイダー、またはクラウドバックアッププロバイダーは、アプリデータまたはお客様が作成したバックアップファイルの別個のコピーを保持する場合があります。これらのコピーには、該当するプロバイダーのポリシーが適用されます。

## 6. 国際データ移転

保管庫内容は、開発者が運用するサーバーへ転送されません。広告および同意情報は、Googleおよび関連する処理者により、米国およびそれらがインフラを運用するその他の国で処理される場合があります。

暗号化バックアップの保存場所として海外のクラウドサービスを選択した場合、ファイルはお客様の指示により国外のサーバーへ同期される場合があります。詳細は[国際データ移転通知](policy/)をご覧ください。

## 7. 権限

本アプリは、お客様が該当機能を使用する際に、以下の権限またはシステム機能を使用する場合があります。

- **ファイルと写真:** お客様が選択したコンテンツのみをインポートします
- **カメラ:** 保管庫用の写真または動画を撮影します
- **マイク:** 動画録画時に音声を含めます
- **生体認証:** 保管庫アクセスまたは機微な設定変更を確認します
- **Androidでのインターネットおよびネットワーク状態:** AdMob広告およびUMP同意情報をリクエストします
- **Androidでの広告ID:** Google広告機能をサポートします
- **クリップボード:** 自動保護を明示的に有効にした場合に、コンテンツをコピーするかクリップボードのテキストを保護します

権限を拒否すると、関連する機能のみが無効になる場合があります。システムのファイルピッカーを使用する場合、アクセスは通常、お客様が選択した項目に限定されます。

## 8. セキュリティ対策および制限

現在の実装では、以下を含む対策を使用しています。

- 保管庫内容および保管庫インデックスに対するAES-256-GCM暗号化
- パスワードベース鍵のためのPBKDF2-HMAC-SHA256鍵導出
- 対応Android端末上のローカル鍵に対するAndroid KeystoreまたはStrongBox保護
- 機微な設定およびアクティビティ履歴に対する端末鍵暗号化
- アプリがバックグラウンドに入る際のベストエフォートによる保管庫ロック、一時ファイルおよびクリップボードのクリーンアップ
- 任意のスクリーンショット保護および生体再認証
- パスワードで暗号化されたポータブルバックアップパッケージ

いかなるセキュリティ方法もすべてのリスクを排除するものではありません。端末の盗難、マルウェア、オペレーティングシステムの脆弱性、弱いパスワード、お客様が共有したファイル、または外部ストレージプロバイダーのセキュリティ問題により、情報が露出する可能性があります。

復号されたコンテンツを別のアプリで開く、またはエクスポートすると、別個のコピーが作成される場合があります。元ファイルの削除および一時ファイルまたはクリップボードのクリーンアップはオペレーティングシステムによって制限される場合があるため、機微な内容の削除を確認してください。

ほとんどの情報はお客様の端末上にのみ残るため、開発者はそれらにリモートでアクセス、訂正、または削除することができません。お客様は以下を行えます。

- アプリデータまたはキャッシュを消去する、またはアプリをアンインストールする

- 利用可能な場合、アプリ内のGoogle広告プライバシーオプションを通じて同意を変更する
- 端末設定で広告識別子を削除またはリセットする、または広告のパーソナライズを制限する
