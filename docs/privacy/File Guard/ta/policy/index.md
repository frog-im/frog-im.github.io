## 3. தேர்வுகள் மற்றும் விளைவுகள்

சர்வதேச செயலாக்கத்தை நீங்கள் வரம்பிடலாம்:

- Google இன் விளம்பரத் தனியுரிமை விருப்பங்கள் கிடைக்கும் இடங்களில் ஒப்புதலை மாற்றுதல்
- தனிப்பயனாக்கப்படாத விளம்பரங்களைத் தேர்ந்தெடுப்பது அல்லது கிடைக்கும் இடங்களில் தரவுச் செயலாக்கம் தடைசெய்யப்பட்டுள்ளது
- விளம்பர அடையாளங்காட்டியை நீக்குதல் அல்லது மீட்டமைத்தல் அல்லது சாதன அமைப்புகளில் விளம்பரத் தனிப்பயனாக்கத்தைக் கட்டுப்படுத்துதல்
- நெட்வொர்க்கிலிருந்து துண்டித்தல், பயன்பாட்டைப் பயன்படுத்துவதை நிறுத்துதல் அல்லது அதை நிறுவல் நீக்குதல்
- வெளிநாட்டு கிளவுட் சேவைக்குப் பதிலாக சாதனம்-உள்ளூர் காப்புப்பிரதி இலக்கைத் தேர்ந்தெடுக்கிறது
- வெளிப்புற சேவையிலிருந்து இருக்கும் காப்பு கோப்புகளை நீக்குதல் மற்றும் ஒத்திசைவை முடக்குதல்

விளம்பரம் தொடர்பான செயலாக்கத்தை மறுப்பது தனிப்பயனாக்கப்பட்ட விளம்பரங்களை வரம்பிடலாம், தனிப்பயனாக்கப்படாத அல்லது வரையறுக்கப்பட்ட விளம்பரங்களை விளைவிக்கலாம் அல்லது சில விளம்பர அம்சங்களைத் தடுக்கலாம். கிளவுட் ஸ்டோரேஜைத் தேர்வு செய்யாமல் உள்ளூர் பெட்டகத்தைப் பயன்படுத்தலாம், ஆனால் அந்த வழங்குநரின் மூலம் ஒத்திசைவு மற்றும் தொலைநிலை மீட்பு ஆகியவை கிடைக்காது.
