# 國際資料傳輸通知

生效日期：2026 年 6 月 23 日  
最後更新時間：2026 年 6 月 23 日

FileGuard 不會將儲存在您的保管庫中的文件、文件內容、密碼、保管庫名稱或活動記錄傳送至開發人員操作的伺服器。

儘管如此，某些資訊可能會在您所在國家或地區之外進行處理： Android 使用廣告或同意功能，或直接選擇海外雲端服務作為備份目的地。

## 1. Google 廣告與同意服務

| 專案 | 詳情 |
|---|---|
| **收件者** | Google LLC、Google 附屬公司、Google 用於廣告、同意管理、測量、安全和服務運營的處理器以及配置的廣告技術提供商 |
| **聯絡方式和政策** | [谷歌隱私權政策](https://policies.google.com/privacy), [Google 廣告科技訊息](https://policies.google.com/technologies/ads) |
| **國家** | 美國以及 Google 或其處理器營運伺服器和基礎設施的其他國家。實際位置可能會因網路路由、服務配置和處理器而異。 |
| **時機** | 當 Android 應用程式更新同意訊息，顯示隱私選項，或要求、顯示或測量廣告 |
| **方法** | 應用程式之間的加密互聯網通訊或 Google SDKs 和外部伺服器 |
| **資訊** | 廣告、應用程式實例或裝置識別碼； IP位址；大概位置；裝置型號；作業系統;應用程式版本；語言;網路資訊；廣告請求、展示、點擊、互動和診斷資訊；同意狀態和隱私選擇 |
| **目的** | 廣告投放、非個人化廣告、頻率上限、測量、分析、詐欺預防、同意和隱私選擇管理、服務安全以及政策和法律合規性 |
| **保留率** | 根據 Google 和每個處理者的隱私權政策、合約義務和適用法律 |

開發者不會向 Google 廣告服務提供保管庫文件、文件內容、文件名稱、保管庫密碼、備份密碼或活動記錄。

## 2. 您選擇的外部儲存或雲端服務

FileGuard 備份檔案使用密碼加密並儲存到您選擇的位置。如果您選擇 Google Drive, iCloud Drive, OneDrive, Dropbox或其他同步或文件提供者服務，該提供者處理的加密備份檔案和相關資訊（例如檔案名稱和儲存時間）可能會傳輸到您所在國家/地區以外的伺服器。

| 專案 | 詳情 |
|---|---|
| **收件者** | 您及其處理者選擇的文件、文件或雲端儲存供應商 |
| **國家** | 如所選提供者的隱私權政策和基礎設施資訊所述 |
| **時間和方法** | 當您選擇服務作為儲存位置並建立或更新備份時，透過作業系統或提供者應用程式的網路傳輸 |
| **資訊** | 密碼加密的備份包、您選擇的檔案名稱、儲存和修改時間以及提供者自動處理的帳戶、裝置或網路訊息 |
| **目的** | 您要求的備份儲存、同步、復原和跨裝置訪問 |
| **保留率** | 直到您刪除檔案或在所選提供者指定的期限內 |

您直接選擇外部服務。開發人員不控制服務的帳戶、伺服器或保留實務。如果您遺失備份密碼，開發人員將無法還原加密備份。

## 3. 選擇和後果

您可以透過以下方式限制國際處理：

- 透過 Google 的廣告隱私選項（如果有）更改同意
- 選擇非個人化廣告或限制資料處理（如果適用）
- 刪除或重設廣告識別碼或限制裝置設定中的廣告個人化
- 斷開網路連線、停止使用應用程式或卸載應用程式
- 選擇設備本地備份目的地而不是海外雲端服務
- 從外部服務刪除現有備份檔案並停用同步

拒絕與廣告相關的處理可能會限制個人化廣告，導致非個人化或有限的廣告，或阻止某些廣告功能。您可以使用本機保管庫而不選擇雲端存儲，但無法透過該提供者進行同步和遠端復原。

## 4. 保障措施

谷歌表示，它使用傳輸加密和國際資料傳輸的法律框架，資訊可能在世界各地的伺服器上處理。

FileGuard 在將備份包寫入所選位置之前，請使用您的備份密碼對其進行加密。外部提供者仍可以處理加密檔案本身、其檔案名稱以及帳戶或網路相關資訊。選擇值得信賴的提供者並使用強大且唯一的備份密碼。
