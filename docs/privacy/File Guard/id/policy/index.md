# Pemberitahuan Transfer Data Internasional

Tanggal efektif: 23 Juni 2026  
Terakhir diperbarui: 23 Juni 2026

FileGuard tidak mengirim file yang disimpan di brankas Anda, konten file, kata sandi, nama brankas, atau riwayat aktivitas ke server yang dioperasikan pengembang.

Namun, beberapa informasi mungkin diproses di luar negara atau wilayah Anda kapan saja Android fitur periklanan atau persetujuan digunakan atau ketika Anda secara langsung memilih layanan cloud luar negeri sebagai tujuan pencadangan.

## 1. Layanan periklanan dan persetujuan Google

| Barang | Detail |
|---|---|
| **Penerima** | Google LLC, afiliasi Google, pemroses yang digunakan oleh Google untuk periklanan, pengelolaan izin, pengukuran, keamanan, dan pengoperasian layanan, serta penyedia teknologi periklanan yang dikonfigurasi |
| **Kontak dan kebijakan** | [Kebijakan Privasi Google](https://policies.google.com/privacy), [Informasi teknologi periklanan Google](https://policies.google.com/technologies/ads) |
| **Negara** | Amerika Serikat dan negara lain tempat Google atau prosesornya mengoperasikan server dan infrastruktur. Lokasi sebenarnya mungkin berbeda berdasarkan perutean jaringan, konfigurasi layanan, dan prosesor. |
| **Waktu** | Ketika Android aplikasi memperbarui informasi persetujuan, menampilkan opsi privasi, atau meminta, menampilkan, atau mengukur iklan |
| **Metode** | Komunikasi internet terenkripsi antara aplikasi atau Google SDKs dan server eksternal |
| **Informasi** | Iklan, contoh aplikasi, atau pengidentifikasi perangkat; alamat IP; perkiraan lokasi; model perangkat; sistem operasi; versi aplikasi; bahasa; informasi jaringan; permintaan iklan, tayangan, klik, interaksi, dan informasi diagnostik; status persetujuan dan pilihan privasi |
| **Tujuan** | Penayangan iklan, iklan yang tidak dipersonalisasi, pembatasan frekuensi, pengukuran, analitik, pencegahan penipuan, manajemen persetujuan dan pilihan privasi, keamanan layanan, dan kepatuhan terhadap kebijakan dan undang-undang |
| **Retensi** | Berdasarkan kebijakan privasi, kewajiban kontrak, dan hukum yang berlaku dari Google dan setiap pemroses |

Pengembang tidak memberikan file vault, konten file, nama file, kata sandi vault, kata sandi cadangan, atau riwayat aktivitas ke layanan periklanan Google.

## 2. Penyimpanan eksternal atau layanan cloud yang Anda pilih

FileGuard file cadangan dienkripsi dengan kata sandi dan disimpan ke lokasi yang Anda pilih. Jika Anda memilih Google Drive, iCloud Drive, OneDrive, Dropbox, atau layanan sinkronisasi atau penyedia dokumen lainnya, file cadangan terenkripsi dan informasi terkait yang diproses oleh penyedia tersebut—seperti nama file dan waktu penyimpanan—dapat ditransfer ke server di luar negara Anda.

| Barang | Detail |
|---|---|
| **Penerima** | Penyedia file, dokumen, atau penyimpanan cloud yang Anda pilih dan pemrosesnya |
| **Negara** | Seperti yang dijelaskan dalam kebijakan privasi dan informasi infrastruktur penyedia yang dipilih |
| **Waktu dan metode** | Saat Anda memilih layanan sebagai lokasi penyimpanan dan membuat atau memperbarui cadangan, melalui transfer jaringan oleh sistem operasi atau aplikasi penyedia |
| **Informasi** | Paket cadangan yang dienkripsi kata sandi, nama file yang Anda pilih, waktu penyimpanan dan modifikasi, serta informasi akun, perangkat, atau jaringan yang diproses secara otomatis oleh penyedia |
| **Tujuan** | Penyimpanan cadangan, sinkronisasi, pemulihan, dan akses lintas perangkat yang Anda minta |
| **Retensi** | Sampai Anda menghapus file atau selama jangka waktu yang ditentukan oleh penyedia yang dipilih |

Anda memilih layanan eksternal secara langsung. Pengembang tidak mengontrol akun, server, atau praktik penyimpanan layanan. Jika Anda kehilangan kata sandi cadangan, pengembang tidak dapat memulihkan cadangan terenkripsi.

## 3. Pilihan dan konsekuensi

Anda dapat membatasi pemrosesan internasional dengan:

- Mengubah persetujuan melalui opsi privasi iklan Google jika tersedia
- Memilih iklan yang tidak dipersonalisasi atau pemrosesan data yang dibatasi jika tersedia
- Menghapus atau menyetel ulang pengidentifikasi iklan atau membatasi personalisasi iklan di pengaturan perangkat
- Memutuskan sambungan dari jaringan, menghentikan penggunaan aplikasi, atau mencopot pemasangannya
- Memilih tujuan pencadangan lokal perangkat, bukan layanan cloud luar negeri
- Menghapus file cadangan yang ada dari layanan eksternal dan menonaktifkan sinkronisasi

Menolak pemrosesan terkait iklan dapat membatasi iklan yang dipersonalisasi, menghasilkan iklan yang tidak dipersonalisasi atau terbatas, atau menghalangi beberapa fitur iklan. Anda dapat menggunakan brankas lokal tanpa memilih penyimpanan cloud, tetapi sinkronisasi dan pemulihan jarak jauh melalui penyedia tersebut tidak akan tersedia.

## 4. Perlindungan

Google menyatakan bahwa mereka menggunakan enkripsi saat transit dan kerangka hukum untuk transfer data internasional dan informasi dapat diproses di server di seluruh dunia.

FileGuard mengenkripsi paket cadangan dengan kata sandi cadangan Anda sebelum menuliskannya ke lokasi yang dipilih. Penyedia eksternal masih dapat memproses file terenkripsi itu sendiri, nama filenya, dan informasi terkait akun atau jaringan. Pilih penyedia tepercaya dan gunakan kata sandi cadangan yang kuat dan unik.
