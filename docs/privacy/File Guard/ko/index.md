## 1. 목적 및 적용 범위

FileGuard는 이용자가 선택하거나 촬영한 파일, 메모 및 클립보드 텍스트를 기기 내 암호화 금고에 보관하고, 암호화 백업 파일을 만들 수 있도록 제공되는 보안 도구입니다.

앱은 회원가입이나 로그인을 요구하지 않으며, 개발자는 금고 파일, 파일 내용, 비밀번호, 금고 이름 또는 활동 기록을 수신하는 서버를 운영하지 않습니다. 다만 Android 버전에서 광고 및 개인정보 선택 기능을 제공하기 위해 Google AdMob과 Google User Messaging Platform(UMP)을 사용할 수 있습니다.

## 2. 처리하는 정보

### 2-1. 이용자가 선택하거나 생성하는 금고 데이터

앱은 기능 제공을 위해 다음 정보를 기기에서 처리할 수 있습니다.

- 이용자가 시스템 파일 선택기를 통해 선택한 사진, 동영상, 문서 및 기타 파일
- 앱의 카메라 기능으로 촬영한 사진 또는 동영상과, 동영상 촬영 시 포함될 수 있는 오디오
- 이용자가 직접 저장하거나 자동 보호 기능을 켠 경우 감지된 클립보드 텍스트
- 파일 이름, MIME 형식, 파일 크기, 생성 시각, 설명, 미리보기 관련 정보
- 금고 이름, 금고 식별자, 보안 등급, 원본 파일 상태 및 원본 참조 정보
- 이용자가 만든 암호화 내보내기, 전송 또는 백업 패키지

이 정보는 앱 기능 제공을 위해 이용자의 기기에서 처리됩니다. 개발자는 이를 개발자 운영 서버로 업로드하지 않습니다.

### 2-2. 인증 및 보안 정보

앱은 다음 정보를 기기 내 보안 저장소에서 처리할 수 있습니다.

- 비밀번호에서 파생된 암호화 키를 구성하기 위한 salt, 키 파생 설정 및 암호화된 키 묶음
- 금고 접근 자격 정보, 생체 인증용으로 기기 키에 의해 보호된 로컬 키
- 화면 캡처 방지, 클립보드 정리, 생체 재인증, 자동 보호 등 보안 설정

비밀번호 원문은 개발자에게 전송되지 않습니다. 생체 인증은 운영체제가 수행하며, 앱은 지문·얼굴 이미지 또는 생체 인식 템플릿을 수집하지 않고 인증 성공 여부만 확인합니다.

### 2-3. 로컬 활동 및 백업 정보

앱은 기능 상태를 표시하고 보안 동작을 기록하기 위해 다음 정보를 기기에 저장할 수 있습니다.

- 보호, 잠금, 삭제, 원본 삭제, 백업 및 복원 등 앱 내 활동의 유형, 설명, 시각과 관련 항목 식별자
- 활동 기록 최대 500건
- 백업 파일 위치, 최근 백업 시각, 백업된 항목 수, 성공 또는 실패 상태
- 자동 백업 사용 여부와 자동 백업에 필요한 비밀번호
- 광고 개인정보 선택, 제한적 데이터 처리 선택 및 광고 표시 빈도 계산용 보호 항목 수

백업 상태와 자동 백업 비밀번호 등 보호가 필요한 설정은 기기 결합 키를 이용한 암호화 저장소에 저장됩니다. 이용자는 백업 비밀번호를 안전하게 관리해야 합니다.

### 2-4. 광고 및 동의 과정에서 자동 처리될 수 있는 정보

지원되는 플랫폼인 Android에서 앱은 Google AdMob 및 UMP를 사용할 수 있습니다. Google과 광고 기술 제공업체는 다음 정보를 처리할 수 있습니다.

- 광고 식별자, 앱 인스턴스 또는 기기 관련 식별자
- IP 주소와 IP 주소 등에서 추정한 대략적인 위치
- 기기 모델, 운영체제, 앱 버전, 언어, 네트워크 정보
- 광고 요청, 노출, 클릭, 상호작용 및 진단 정보
- 광고 동의 상태와 지역별 개인정보 선택

이 정보는 광고 제공, 비개인 맞춤 광고, 빈도 제한, 측정, 부정 사용 방지, 동의 관리, 보안 및 법적 의무 준수를 위해 처리될 수 있습니다. 앱은 UMP가 광고 요청을 허용한 이후에 Google Mobile Ads SDK를 초기화하도록 구현되어 있습니다.

Google의 처리 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [Google 광고 기술 안내](https://policies.google.com/technologies/ads)에서 확인할 수 있습니다.

개발자는 금고 콘텐츠, 비밀번호 또는 앱 내 활동 기록을 판매하지 않으며, 이를 개발자 운영 서버를 통해 제3자에게 제공하지 않습니다.

Android에서 광고 또는 동의 기능이 작동하면 Google LLC, Google 계열사, 광고 기술 제공업체 및 관련 처리업체가 제2-4항의 정보를 처리할 수 있습니다. 자세한 내용은 별도의 [국가 간 데이터 이전 안내](policy/)를 확인해 주십시오.

이용자가 파일 선택기, 공유 기능 또는 백업 저장 위치로 외부 앱이나 클라우드 서비스를 직접 선택하면 해당 제공자가 이용자의 지시에 따라 파일을 처리할 수 있습니다. 이 경우 해당 제공자의 개인정보 처리방침과 보안 설정이 적용되며, 개발자는 이용자가 선택한 외부 서비스의 처리 방식을 통제하지 않습니다.

## 6. 국가 간 데이터 이전

금고 콘텐츠는 개발자 운영 서버로 이전되지 않습니다. 다만 Android의 광고 및 동의 기능을 이용할 때 Google과 관련 처리업체가 광고 및 동의 관련 정보를 미국과 그 밖의 인프라 운영 국가에서 처리할 수 있습니다.

또한 이용자가 암호화 백업 파일의 저장 위치로 해외 클라우드 서비스를 선택하면 해당 파일이 이용자의 선택에 따라 국외 서버로 동기화될 수 있습니다. 자세한 사항은 [국가 간 데이터 이전 안내](policy/)를 확인해 주십시오.

## 7. 권한 사용

앱은 이용자가 해당 기능을 사용할 때 다음 권한 또는 시스템 기능을 사용할 수 있습니다.

- **파일 및 사진 선택:** 이용자가 명시적으로 선택한 파일을 가져오기 위해 사용
- **카메라:** 사진 또는 동영상을 촬영해 금고에 저장하기 위해 사용
- **마이크:** 동영상 촬영 시 오디오를 포함하기 위해 사용
- **생체 인증:** 금고 잠금 해제 또는 민감한 설정 변경을 재확인하기 위해 사용
- **인터넷 및 네트워크 상태(Android):** AdMob 광고와 UMP 동의 정보를 요청하기 위해 사용

권한을 허용하지 않으면 해당 기능만 제한될 수 있습니다. 시스템 파일 선택기를 사용하는 경우 앱의 접근 범위는 원칙적으로 이용자가 선택한 항목으로 제한됩니다.

## 8. 보안 조치와 한계

현재 구현은 다음과 같은 조치를 사용합니다.

- 금고 콘텐츠와 금고 색인을 AES-256-GCM 방식으로 암호화
- 비밀번호 기반 키에 PBKDF2-HMAC-SHA256 키 파생 적용
- 지원되는 Android 기기에서 Android Keystore 또는 StrongBox를 이용한 로컬 키 보호
- 중요한 설정과 활동 기록의 기기 결합 암호화 저장
- 앱이 백그라운드로 전환될 때 금고 잠금, 임시 파일 및 클립보드 정리 시도
- 선택 가능한 화면 캡처 방지 및 생체 재인증
- 비밀번호로 암호화된 휴대용 백업 패키지

어떠한 보안 방식도 모든 위험을 완전히 제거할 수 없습니다. 기기 탈취, 악성 프로그램, 운영체제 취약점, 약한 비밀번호, 이용자가 직접 공유한 파일 또는 외부 저장 서비스의 보안 문제로 정보가 노출될 수 있습니다.

복호화된 콘텐츠를 다른 앱으로 열거나 내보내면 해당 앱 또는 저장 위치에 별도 사본이 남을 수 있습니다. 원본 삭제와 임시 파일·클립보드 정리는 운영체제 제한으로 완료되지 않을 수 있으므로 민감한 파일은 이용자가 직접 확인해야 합니다.
