# 隱私權政策（TimeBack）

- **應用程式名稱：** TimeBack
- **開發商：** frog-im
- **聯絡方式：** [g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)
- **生效日期：** 2026-06-03
- **最後更新：** 2026-06-06

本隱私權政策基於 TimeBack 應用程式的目前實施。 TimeBack 提供螢幕時間回顧、每日目標、回收時間記錄、反思、挑戰、通知、分享和廣告功能。

## 1. 特點

TimeBack 提供以下功能：

- 透過Android使用存取權限審核App使用時間
- 每日使用目標、提醒和狀態列使用通知
- 硬限制警告通知和疊加顯示
- 疊加異常應用程式選擇
- 回收時間活動記錄
- 每日反思記錄
- 挑戰進度和清單管理
- 使用統計圖像共享
- Google AdMob 廣告和基於 UMP 的隱私選項

## 2. 我們處理的訊息

### 2-1.資訊讀取使用存取權限

如果使用者授予 Android `PACKAGE_USAGE_STATS` 權限，應用程式可能會從裝置讀取以下資訊：

- 應用程式包名稱
- 應用程式名稱
- 應用程式使用時間
- 用於使用情況聚合的日期和時間範圍

此資訊用於提供使用情況統計資料並將使用情況與使用者目標進行比較。

### 2-2.使用者輸入或配置的訊息

- 每日使用目標
- 使用提醒啟用狀態和間隔
- 狀態列使用情況顯示設定
- 回收時間活動類別、標題、開始時間和持續時間
- 每日反思文字
- 挑戰進度和清單條目
- 疊加異常應用列表

### 2-3.設備上儲存的信息

該應用程式可能會將下列資訊儲存在本機 SQLite 資料庫或 SharedPreferences 中：

- 應用程式使用時間記錄
- 每日目標和設置
- 回收時間活動記錄
- 每日反思記錄
- 挑戰進度和清單狀態
- 入職完成狀態
- 使用提醒、硬限制警告、狀態列顯示和覆蓋例外應用程式等設置
- 本地廣告同意和隱私選項狀態

根據目前的實現，這些本地記錄不會自動上傳到 frog-im 伺服器。

### 2-4.廣告與同意數據

當使用 Google 行動廣告 SDK (AdMob) 和 UMP 時，Google 或其關聯公司可能會處理下列資訊：

- 廣告標識符，例如 Android AD_ID
- IP 位址與網路訊息
- 設備資訊、OS版本和應用程式訊息
- 廣告展示次數、點擊次數、測量數據和錯誤訊號
- 廣告同意和隱私選項狀態
- 大概位置

## 3. 處理目的

該應用程式出於以下目的處理資訊：

- 讀取使用時間、顯示統計資料並將使用情況與目標進行比較
- 儲存使用者輸入的回收時間和反射記錄
- 管理挑戰進度
- 提供提醒和狀態列通知
- 提供硬限制警告通知、疊加顯示、疊加異常處理
- 根據用戶請求共享使用情況統計圖像
- 投放廣告、衡量廣告成效、應用程式廣告同意選擇
- 維護應用程式穩定性並響應錯誤

## 4. 本地儲存和外部處理

### 4-1.本地存儲

TimeBack 主要將使用者資料儲存在裝置上應用程式的內部儲存中。根據目前的實現，使用記錄、目標、反思和挑戰資訊不會自動上傳到 frog-im 伺服器。

本機儲存可能包括以下內容。

| 貯存 | 儲存物品 | 目的 | 刪除方法 |
|---|---|---|---|
| SQLite資料庫 | 應用程式使用記錄、套件名稱、應用程式名稱、使用時間、基於日期的聚合 | 顯示使用情況統計資料並將使用情況與目標進行比較 | 應用程式內刪除功能，清除應用程式資料或卸載應用程式 |
| SQLite資料庫 | 回收時間活動、反思、挑戰進度、清單條目 | 顯示記錄並管理進度 | 應用程式內刪除功能，清除應用程式資料或卸載應用程式 |
| 共享首選項 | 登入完成狀態、提醒設定、硬限制警告設定、狀態列顯示設定、覆蓋例外應用程式清單、本機廣告同意狀態 | 保留應用程式設定 | 清除應用程式資料或卸載應用程式 |
| 臨時文件/緩存 | 共享使用情況統計圖像和類似的臨時文件 | 執行用戶請求的共享 | 盡可能在共享後刪除，或根據 OS/app 清理政策 |

當使用者清除應用程式資料或卸載應用程式時，應用程式內部儲存體中儲存的資料通常會被刪除。然而，Android備份、製造商備份、雲端備份或用戶直接共享的檔案可能會根據這些服務的政策單獨保留。

使用記錄和反思文字可能會揭示個人習慣或興趣。在共用裝置上，使用者應使用適當的保護措施，例如裝置鎖定或單獨的 OS 帳戶。

### 4-2.伺服器上傳

基於目前項目，TimeBack不會自動上傳使用記錄、反思或挑戰記錄到frog-im伺服器。如果使用者使用共享功能，則產生的統計圖像可以被傳送到使用者選擇的外部應用程式或服務。

### 4-3.廣告處理

Google AdMob 和 UMP 用於應用程式內廣告和同意管理。廣告相關資訊可能會在 Google 基礎架構上處理。

## 5. 第三方服務與處理者

- 橫幅廣告投放

## 7. 已安裝的應用程式清單和疊加異常

在Android上，如果使用者配置覆蓋例外應用程序，則該應用程式可以讀取裝置上可啟動應用程式的套件名稱和應用程式名稱以顯示選擇清單。使用者選擇的例外套件名稱儲存在裝置上的 SharedPreferences 中，僅用於避免在這些應用程式之上顯示硬限制警告疊加層。

## 8. 保留

該應用程式根據以下標準保留資訊：

- 本地使用情況、目標、反思和挑戰資訊：直到使用者刪除、清除應用程式資料或卸載應用程式
- SharedPreferences 設定：直到使用者清除應用程式資料或卸載應用程式
- 共用映像的臨時檔案：根據共用需求或根據 OS 清理策略
- 廣告與同意相關數據：根據 Google 和其他相關第三方的政策

## 9. 權限

該應用程式可能使用以下權限：

- `PACKAGE_USAGE_STATS`：讀取應用程式使用時間
- `POST_NOTIFICATIONS`：顯示使用提醒和狀態列通知
- `SYSTEM_ALERT_WINDOW`：顯示硬限制警告疊加
- `INTERNET`：與廣告 SDK 溝通並顯示法律聲明頁面
- `ACCESS_NETWORK_STATE`：檢查網路狀態
- `com.google.android.gms.permission.AD_ID`：使用廣告標識符

僅在應用程式功能需要時使用權限。使用者可以在裝置設定中撤銷權限，但相關功能可能會受到限制。
