## 1. 目的與適用範圍

`know_me` 是一款旨在協助使用者記錄與管理人物相關資訊的應用程式，並可於必要時將該等資訊進行備份、還原，以及以 PDF 檔案形式分享。

其主要功能包括：

- 儲存與特定人物相關之資訊（例如姓名、識別文字、備註、性格特徵、國家、性別、聯絡資訊等）
- 資料夾分類、搜尋與合併功能
- 附加照片並管理說明
- 匯出與匯入備份（`.knm`）
- 匯出 PDF
- 應用程式鎖定（密碼 / 圖案）
- 廣告與同意管理（AdMob / UMP）

本應用程式無須另外註冊帳號，且應用程式的核心使用者資料通常儲存在使用者裝置本機。  
然而，為廣告與同意管理而整合的部分第三方 SDK 可能會處理某些資訊。

## 2. 處理之個人資訊類別

### 2-1) 使用者直接輸入之資訊

以下資訊僅在使用者直接輸入時才會儲存：

- 姓名
- 識別文字（例如作為備註文字使用的外觀 / 特徵）
- 備註
- 性格特徵、國家、性別
- 電話號碼
- 與出現時間 / 見面時間相關之文字
- 平台 / 網站資訊
- 資料夾名稱 / 顏色
- 圖片說明（caption）

### 2-2) 於裝置上選擇之檔案

- 使用者於附加照片時所選擇之圖片檔案
- 使用者於匯入備份時所選擇之 `.knm` 備份檔案
- 使用者於匯出 PDF / 備份時所選擇之儲存路徑及儲存檔案

### 2-3) 於應用程式內本機儲存之資料

為提供應用程式功能，以下資料可能會儲存在使用者裝置上：

- SQLite 資料庫（`people_note.db`）：與人物 / 資料夾 / 平台 / 網站 / 圖片相關之中繼資料
- 圖片檔案：加密後儲存在應用程式文件資料夾中（`.enc`）
- 應用程式設定（`SharedPreferences`）：主題、排序、隱私 / 廣告選項、PDF 遮罩選項、應用程式鎖定政策等
- 應用程式鎖定資訊：密碼 / 圖案之雜湊值與鹽值（`SharedPreferences`）
- 本機加密金鑰：儲存於 `flutter_secure_storage`
- 暫存檔案：圖片解密預覽、匯入 / 匯出快取檔案等（暫存資料夾）

### 2-4) 於廣告與同意管理過程中可能自動處理之資訊

當廣告或同意管理功能啟用時，Google LLC 及其相關合作夥伴之 SDK（如 AdMob、UMP）可能會自動處理以下資訊：

- 廣告識別碼（AAID / IDFA 等）
- IP 位址及網路資訊
- 裝置資訊（作業系統版本、裝置型號、應用程式版本等）
- 廣告互動資訊（曝光、點擊等）
- 同意狀態及隱私選擇資訊
- 診斷、效能及安全相關資訊

本應用程式的核心使用者紀錄通常不會上傳至開發者伺服器，但於使用廣告 / 同意功能期間，上述部分資訊可能會傳輸至第三方服務。

## 3. 個人資訊處理目的

本應用程式基於以下目的處理個人資訊或相關資訊：

- 記錄與瀏覽以聯絡資訊 / 備註為核心之人物資訊
- 提供資料夾分類、搜尋、合併等整理功能
- 附加並顯示照片
- 執行使用者要求之功能，例如備份 / 還原及 PDF 匯出
- 提供應用程式鎖定安全功能
- 提供廣告、管理同意、防止詐欺行為以及履行法律義務

## 4. 個人資訊保存與儲存期間

- 應用程式內部資料（SQLite、本機設定、加密圖片）：於應用程式刪除、應用程式資料清除，或使用者直接刪除資料前，儲存於使用者裝置上
- 暫存檔案：於相關作業完成後刪除，或依作業系統之快取政策清理
- 使用者匯出之檔案（PDF、備份檔案）：可能保留於使用者所選擇之儲存位置，並須由使用者自行刪除
- 與廣告 / 同意相關之資料（由第三方處理）：受各服務提供者之政策及適用法律約束

原則上，本應用程式不會於開發者伺服器上儲存核心使用者紀錄。  
然而，使用者直接儲存至外部儲存空間之檔案，將由使用者自身環境進行管理。

## 5. 個人資訊刪除程序與刪除方式

當處理目的已達成，或使用者提出刪除要求時，本應用程式將以下列方式刪除相關資訊，或將其處理為不再被參照之狀態。

### 5-1) 刪除程序

- 當使用者直接刪除個別人物紀錄、資料夾、圖片、備份資料等時，該等資料將被視為立即刪除對象。
- 當使用者刪除應用程式，或於裝置設定中清除應用程式資料時，儲存於應用程式內部儲存區域之資料，將依作業系統之刪除程序移除。
- 暫存檔案會於相關作業結束後納入清理流程，部分快取資料可能會依作業系統政策保留一段時間。

### 5-2) 刪除方式

- SQLite 資料：刪除相關紀錄
- 應用程式設定（`SharedPreferences`）：刪除相關鍵值或全部設定
- `flutter_secure_storage` 中之值：刪除相應之安全儲存項目
- 應用程式內部檔案（加密圖片、暫存檔案等）：刪除相關檔案
- 使用者直接儲存至外部儲存空間之 PDF / 備份檔案：不會由應用程式自動刪除，須由使用者自行刪除

除非適用法律另有要求，開發者不會於開發者伺服器上另行儲存核心使用者紀錄。

## 10. 安全措施

開發者已採取或致力採取以下措施：

- 使用者紀錄通常儲存於裝置本機
