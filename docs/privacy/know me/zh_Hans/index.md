## 1. 目的和适用范围

`know_me` 是一款旨在帮助用户记录和管理与人物相关信息的应用，并可在需要时对该等信息进行备份、恢复，并以 PDF 文件形式进行分享。

其主要功能包括：

- 存储与特定人物相关的信息（如姓名、识别文本、备注、性格特征、国家、性别、联系方式等）
- 文件夹分类、搜索及合并功能
- 附加照片并管理说明
- 导出和导入备份（`.knm`）
- 导出 PDF
- 应用锁定（密码 / 图案）
- 广告及同意管理（AdMob / UMP）

本应用无需单独注册账户，且应用的核心用户数据通常存储在用户设备本地。  
但是，为广告和同意管理而集成的某些第三方 SDK 可能会处理部分信息。

## 2. 处理的个人信息类别

### 2-1) 用户直接输入的信息

以下信息仅在用户直接输入时才会被存储：

- 姓名
- 识别文本（例如用作备注文本的外貌 / 特征）
- 备注
- 性格特征、国家、性别
- 电话号码
- 与出现时间 / 见面时间相关的文本
- 平台 / 网站信息
- 文件夹名称 / 颜色
- 图片说明（caption）

### 2-2) 在设备上选择的文件

- 用户在附加照片时选择的图片文件
- 用户在导入备份时选择的 `.knm` 备份文件
- 用户在导出 PDF / 备份时选择的保存路径及保存文件

### 2-3) 在应用内本地存储的数据

为提供应用功能，以下数据可能会存储在用户设备上：

- SQLite 数据库（`people_note.db`）：与人物 / 文件夹 / 平台 / 网站 / 图片相关的元数据
- 图片文件：加密后存储在应用文档目录中（`.enc`）
- 应用设置（`SharedPreferences`）：主题、排序、隐私 / 广告选项、PDF 遮罩选项、应用锁定策略等
- 应用锁定信息：密码 / 图案的哈希值和盐值（`SharedPreferences`）
- 本地加密密钥：存储于 `flutter_secure_storage`
- 临时文件：图片解密预览、导入 / 导出缓存文件等（临时文件夹）

### 2-4) 在广告及同意管理过程中可能被自动处理的信息

当广告或同意管理功能启用时，Google LLC 及其相关合作伙伴的 SDK（如 AdMob、UMP）可能会自动处理以下信息：

- 广告标识符（AAID / IDFA 等）
- IP 地址及网络信息
- 设备信息（操作系统版本、设备型号、应用版本等）
- 广告交互信息（展示、点击等）
- 同意状态及隐私选择信息
- 诊断、性能及安全相关信息

本应用的核心用户记录通常不会上传至开发者服务器，但在使用广告 / 同意功能期间，上述部分信息可能会传输至第三方服务。

## 3. 个人信息的处理目的

本应用出于以下目的处理个人信息或相关信息：

- 记录和查看以联系人 / 备注为核心的人物信息
- 提供文件夹分类、搜索、合并等整理功能
- 附加并显示照片
- 执行用户请求的功能，如备份 / 恢复及 PDF 导出
- 提供应用锁定安全功能
- 提供广告、管理同意、防止欺诈行为并履行法律义务

## 4. 个人信息的保存及存储期限

- 应用内部数据（SQLite、本地设置、加密图片）：在应用被删除、应用数据被清除或用户直接删除数据之前，保存在用户设备上
- 临时文件：在相关任务完成后删除，或根据操作系统缓存策略进行清理
- 用户导出的文件（PDF、备份文件）：可能保留在用户选择的存储位置，需由用户自行删除
- 与广告 / 同意相关的数据（由第三方处理）：受各服务提供商的政策及适用法律约束

原则上，本应用不会在开发者服务器上存储核心用户记录。  
但是，用户直接保存到外部存储中的文件由用户自身环境进行管理。

## 5. 个人信息的删除程序和删除方式

当处理目的已实现，或用户提出删除请求时，本应用将按如下方式删除相关信息，或对其进行处理使其不再被引用。

### 5-1) 删除程序

- 当用户直接删除单个人物记录、文件夹、图片、备份数据等时，该等数据将被视为立即删除对象。
- 当用户删除应用或在设备设置中清除应用数据时，存储在应用内部存储区域的数据将按照操作系统的删除程序被移除。
- 临时文件将在相关任务结束后进入清理流程，部分缓存数据可能会根据操作系统策略保留一段时间。

### 5-2) 删除方式

- SQLite 数据：删除相关记录
- 应用设置（`SharedPreferences`）：删除相关键值或全部设置
- `flutter_secure_storage` 中的值：删除相应的安全存储条目
- 应用内部文件（加密图片、临时文件等）：删除相关文件
- 用户直接保存到外部存储的 PDF / 备份文件：不会由应用自动删除，需由用户自行删除

除非适用法律另有要求，开发者不会在开发者服务器上另行存储核心用户记录。

## 10. 安全措施

开发者已采取或致力于采取以下措施：

- 用户记录通常存储在设备本地
- 附加的图片文件以加密形式存储在本地（基于 AES-GCM）
- 应用锁定信息以哈希形式存储，而非明文存储
- 备份文件会先基于用户密码进行加密后再存储
- 与第三方 SDK 的通信已加密（HTTPS / TLS）
- 权限以最小必要访问范围使用

但是，由用户设备安全状态引发的风险（如 root / 越狱、恶意应用、共享存储暴露等）无法被完全消除。
