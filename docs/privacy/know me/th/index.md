## 1. วัตถุประสงค์และขอบเขต

`know_me` เป็นแอปที่ออกแบบมาเพื่อช่วยให้ผู้ใช้บันทึกและจัดการข้อมูลเกี่ยวกับบุคคลต่าง ๆ และเมื่อจำเป็น ยังสามารถสำรองข้อมูล กู้คืนข้อมูล และแชร์ข้อมูลดังกล่าวในรูปแบบไฟล์ PDF ได้

คุณสมบัติหลักของแอปประกอบด้วย:

- จัดเก็บข้อมูลเฉพาะของแต่ละบุคคล (เช่น ชื่อ ข้อความระบุตัวตน บันทึก ลักษณะนิสัย ประเทศ เพศ ข้อมูลติดต่อ เป็นต้น)
- การจัดหมวดหมู่โฟลเดอร์ การค้นหา และฟังก์ชันรวมข้อมูล
- การแนบรูปภาพและจัดการคำอธิบาย
- การส่งออกและนำเข้าข้อมูลสำรอง (`.knm`)
- การส่งออก PDF
- การล็อกแอป (รหัสผ่าน / รูปแบบ)
- การจัดการโฆษณาและความยินยอม (AdMob / UMP)

แอปนี้ไม่จำเป็นต้องลงทะเบียนบัญชีแยกต่างหาก และโดยทั่วไปข้อมูลหลักของผู้ใช้จะถูกจัดเก็บไว้ภายในอุปกรณ์ของผู้ใช้แบบภายในเครื่อง  
อย่างไรก็ตาม SDK ของบุคคลที่สามบางรายการที่รวมอยู่เพื่อการจัดการโฆษณาและความยินยอม อาจประมวลผลข้อมูลบางส่วนได้

## 2. ประเภทของข้อมูลส่วนบุคคลที่มีการประมวลผล

### 2-1) ข้อมูลที่ผู้ใช้ป้อนโดยตรง

ข้อมูลต่อไปนี้จะถูกจัดเก็บเฉพาะเมื่อผู้ใช้ป้อนเองโดยตรงเท่านั้น:

- ชื่อ
- ข้อความระบุตัวตน (เช่น รูปลักษณ์ / ลักษณะเฉพาะที่ใช้เป็นข้อความบันทึก)
- บันทึก
- ลักษณะนิสัย ประเทศ เพศ
- หมายเลขโทรศัพท์
- ข้อความที่เกี่ยวข้องกับเวลาที่ปรากฏ / เวลาที่พบกัน
- ข้อมูลแพลตฟอร์ม / เว็บไซต์
- ชื่อโฟลเดอร์ / สี
- คำอธิบายรูปภาพ (caption)

### 2-2) ไฟล์ที่เลือกบนอุปกรณ์

- ไฟล์รูปภาพที่ผู้ใช้เลือกเมื่อแนบรูปภาพ
- ไฟล์สำรองข้อมูล `.knm` ที่ผู้ใช้เลือกเมื่อนำเข้าข้อมูลสำรอง
- เส้นทางการบันทึกและไฟล์ที่บันทึก ซึ่งผู้ใช้เลือกเมื่อส่งออก PDF / ข้อมูลสำรอง

### 2-3) ข้อมูลที่จัดเก็บภายในแอปแบบภายในเครื่อง

ข้อมูลต่อไปนี้อาจถูกจัดเก็บไว้บนอุปกรณ์ของผู้ใช้เพื่อให้บริการคุณสมบัติต่าง ๆ ของแอป:

- ฐานข้อมูล SQLite (`people_note.db`): เมทาดาทาที่เกี่ยวข้องกับบุคคล / โฟลเดอร์ / แพลตฟอร์ม / เว็บไซต์ / รูปภาพ
- ไฟล์รูปภาพ: เข้ารหัสและจัดเก็บไว้ในโฟลเดอร์เอกสารของแอป (`.enc`)
- การตั้งค่าแอป (`SharedPreferences`): ธีม การเรียงลำดับ ตัวเลือกความเป็นส่วนตัว / โฆษณา ตัวเลือกการปกปิดข้อมูลใน PDF นโยบายการล็อกแอป เป็นต้น
- ข้อมูลการล็อกแอป: ค่าแฮชและ salt ของรหัสผ่าน / รูปแบบ (`SharedPreferences`)
- คีย์เข้ารหัสภายในเครื่อง: จัดเก็บไว้ใน `flutter_secure_storage`
- ไฟล์ชั่วคราว: ตัวอย่างการถอดรหัสรูปภาพ ไฟล์แคชสำหรับการนำเข้า / ส่งออก เป็นต้น (โฟลเดอร์ชั่วคราว)

### 2-4) ข้อมูลที่อาจถูกประมวลผลโดยอัตโนมัติระหว่างการจัดการโฆษณาและความยินยอม

เมื่อเปิดใช้งานคุณสมบัติโฆษณาหรือการจัดการความยินยอม SDK ของ Google LLC และพันธมิตรที่เกี่ยวข้อง (เช่น AdMob และ UMP) อาจประมวลผลข้อมูลต่อไปนี้โดยอัตโนมัติ:

- ตัวระบุโฆษณา (AAID / IDFA เป็นต้น)
- ที่อยู่ IP และข้อมูลเครือข่าย
- ข้อมูลอุปกรณ์ (เวอร์ชันระบบปฏิบัติการ รุ่นอุปกรณ์ เวอร์ชันแอป เป็นต้น)
- ข้อมูลการโต้ตอบกับโฆษณา (การแสดงผล การคลิก เป็นต้น)
- สถานะความยินยอมและข้อมูลตัวเลือกความเป็นส่วนตัว
- ข้อมูลที่เกี่ยวข้องกับการวินิจฉัย ประสิทธิภาพ และความปลอดภัย

โดยทั่วไป ข้อมูลหลักของผู้ใช้ในแอปจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของผู้พัฒนา แต่ข้อมูลบางส่วนตามที่กล่าวข้างต้นอาจถูกส่งไปยังบริการของบุคคลที่สามในระหว่างที่มีการใช้คุณสมบัติโฆษณา / ความยินยอม

## 3. วัตถุประสงค์ของการประมวลผลข้อมูลส่วนบุคคล

แอปประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลที่เกี่ยวข้องเพื่อวัตถุประสงค์ดังต่อไปนี้:

- บันทึกและดูข้อมูลเกี่ยวกับบุคคล โดยเน้นที่ข้อมูลติดต่อ / บันทึก
- ให้บริการคุณสมบัติการจัดระเบียบ เช่น การจัดหมวดหมู่โฟลเดอร์ การค้นหา และการรวมข้อมูล
- แนบและแสดงรูปภาพ
- ดำเนินการตามคุณสมบัติที่ผู้ใช้ร้องขอ เช่น การสำรอง / กู้คืน และการส่งออก PDF
- ให้บริการคุณสมบัติด้านความปลอดภัยของการล็อกแอป
- ให้บริการโฆษณา จัดการความยินยอม ป้องกันกิจกรรมฉ้อโกง และปฏิบัติตามภาระผูกพันทางกฎหมาย

## 4. ระยะเวลาในการเก็บรักษาและการจัดเก็บข้อมูลส่วนบุคคล

- ข้อมูลภายในแอป (SQLite การตั้งค่าในเครื่อง รูปภาพที่เข้ารหัส): จะถูกเก็บไว้บนอุปกรณ์ของผู้ใช้จนกว่าจะลบแอป ล้างข้อมูลแอป หรือผู้ใช้ลบข้อมูลโดยตรง
- ไฟล์ชั่วคราว: จะถูกลบหลังจากงานที่เกี่ยวข้องเสร็จสิ้น หรือถูกล้างตามนโยบายแคชของระบบปฏิบัติการ
- ไฟล์ที่ผู้ใช้ส่งออก (PDF, ไฟล์สำรอง): อาจคงอยู่ในตำแหน่งที่ผู้ใช้เลือกบันทึกไว้ และผู้ใช้ต้องลบเองโดยตรง
- ข้อมูลที่เกี่ยวข้องกับโฆษณา / ความยินยอม (ที่ประมวลผลโดยบุคคลที่สาม): อยู่ภายใต้นโยบายของผู้ให้บริการแต่ละรายและกฎหมายที่ใช้บังคับ

โดยหลักการแล้ว แอปจะไม่จัดเก็บข้อมูลหลักของผู้ใช้ไว้บนเซิร์ฟเวอร์ของผู้พัฒนา  
อย่างไรก็ตาม ไฟล์ที่ผู้ใช้บันทึกไว้บนพื้นที่จัดเก็บภายนอกโดยตรง จะถูกจัดการภายในสภาพแวดล้อมของผู้ใช้เอง

## 5. ขั้นตอนและวิธีการลบข้อมูลส่วนบุคคล

เมื่อวัตถุประสงค์ของการประมวลผลเสร็จสมบูรณ์แล้ว หรือเมื่อผู้ใช้ร้องขอให้ลบ แอปจะลบข้อมูลที่เกี่ยวข้อง หรือประมวลผลข้อมูลดังกล่าวเพื่อไม่ให้อ้างอิงได้อีก ดังนี้

### 5-1) ขั้นตอนการลบ

- เมื่อผู้ใช้ลบบันทึกของบุคคลแต่ละราย โฟลเดอร์ รูปภาพ ข้อมูลสำรอง เป็นต้น โดยตรง ข้อมูลดังกล่าวจะถือว่าเป็นข้อมูลที่ต้องถูกลบทันที
- เมื่อผู้ใช้ลบแอปหรือล้างข้อมูลแอปจากการตั้งค่าอุปกรณ์ ข้อมูลที่จัดเก็บอยู่ในพื้นที่จัดเก็บภายในของแอปจะถูกลบตามขั้นตอนการลบของระบบปฏิบัติการ
- ไฟล์ชั่วคราวจะเข้าสู่กระบวนการล้างหลังจากงานที่เกี่ยวข้องสิ้นสุดลง และข้อมูลแคชบางส่วนอาจยังคงอยู่ระยะหนึ่ง ขึ้นอยู่กับนโยบายของระบบปฏิบัติการ

### 5-2) วิธีการลบ

- ข้อมูล SQLite: ลบบันทึกที่เกี่ยวข้อง
- การตั้งค่าแอป (`SharedPreferences`): ลบคีย์ที่เกี่ยวข้องหรือการตั้งค่าทั้งหมด
- ค่าที่อยู่ใน `flutter_secure_storage`: ลบรายการจัดเก็บที่ปลอดภัยที่เกี่ยวข้อง
- ไฟล์ภายในแอป (รูปภาพที่เข้ารหัส ไฟล์ชั่วคราว เป็นต้น): ลบไฟล์ที่เกี่ยวข้อง
- ไฟล์ PDF / ไฟล์สำรองที่ผู้ใช้บันทึกลงในพื้นที่จัดเก็บภายนอกโดยตรง: แอปจะไม่ลบให้อัตโนมัติ และผู้ใช้ต้องลบเองโดยตรง

เว้นแต่กฎหมายที่ใช้บังคับจะกำหนดไว้เป็นอย่างอื่น ผู้พัฒนาจะไม่จัดเก็บข้อมูลหลักของผู้ใช้แยกต่างหากไว้บนเซิร์ฟเวอร์ของผู้พัฒนา

## 6. การให้ข้อมูลแก่บุคคลที่สาม การมอบหมายการประมวลผล และการโอนข้อมูลข้ามพรมแดน

แอปอาจใช้บริการของ Google เพื่อการจัดการโฆษณาและความยินยอม

| รายการ | รายละเอียด |
|---|---|
| **ผู้รับ / ผู้รับมอบหมาย** | Google LLC และบริษัทในเครือ (ผู้ดำเนินการ AdMob / UMP) |
| **ประเทศที่โอนข้อมูลไป** | สหรัฐอเมริกา และภูมิภาคที่มีการดำเนินโครงสร้างพื้นฐานของ Google |
| **ช่วงเวลาที่มีการโอนข้อมูล** | อย่างต่อเนื่องระหว่างการขอโฆษณา การตรวจสอบสถานะความยินยอม การเริ่มต้น SDK และการทำงาน |
| **วิธีการโอนข้อมูล** | การส่งผ่านการสื่อสารเครือข่ายระหว่างแอปและเซิร์ฟเวอร์ของบุคคลที่สาม |
| **ฐานทางกฎหมายสำหรับการโอนข้อมูลข้ามพรมแดน** | ดำเนินการภายในขอบเขตที่จำเป็นต่อการให้บริการภายใต้ฐานทางกฎหมายที่ใช้บังคับ หรือหากจำเป็น อาจอาศัยความยินยอมของเจ้าของข้อมูล |
| **วัตถุประสงค์** | การแสดงโฆษณา การวัดผลโฆษณา การจัดการความยินยอม การป้องกันการฉ้อโกง และการปฏิบัติตามนโยบาย / กฎหมาย |
| **ประเภทของข้อมูล (ตัวอย่าง)** | ตัวระบุโฆษณา (AAID / IDFA), ข้อมูล IP / เครือข่าย, ข้อมูลอุปกรณ์ / แอป, ข้อมูลการโต้ตอบกับโฆษณา, สถานะความยินยอม |
| **ระยะเวลาการเก็บรักษา** | เป็นไปตามนโยบายของ Google และกฎหมายที่ใช้บังคับ |
| **ผลกระทบหากปฏิเสธ** | โฆษณาแบบปรับให้เหมาะกับบุคคลอาจถูกจำกัด อาจมีการแสดงโฆษณาแบบไม่ปรับให้เหมาะกับบุคคล หรือคุณสมบัติบางอย่างที่เกี่ยวข้องกับโฆษณาอาจถูกจำกัด |

ผู้พัฒนาไม่ได้เก็บรวบรวมหรือขายข้อมูลหลักของบันทึกบุคคลในแอปผ่านเซิร์ฟเวอร์ของตนเอง

## 7. ข้อมูลเกี่ยวกับสิทธิ์ที่ใช้งาน
