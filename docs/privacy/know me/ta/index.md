## 1. நோக்கம் மற்றும் வரம்பு

`know_me` என்பது, பயனர்கள் மனிதர்களைப் பற்றிய தகவல்களை பதிவு செய்து நிர்வகிக்க உதவுவதற்காக வடிவமைக்கப்பட்ட பயன்பாடாகும்; தேவையானபோது, அத்தகவல்களை காப்புப்பிரதி எடுக்கவும், மீட்டெடுக்கவும், PDF கோப்புகளாகப் பகிரவும் இது உதவுகிறது.

இதன் முக்கிய அம்சங்கள் பின்வருமாறு:

- நபர் சார்ந்த தகவல்களைச் சேமித்தல் (உதாரணமாக பெயர், அடையாள உரை, குறிப்புகள், தன்மை அம்சங்கள், நாடு, பாலினம், தொடர்பு தகவல் முதலியவை)
- கோப்புறை வகைப்படுத்தல், தேடல் மற்றும் இணைத்தல் செயல்பாடுகள்
- புகைப்படங்களை இணைத்தல் மற்றும் அவற்றின் விளக்கங்களை நிர்வகித்தல்
- காப்புப்பிரதிகளை (`.knm`) ஏற்றுமதி மற்றும் இறக்குமதி செய்தல்
- PDF ஏற்றுமதி
- பயன்பாட்டு பூட்டு (கடவுச்சொல் / வடிவமைப்பு)
- விளம்பர மற்றும் ஒப்புதல் நிர்வாகம் (AdMob / UMP)

இந்த பயன்பாட்டிற்கு தனியான கணக்கு பதிவு தேவையில்லை; பயன்பாட்டின் முக்கிய பயனர் தரவு பொதுவாக பயனரின் சாதனத்தில் உள்ளூராகவே சேமிக்கப்படுகிறது.  
ஆனால், விளம்பர மற்றும் ஒப்புதல் நிர்வாகத்திற்காக சேர்க்கப்பட்டுள்ள சில மூன்றாம் தரப்பு SDK-கள் சில தகவல்களை செயலாக்கக்கூடும்.

## 2. செயலாக்கப்படும் தனிப்பட்ட தகவல்களின் வகைகள்

### 2-1) பயனர் நேரடியாக உள்ளிடும் தகவல்

பயனர் நேரடியாக உள்ளிடும்போது மட்டுமே பின்வரும் தகவல்கள் சேமிக்கப்படும்:

- பெயர்
- அடையாளப்படுத்தும் உரை (குறிப்பு உரையாகப் பயன்படுத்தப்படும் தோற்றம் / அம்சங்கள் போன்றவை)
- குறிப்புகள்
- தன்மை அம்சங்கள், நாடு, பாலினம்
- தொலைபேசி எண்
- தோன்றிய நேரம் / சந்தித்த நேரம் தொடர்பான உரை
- தளம் / இணையதள தகவல்
- கோப்புறை பெயர் / நிறம்
- பட விளக்கம் (caption)

### 2-2) சாதனத்தில் தேர்ந்தெடுக்கப்படும் கோப்புகள்

- புகைப்படங்களை இணைக்கும் போது பயனர் தேர்ந்தெடுக்கும் படக் கோப்புகள்
- காப்புப்பிரதிகளை இறக்குமதி செய்யும் போது பயனர் தேர்ந்தெடுக்கும் `.knm` காப்புப்பிரதி கோப்புகள்
- PDF / காப்புப்பிரதிகளை ஏற்றுமதி செய்யும் போது பயனர் தேர்ந்தெடுக்கும் சேமிப்பு பாதைகள் மற்றும் சேமிக்கப்பட்ட கோப்புகள்

### 2-3) பயன்பாட்டிற்குள் உள்ளூராக சேமிக்கப்படும் தரவு

பயன்பாட்டு அம்சங்களை வழங்குவதற்காக பின்வரும் தரவு பயனரின் சாதனத்தில் சேமிக்கப்படலாம்:

- SQLite DB (`people_note.db`): நபர்கள் / கோப்புறைகள் / தளங்கள் / இணையதளங்கள் / படங்கள் தொடர்பான மெட்டாடேட்டா
- படக் கோப்புகள்: குறியாக்கம் செய்யப்பட்டு பயன்பாட்டின் ஆவணக் கோப்புறையில் சேமிக்கப்படும் (`.enc`)
- பயன்பாட்டு அமைப்புகள் (`SharedPreferences`): தோற்றம், வரிசைப்படுத்தல், தனியுரிமை / விளம்பர விருப்பங்கள், PDF மறைப்பு விருப்பங்கள், பயன்பாட்டு பூட்டு கொள்கைகள் முதலியவை
- பயன்பாட்டு பூட்டு தகவல்: கடவுச்சொற்கள் / வடிவங்களுக்கு ஹாஷ் மதிப்புகள் மற்றும் salt மதிப்புகள் (`SharedPreferences`)
- உள்ளூர் குறியாக்க விசைகள்: `flutter_secure_storage`-ல் சேமிக்கப்படும்
- தற்காலிக கோப்புகள்: படங்களை மறைகுறியீடு நீக்கும் முன்னோட்டங்கள், இறக்குமதி / ஏற்றுமதி cache கோப்புகள் முதலியவை (தற்காலிக கோப்புறை)

### 2-4) விளம்பர மற்றும் ஒப்புதல் நிர்வாகத்தின் போது தானாக செயலாக்கப்படக்கூடிய தகவல்

விளம்பர அல்லது ஒப்புதல் நிர்வாக அம்சங்கள் இயக்கப்பட்டிருக்கும்போது, Google LLC மற்றும் தொடர்புடைய கூட்டாளர்களின் SDK-கள் (உதாரணமாக AdMob மற்றும் UMP) பின்வரும் தகவல்களை தானாக செயலாக்கக்கூடும்:

- விளம்பர அடையாளங்கள் (AAID / IDFA முதலியவை)
- IP முகவரி மற்றும் வலையமைப்பு தகவல்
- சாதன தகவல் (OS பதிப்பு, சாதன மாடல், பயன்பாட்டு பதிப்பு முதலியவை)
- விளம்பர தொடர்பு தகவல் (காண்பிப்புகள், கிளிக்குகள் முதலியவை)
- ஒப்புதல் நிலை மற்றும் தனியுரிமை தேர்வு தகவல்
- கண்டறிதல், செயல்திறன் மற்றும் பாதுகாப்பு தொடர்பான தகவல்

பயன்பாட்டின் முக்கிய பயனர் பதிவுகள் பொதுவாக உருவாக்குநரின் சேவையகத்திற்கு பதிவேற்றப்படுவதில்லை; ஆனால், விளம்பர / ஒப்புதல் அம்சங்கள் பயன்படுத்தப்படும் போது மேலே கூறப்பட்ட தகவல்களில் சில மூன்றாம் தரப்பு சேவைகளுக்கு அனுப்பப்படலாம்.

## 3. தனிப்பட்ட தகவல் செயலாக்கத்தின் நோக்கங்கள்

பயன்பாடு, தனிப்பட்ட தகவல் அல்லது தொடர்புடைய தகவல்களை பின்வரும் நோக்கங்களுக்காக செயலாக்குகிறது:

- தொடர்புகள் / குறிப்புகளை மையமாகக் கொண்ட நபர் தொடர்பான தகவல்களை பதிவு செய்தல் மற்றும் உலாவல்
- கோப்புறை வகைப்படுத்தல், தேடல், இணைத்தல் போன்ற ஒழுங்குபடுத்தும் அம்சங்களை வழங்குதல்
- புகைப்படங்களை இணைத்தல் மற்றும் காட்சிப்படுத்துதல்
- காப்புப்பிரதி / மீட்பு மற்றும் PDF ஏற்றுமதி போன்ற பயனர் கோரிய செயல்பாடுகளை நிறைவேற்றுதல்
- பயன்பாட்டு பூட்டு பாதுகாப்பு அம்சங்களை வழங்குதல்
- விளம்பரங்களை வழங்குதல், ஒப்புதலை நிர்வகித்தல், மோசடி செயல்பாடுகளைத் தடுப்பது மற்றும் சட்டப் பொறுப்புகளைப் பின்பற்றுதல்

## 4. தனிப்பட்ட தகவல்களின் சேமிப்பு மற்றும் பதில்நிறுத்த காலம்

- பயன்பாட்டின் உள் தரவு (SQLite, உள்ளூர் அமைப்புகள், குறியாக்கம் செய்யப்பட்ட படங்கள்): பயன்பாடு நீக்கப்படும் வரை, பயன்பாட்டு தரவு அழிக்கப்படும் வரை, அல்லது பயனர் தரவை நேரடியாக நீக்கும் வரை பயனரின் சாதனத்தில் வைத்திருக்கும்
- தற்காலிக கோப்புகள்: தொடர்புடைய பணி முடிந்த பிறகு நீக்கப்படும் அல்லது இயக்க முறைமையின் cache கொள்கைக்கு ஏற்ப சுத்தம் செய்யப்படும்
- பயனர் ஏற்றுமதி செய்த கோப்புகள் (PDF-கள், காப்புப்பிரதி கோப்புகள்): பயனர் தேர்ந்தெடுத்த சேமிப்பு இடத்தில் நிலைத்திருக்கக்கூடும்; அவற்றை பயனர் நேரடியாக நீக்க வேண்டும்
- விளம்பர / ஒப்புதல் தொடர்பான தரவு (மூன்றாம் தரப்பால் செயலாக்கப்படும்): ஒவ்வொரு சேவை வழங்குநரின் கொள்கைகள் மற்றும் பொருந்தும் சட்டங்களுக்கு உட்பட்டது

அடிப்படையாக, பயன்பாடு முக்கிய பயனர் பதிவுகளை உருவாக்குநரின் சேவையகத்தில் சேமிப்பதில்லை.  
ஆனால், பயனர் வெளிப்புற சேமிப்பகத்தில் நேரடியாக சேமிக்கும் கோப்புகள், பயனரின் சொந்த சூழலிலேயே நிர்வகிக்கப்படும்.

## 5. தனிப்பட்ட தகவல்களை அழிக்கும் நடைமுறைகள் மற்றும் முறைகள்

### 5-1) அழிப்பு நடைமுறைகள்
