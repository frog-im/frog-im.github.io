## 1. 目的および適用範囲

`know_me` は、ユーザーが人物に関する情報を記録・管理し、必要に応じてバックアップ、復元、およびPDFファイルとして共有できるよう支援するためのアプリです。

主な機能は次のとおりです。

- 人物ごとの情報（氏名、識別用テキスト、メモ、性格傾向、国、性別、連絡先情報など）の保存
- フォルダ分類、検索、および統合機能
- 写真の添付および説明の管理
- バックアップ（`.knm`）のエクスポートおよびインポート
- PDFのエクスポート
- アプリロック（パスワード / パターン）
- 広告および同意管理（AdMob / UMP）

本アプリでは、別途アカウント登録は必要ありません。また、本アプリの主要なユーザーデータは、通常、ユーザーの端末内にローカル保存されます。  
ただし、広告および同意管理のために組み込まれた一部の第三者SDKが、一定の情報を処理する場合があります。

## 2. 取り扱う個人情報の項目

### 2-1) ユーザーが直接入力する情報

以下の情報は、ユーザーが直接入力した場合にのみ保存されます。

- 氏名
- 識別用テキスト（外見・特徴などのメモ用テキスト）
- メモ
- 性格傾向、国、性別
- 電話番号
- 登場時刻 / 会った時点に関するテキスト
- プラットフォーム / サイト情報
- フォルダ名 / 色
- 画像の説明（caption）

### 2-2) 端末上で選択されるファイル

- 写真添付時にユーザーが選択した画像ファイル
- バックアップ取り込み時にユーザーが選択した `.knm` バックアップファイル
- PDF / バックアップのエクスポート時にユーザーが選択した保存先パスおよび保存ファイル

### 2-3) アプリ内でローカル保存されるデータ

アプリ機能の提供のため、以下のデータがユーザーの端末に保存される場合があります。

- SQLite DB（`people_note.db`）: 人物 / フォルダ / プラットフォーム / サイト / 画像に関するメタデータ
- 画像ファイル: アプリのドキュメントフォルダ内に暗号化して保存（`.enc`）
- アプリ設定（`SharedPreferences`）: テーマ、並び順、プライバシー / 広告オプション、PDFマスキングオプション、アプリロック方針など
- アプリロック情報: パスワード / パターンのハッシュ値およびソルト（`SharedPreferences`）
- ローカル暗号鍵: `flutter_secure_storage` に保存
- 一時ファイル: 画像復号プレビュー、インポート / エクスポート時のキャッシュファイルなど（テンポラリフォルダ）

### 2-4) 広告および同意管理の過程で自動的に処理される場合がある情報

広告または同意管理機能が有効な場合、Google LLC および関連パートナーのSDK（AdMob、UMPなど）は、以下の情報を自動的に処理することがあります。

- 広告識別子（AAID / IDFA など）
- IPアドレスおよびネットワーク情報
- 端末情報（OSバージョン、端末モデル、アプリバージョンなど）
- 広告との相互作用情報（表示、クリックなど）
- 同意状態およびプライバシー選択情報
- 診断、パフォーマンス、およびセキュリティ関連情報

本アプリの主要なユーザー記録は、通常、開発者のサーバーにアップロードされませんが、広告 / 同意機能の利用中は、上記情報の一部が第三者サービスへ送信される場合があります。

## 3. 個人情報の処理目的

本アプリは、以下の目的のために個人情報または関連情報を取り扱います。

- 連絡先 / メモを中心とした人物情報の記録および閲覧
- フォルダ分類、検索、統合などの整理機能の提供
- 写真の添付および表示
- バックアップ / 復元、PDFエクスポートなど、ユーザーが要求した機能の実行
- アプリロックによるセキュリティ機能の提供
- 広告の提供、同意管理、不正行為の防止、および法的義務の遵守

## 4. 個人情報の保管期間および保存期間

- アプリ内部データ（SQLite、ローカル設定、暗号化画像）: アプリの削除、アプリデータの消去、またはユーザーによる直接削除まで、ユーザーの端末上に保存されます
- 一時ファイル: 関連処理の完了後に削除されるか、OSのキャッシュポリシーに従って整理されます
- ユーザーがエクスポートしたファイル（PDF、バックアップファイル）: ユーザーが選択した保存先に残る場合があり、ユーザー自身で削除する必要があります
- 広告 / 同意関連データ（第三者により処理されるもの）: 各サービス提供者のポリシーおよび適用法令に従います

原則として、本アプリは主要なユーザー記録を開発者のサーバー上に保存しません。  
ただし、ユーザーが外部ストレージに直接保存したファイルは、ユーザー自身の環境で管理されます。

## 5. 個人情報の削除手続および削除方法

処理目的が達成された場合、またはユーザーから削除の依頼があった場合、本アプリは、次のとおり、該当情報を削除するか、参照されない状態に処理します。

### 5-1) 削除手続

- ユーザーが人物記録、フォルダ、画像、バックアップデータなどを直接削除した場合、当該データは直ちに削除対象として取り扱われます。
- ユーザーがアプリを削除した場合、または端末設定からアプリデータを消去した場合、アプリ内部ストレージ領域に保存されたデータは、OSの削除手続に従って削除されます。
- 一時ファイルは、関連処理の終了後にクリーンアップ対象となり、一部のキャッシュデータは、OSのポリシーにより一定期間残ることがあります。

### 5-2) 削除方法

- SQLiteデータ: 該当レコードの削除
- アプリ設定（`SharedPreferences`）: 該当キーまたはすべての設定の削除
- `flutter_secure_storage` の値: 該当するセキュアストレージ項目の削除
- アプリ内部ファイル（暗号化画像、一時ファイルなど）: 該当ファイルの削除
- ユーザーが外部ストレージに直接保存したPDF / バックアップファイル: アプリが自動的に削除することはなく、ユーザー自身で削除する必要があります

適用法令により別途要求される場合を除き、開発者は、主要なユーザー記録を開発者のサーバーに別途保存しません。

本アプリは、以下の権限を使用する場合があります。
