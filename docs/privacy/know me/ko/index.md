## 1. 목적 및 적용 범위

`know_me`는 사용자가 사람 정보를 기록·관리하고, 필요 시 백업·복원·PDF 공유를 할 수 있도록 돕는 앱입니다.

주요 기능은 다음과 같습니다.

- 사람별 정보(이름, 식별 텍스트, 메모, 성향, 국가, 성별, 연락처 등) 저장
- 폴더 분류, 검색, 병합
- 사진 첨부 및 설명 관리
- 백업(`.knm`) 내보내기 및 가져오기
- PDF 내보내기
- 앱 잠금(비밀번호/패턴)
- 광고 및 동의 관리(AdMob/UMP)

앱은 별도 회원가입을 요구하지 않으며, 앱의 핵심 사용자 데이터는 기본적으로 사용자 기기에 로컬 저장됩니다.  
다만 광고 및 동의 관리 기능을 위해 포함된 제3자 SDK가 일부 정보를 처리할 수 있습니다.

## 2. 처리하는 개인정보 항목

### 2-1) 사용자가 직접 입력하는 정보

다음 정보는 사용자가 직접 입력할 때에만 저장됩니다.

- 이름
- 식별 텍스트(외모/특징 등 메모용 텍스트)
- 메모
- 성향, 국가, 성별
- 전화번호
- 등장 시간/만난 시점 관련 텍스트
- 플랫폼/사이트 정보
- 폴더 이름/색상
- 이미지 설명(caption)

### 2-2) 기기에서 선택한 파일

- 이미지 첨부 시 사용자가 선택한 이미지 파일
- 백업 가져오기 시 사용자가 선택한 `.knm` 백업 파일
- PDF/백업 저장 시 사용자가 선택한 저장 경로 및 저장 파일

### 2-3) 앱 내 로컬 저장 데이터

앱 기능 제공을 위해 다음 데이터가 사용자 기기에 저장될 수 있습니다.

- SQLite DB(`people_note.db`): 사람/폴더/플랫폼/사이트/이미지 메타데이터
- 이미지 파일: 앱 문서 폴더 내부에 암호화 저장(`.enc`)
- 앱 설정값(`SharedPreferences`): 테마, 정렬, 프라이버시/광고 옵션, PDF 마스킹 옵션, 앱 잠금 정책 등
- 앱 잠금 정보: 비밀번호/패턴의 해시값 및 salt (`SharedPreferences`)
- 로컬 암호화 키: `flutter_secure_storage`에 저장
- 임시 파일: 이미지 복호화 미리보기, 가져오기/내보내기 과정 캐시 등(임시 폴더)

### 2-4) 광고 및 동의 처리 과정에서 자동으로 처리될 수 있는 정보

광고 또는 동의 관리 기능이 활성화되는 경우, Google LLC 및 관련 파트너의 SDK(예: AdMob, UMP)가 다음 정보를 자동으로 처리할 수 있습니다.

- 광고 식별자(AAID/IDFA 등)
- IP 주소 및 네트워크 정보
- 기기 정보(OS 버전, 기기 모델, 앱 버전 등)
- 광고 상호작용 정보(노출, 클릭 등)
- 동의 상태 및 프라이버시 선택 정보
- 진단, 성능, 보안 관련 정보

앱의 핵심 사용자 기록은 기본적으로 개발자 서버에 업로드되지 않지만, 광고/동의 기능 이용 중에는 위 정보의 일부가 제3자 서비스로 전송될 수 있습니다.

- 앱 내부 데이터(SQLite, 로컬 설정, 암호화된 이미지): 앱 삭제, 앱 데이터 삭제 또는 사용자가 직접 삭제하기 전까지 사용자 기기에 보관

## 5. 개인정보의 파기절차 및 파기방법

앱은 처리 목적이 달성되었거나 사용자가 삭제를 요청한 경우, 다음과 같은 방법으로 관련 정보를 파기하거나 더 이상 참조하지 않도록 처리합니다.

### 5-1) 파기절차

- 사용자가 개별 사람 정보, 폴더, 이미지, 백업 데이터 등을 직접 삭제하는 경우 해당 데이터는 즉시 삭제 대상으로 처리됩니다.
- 사용자가 앱을 삭제하거나 기기 설정에서 앱 데이터를 삭제하는 경우, 앱 내부 저장 영역에 있던 데이터는 운영체제의 삭제 절차에 따라 제거됩니다.
- 임시 파일은 작업 종료 후 정리 대상이 되며, 일부 캐시는 운영체제 정책에 따라 일정 시점까지 남아 있을 수 있습니다.

### 5-2) 파기방법

- SQLite 데이터: 관련 레코드 삭제
- 앱 설정값(`SharedPreferences`): 해당 키 또는 전체 설정값 삭제
- `flutter_secure_storage` 저장값: 관련 보안 저장 항목 삭제
- 앱 내부 파일(암호화 이미지, 임시 파일 등): 해당 파일 삭제
- 사용자가 외부 저장소에 직접 저장한 PDF/백업 파일: 앱이 자동 삭제하지 않으며, 사용자가 직접 삭제해야 함

앱은 별도 법령상 보존 의무가 없는 한, 개발자 서버에 사용자 핵심 기록을 별도 보관하지 않습니다.

## 7. 권한 사용 안내

앱은 다음 권한을 사용할 수 있습니다.

- `INTERNET`: 광고 SDK 통신 및 관련 네트워크 기능

권한은 해당 기능 수행에 필요한 범위 내에서만 사용됩니다.
