## 1. Цель и сфера применения

`know_me` — это приложение, предназначенное для того, чтобы помогать пользователям записывать и управлять информацией о людях, а при необходимости выполнять резервное копирование, восстановление и обмен такой информацией в виде PDF-файлов.

Основные функции приложения включают:

- Хранение информации о конкретных людях (например, имя, идентифицирующий текст, заметки, черты характера, страна, пол, контактная информация и т. д.)
- Классификация по папкам, поиск и функции объединения
- Прикрепление фотографий и управление описаниями
- Экспорт и импорт резервных копий (`.knm`)
- Экспорт PDF
- Блокировка приложения (пароль / графический ключ)
- Управление рекламой и согласием (AdMob / UMP)

Приложение не требует отдельной регистрации учётной записи, и основные пользовательские данные приложения, как правило, хранятся локально на устройстве пользователя.  
Однако некоторые сторонние SDK, включённые для управления рекламой и согласием, могут обрабатывать определённую информацию.

## 2. Категории обрабатываемых персональных данных

### 2-1) Информация, вводимая пользователем напрямую

Следующая информация сохраняется только в том случае, если пользователь вводит её напрямую:

- Имя
- Идентифицирующий текст (например, описание внешности / особенностей, используемое как текст заметки)
- Заметки
- Черты характера, страна, пол
- Номер телефона
- Текст, связанный со временем появления / временем встречи
- Информация о платформе / сайте
- Название / цвет папки
- Описание изображения (caption)

### 2-2) Файлы, выбранные на устройстве

- Файлы изображений, выбранные пользователем при прикреплении фотографий
- Файлы резервных копий `.knm`, выбранные пользователем при импорте резервных копий
- Пути сохранения и сохранённые файлы, выбранные пользователем при экспорте PDF / резервных копий

### 2-3) Данные, хранящиеся локально в приложении

Следующие данные могут храниться на устройстве пользователя для предоставления функций приложения:

- База данных SQLite (`people_note.db`): метаданные, относящиеся к людям / папкам / платформам / сайтам / изображениям
- Файлы изображений: зашифрованы и хранятся в папке документов приложения (`.enc`)
- Настройки приложения (`SharedPreferences`): тема, сортировка, параметры конфиденциальности / рекламы, параметры маскирования PDF, политики блокировки приложения и т. д.
- Информация о блокировке приложения: хеш-значения и salt для паролей / графических ключей (`SharedPreferences`)
- Локальные ключи шифрования: хранятся в `flutter_secure_storage`
- Временные файлы: предварительный просмотр расшифровки изображений, кэш-файлы импорта / экспорта и т. д. (временная папка)

### 2-4) Информация, которая может обрабатываться автоматически при работе рекламы и управлении согласием

Когда функции рекламы или управления согласием включены, SDK компании Google LLC и связанных партнёров (например, AdMob и UMP) могут автоматически обрабатывать следующую информацию:

- Рекламные идентификаторы (AAID / IDFA и т. д.)
- IP-адрес и сетевую информацию
- Информацию об устройстве (версия ОС, модель устройства, версия приложения и т. д.)
- Информацию о взаимодействии с рекламой (показы, клики и т. д.)
- Статус согласия и информацию о настройках конфиденциальности
- Информацию, связанную с диагностикой, производительностью и безопасностью

Основные пользовательские записи приложения, как правило, не загружаются на сервер разработчика, однако часть вышеуказанной информации может передаваться сторонним сервисам при использовании функций рекламы / согласия.

- Выполнение функций, запрошенных пользователем, таких как резервное копирование / восстановление и экспорт PDF

## 4. Срок хранения и хранения персональных данных

- Внутренние данные приложения (SQLite, локальные настройки, зашифрованные изображения): хранятся на устройстве пользователя до удаления приложения, очистки данных приложения или прямого удаления данных пользователем
- Временные файлы: удаляются после завершения соответствующей задачи или очищаются в соответствии с политикой кэша операционной системы
- Файлы, экспортированные пользователем (PDF, файлы резервных копий): могут оставаться в месте хранения, выбранном пользователем, и должны удаляться пользователем самостоятельно
- Данные, связанные с рекламой / согласием (обрабатываемые третьими лицами): регулируются политиками каждого поставщика услуг и применимым законодательством

В принципе, приложение не хранит основные пользовательские записи на сервере разработчика.  
Однако файлы, которые пользователь напрямую сохраняет во внешнем хранилище, управляются в собственной среде пользователя.

## 5. Процедуры и способы удаления персональных данных

Когда цель обработки достигнута либо когда пользователь запрашивает удаление, приложение уничтожает соответствующую информацию или обрабатывает её таким образом, чтобы к ней больше не обращались, следующим образом.

### 5-1) Процедуры удаления

- Когда пользователь напрямую удаляет отдельные записи о людях, папки, изображения, данные резервных копий и т. д., такие данные считаются подлежащими немедленному удалению.
- Когда пользователь удаляет приложение или очищает данные приложения в настройках устройства, данные, хранящиеся во внутренней области хранения приложения, удаляются в соответствии с процедурами удаления операционной системы.
- Временные файлы подлежат очистке после завершения соответствующей задачи, и часть кэшированных данных может сохраняться в течение определённого времени в зависимости от политики операционной системы.

### 5-2) Способы удаления

- Данные SQLite: удаление соответствующих записей
- Настройки приложения (`SharedPreferences`): удаление соответствующего ключа или всех настроек
- Значения в `flutter_secure_storage`: удаление соответствующих элементов защищённого хранилища
- Внутренние файлы приложения (зашифрованные изображения, временные файлы и т. д.): удаление соответствующих файлов
- PDF / файлы резервных копий, напрямую сохранённые пользователем во внешнем хранилище: не удаляются приложением автоматически и должны удаляться пользователем самостоятельно

Если иное не требуется применимым законодательством, разработчик не хранит основные пользовательские записи отдельно на сервере разработчика.
