# 국가 간 데이터 이전 안내

시행일: 2026-07-08  
최종 수정일: 2026-07-08

다음한걸음은 이용자가 작성한 메모, 이유, 다음 행동, 폴더, PIN 또는 생체 인증 정보를 개발자 운영 서버로 전송하지 않습니다.

다만 광고 및 광고 개인정보 선택 기능을 사용하거나, 이용자가 백업 파일 저장 위치 또는 공유 대상으로 해외 서비스나 국외 서버 기반 서비스를 직접 선택하면 일부 정보가 이용자의 국가 또는 지역 밖에서 처리될 수 있습니다.

## 1. Google 광고 및 동의 서비스

| 항목 | 내용 |
|---|---|
| **이전받는 자** | Google LLC, Google 계열사, Google이 광고·동의 관리·측정·보안·서비스 운영을 위해 사용하는 처리업체 및 설정된 광고 기술 제공업체 |
| **연락 및 정책** | [Google 개인정보처리방침](https://policies.google.com/privacy), [Google 광고 기술 안내](https://policies.google.com/technologies/ads) |
| **이전 국가** | 미국 및 Google 또는 관련 처리업체의 서버와 인프라가 위치한 국가. 실제 처리 위치는 네트워크, 서비스 구성 및 처리업체에 따라 달라질 수 있습니다. |
| **이전 시기** | 앱이 동의 정보를 갱신하거나 개인정보 선택 화면을 표시하거나 광고를 요청·표시·측정할 때 |
| **이전 방법** | 앱 또는 Google SDK와 외부 서버 사이의 암호화된 인터넷 통신 |
| **이전될 수 있는 정보** | 광고 식별자, 앱 인스턴스 또는 기기 식별자, IP 주소, 대략적인 위치, 기기 모델, 운영체제, 앱 버전, 언어, 네트워크 정보, 광고 요청·노출·클릭·상호작용·진단 정보, 동의 상태와 개인정보 선택 |
| **목적** | 광고 제공, 비개인 맞춤 광고, 빈도 제한, 측정, 분석, 부정 사용 방지, 동의 및 개인정보 선택 관리, 서비스 보안, 정책과 법적 의무 준수 |
| **보유 기간** | Google과 각 처리업체의 개인정보 처리방침, 계약상 의무 및 적용 법령에 따른 기간 |

개발자는 이용자가 작성한 메모 내용, 폴더 정보, PIN 또는 백업 파일 내용을 Google 광고 서비스에 제공하지 않습니다.

## 2. 이용자가 선택한 외부 저장 또는 공유 서비스

다음한걸음의 백업 파일과 리뷰 이미지는 이용자가 직접 선택한 위치 또는 앱으로 전달됩니다. 이용자가 Google Drive, iCloud Drive, OneDrive, Dropbox, 메신저, 메일 앱 또는 그 밖의 동기화·문서·공유 서비스를 저장 또는 공유 대상으로 선택하면 파일과 부가 정보가 국외 서버로 이전될 수 있습니다.

| 항목 | 내용 |
|---|---|
| **이전받는 자** | 이용자가 직접 선택한 파일·문서·클라우드 저장 서비스 제공자, 공유 앱 제공자와 그 처리업체 |
| **이전 국가** | 선택한 제공자의 개인정보 처리방침과 서버 운영 지역에 따름 |
| **이전 시기 및 방법** | 이용자가 해당 서비스를 저장 위치나 공유 대상으로 선택하고 백업 파일을 생성·복원·공유하거나 리뷰 이미지를 공유할 때, 운영체제 또는 제공자의 앱을 통한 네트워크 전송 |
| **이전 정보** | JSON 백업 파일, 리뷰 이미지, 이용자가 지정한 파일 이름, 저장·수정 시각 및 제공자가 자동 생성하는 계정·기기·네트워크 정보 |
| **목적** | 이용자가 요청한 파일 저장, 동기화, 공유, 복구 및 기기 간 이용 |
| **보유 기간** | 이용자가 파일을 삭제할 때까지 또는 선택한 제공자의 정책에 따른 기간 |

외부 저장 또는 공유 서비스는 이용자가 직접 선택하며 개발자는 해당 서비스의 계정, 서버 또는 보유 기간을 통제하지 않습니다.

## 3. 거부 방법과 영향

이용자는 다음 방법으로 국가 간 처리를 제한할 수 있습니다.

- 적용되는 경우 앱의 Google 광고 개인정보 선택 화면에서 동의를 변경
- 비개인 맞춤 광고 또는 제한적 데이터 처리 선택 사용
- 기기 설정에서 광고 식별자를 삭제·재설정하거나 광고 맞춤 설정 제한
- 네트워크 연결을 끄거나 앱 사용을 중단하고 제거
- 해외 클라우드 서비스 대신 기기 내 로컬 저장 위치를 백업 대상으로 선택
- 외부 저장 서비스나 공유 앱에서 기존 백업 파일 또는 리뷰 이미지 삭제

광고 관련 처리를 거부하면 개인 맞춤 광고가 제한되거나 비개인 맞춤·제한 광고가 표시되거나 광고 기능 일부가 제공되지 않을 수 있습니다. 외부 클라우드 저장이나 공유 서비스를 선택하지 않아도 앱의 핵심 로컬 기능은 사용할 수 있지만, 해당 서비스를 통한 동기화, 외부 저장, 외부 공유는 사용할 수 없습니다.

## 4. 보호 조치

Google은 자체 정책에 따라 전송 중 암호화와 국제 데이터 이전 관련 법적 체계를 적용한다고 설명합니다. Google은 전 세계 서버에서 정보를 처리할 수 있다고 고지하고 있습니다.

다음한걸음이 생성하는 백업 파일과 리뷰 이미지는 이용자의 선택에 따라 외부 서비스로 전달될 수 있습니다. 그러나 외부 제공자는 파일 자체와 파일명, 계정 및 네트워크 관련 정보를 처리할 수 있으므로 신뢰할 수 있는 제공자를 선택해야 합니다.
