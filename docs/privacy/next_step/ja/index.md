## 1. 目的および適用範囲

Next Step は、ユーザーが繰り返し発生する問題、原因、次の行動、実行記録を自分の端末内で整理し、振り返ることを支援するローカル中心の自己省察アプリです。

本アプリは会員登録やログインを必要としません。開発者は、メモ内容、フォルダ情報、バックアップファイル、PIN、生体認証情報、統計データを受信する開発者運営サーバーを保有していません。ただし、広告および広告プライバシー選択機能を提供するため、Google AdMob と Google User Messaging Platform（UMP）を使用することがあります。

## 2. 処理する情報

### 2-1. ユーザーが直接入力または作成するメモデータ

アプリは機能提供のため、端末上で次の情報を処理することがあります。

- ユーザーが作成した問題、理由、次の行動、実行メモ
- 感情、重要度、タグ、カテゴリ、完了状態
- メモの作成時刻、更新時刻、完了処理状態
- ユーザーが作成または変更したフォルダ名、色、親フォルダ情報
- レビュー画面、統計画面、マクロ実行、振り返りを構成するためのローカル計算結果

これらの情報は、アプリ機能の提供のためユーザーの端末上で処理されます。開発者が開発者運営サーバーへアップロードすることはありません。

### 2-2. 認証およびセキュリティ情報

アプリロック機能の提供のため、アプリは端末内の安全なストレージで次の情報を処理することがあります。

- アプリロックの使用有無
- PIN のハッシュおよび salt
- 生体認証の使用有無
- ロック関連の更新時刻などの設定情報

PIN の原文は保存されず、開発者に送信されません。生体認証は OS が実行し、アプリは指紋画像、顔画像、または生体認証テンプレートを収集せず、認証の成否のみを確認します。

### 2-3. ローカルバックアップ、復元および共有情報

ユーザーが直接エクスポート、復元、または共有を行う場合、アプリは次の情報を処理することがあります。

- メモとフォルダを含む JSON バックアップファイル
- バックアップファイル名、作成時刻、復元結果情報
- レビュー画像共有時に生成される画像ファイル
- ユーザーが選択したファイルパス、または OS が提供するドキュメント選択結果

バックアップファイルおよびレビュー画像は、ユーザーが直接エクスポートまたは共有する場合にのみ作成されます。開発者はこれらのファイルを開発者運営サーバーで受信しません。

### 2-4. 広告および同意手続きで自動処理される可能性がある情報

対応プラットフォームでは、アプリが Google AdMob および UMP を使用することがあります。Google および広告技術提供者は次の情報を処理することがあります。

- 広告 ID、アプリインスタンス ID、または端末関連 ID
- IP アドレスおよび IP アドレス等から推定されるおおよその位置情報
- 端末モデル、OS、アプリバージョン、言語、ネットワーク情報
- 広告リクエスト、表示、クリック、インタラクション、診断情報
- 広告同意状態および地域別プライバシー選択

これらの情報は、広告配信、非パーソナライズ広告、頻度制限、測定、不正利用防止、同意管理、セキュリティ、法的義務の遵守のために処理されることがあります。アプリは UMP 手続き後、広告リクエストが可能な状態になった場合にのみ広告をリクエストするよう実装されています。

Google による処理方法は、[Google プライバシーポリシー](https://policies.google.com/privacy)および[Google 広告技術ガイド](https://policies.google.com/technologies/ads)で確認できます。

## 3. 情報処理の目的

Next Step は次の目的で情報を処理します。

- メモ、原因、次の行動、感情、タグ、フォルダの保存および表示
- メモ完了状態と振り返りフローの管理
- レビュー、統計、繰り返し問題、残りの行動などのローカル分析結果の提供
- アプリロック、PIN、生体認証によるアクセス制御
- バックアップファイルの作成、復元、レビュー画像の共有
- 言語、テーマ、広告プライバシー選択などのアプリ設定の維持
- 広告配信、広告頻度管理、プライバシー選択の提供
- 不正利用防止、サービスセキュリティ、法的義務の遵守

## 4. 保存場所と保存期間

| 区分 | 保存場所および期間 | 削除方法 |
|---|---|---|
| メモ、フォルダ、完了状態などの主要データ | ユーザーが削除するまでアプリ専用ローカルストレージに保存 | アプリ内で削除、アプリデータ削除、アプリのアンインストール |
| アプリロック設定、PIN ハッシュ、生体認証設定 | 設定変更またはアプリデータ削除まで OS の安全なストレージに保存 | 関連機能の無効化、アプリデータ削除、アプリのアンインストール |
| バックアップファイル | ユーザーが選択した端末フォルダ、ドキュメントプロバイダ、外部保存場所にユーザーが削除するまで保存 | 該当するファイル管理アプリまたは保存サービスで削除 |
| レビュー画像 | 共有直前に一時生成され、OS またはユーザーが選択したアプリで処理 | アプリ終了、キャッシュ削除、共有アプリまたは保存場所で削除 |
| Google 広告関連情報 | Google および関連処理者のポリシーと法的義務に従って保持 | アプリまたは端末の広告設定変更、Google プライバシー設定の利用 |

OS、端末メーカー、ファイル提供者、クラウド保存サービスは、アプリデータやユーザー作成のバックアップファイルの別個のコピーを保管する場合があります。これらのコピーには各提供者のポリシーが適用されます。

## 5. 第三者提供、処理委託および販売

開発者は、メモ内容、PIN、またはアプリ内ローカルデータを販売せず、これらを開発者運営サーバーを通じて第三者へ提供しません。

広告または同意機能が動作する場合、Google LLC、Google 関連会社、広告技術提供者および関連処理者が第 2-4 項の情報を処理することがあります。詳細は別途[国際データ移転に関する通知](policy/)をご確認ください。

ユーザーがバックアップファイルの保存、ファイル選択、レビュー画像共有のために外部アプリやクラウドサービスを直接選択した場合、その提供者はユーザーの指示に従いファイルを処理することがあります。この場合、当該提供者のプライバシーポリシーとセキュリティ設定が適用され、開発者はユーザーが選択した外部サービスの処理方法を管理しません。

## 6. 国際データ移転

メモおよび主要アプリデータは開発者運営サーバーへ移転されません。ただし、広告および同意機能を利用する場合、Google と関連処理者が広告および同意関連情報を米国その他インフラ運用国で処理することがあります。

また、ユーザーがバックアップ保存先や共有先として海外クラウドサービスまたは国外サーバー型サービスを選択した場合、当該ファイルはユーザーの選択に従い国外サーバーへ転送または同期されることがあります。詳細は[国際データ移転に関する通知](policy/)をご確認ください。

## 7. 権限の使用

ユーザーが該当機能を使用する際、アプリは次の権限またはシステム機能を使用することがあります。

- **ファイル選択および保存:** バックアップファイルを選択または保存するため
- **生体認証:** アプリのロック解除または機密設定変更の再確認のため
- **インターネットおよびネットワーク状態:** AdMob 広告と UMP 同意情報をリクエストするため
- **広告 ID:** Google 広告機能を提供するため

権限を許可しない場合、該当機能のみが制限されることがあります。システムファイル選択機能を使用する場合、アプリのアクセス範囲は原則としてユーザーが選択した項目に限定されます。

## 8. セキュリティ対策と限界

現在の実装では次の対策を使用しています。

- メモとフォルダデータを端末のローカルストレージに保存
- PIN ハッシュと salt を安全なストレージに保存
- 対応端末で OS の生体認証を使用
- アプリロックの使用有無とセキュリティ設定を安全なストレージに保存
- ユーザーがバックアップファイルを直接作成、保存、復元できるように提供

いかなるセキュリティ方式もすべてのリスクを完全に排除することはできません。端末の紛失、マルウェア、OS の脆弱性、弱い PIN、ユーザーが直接共有したファイル、外部保存サービスのセキュリティ問題により情報が漏えいする可能性があります。

バックアップファイルやレビュー画像を外部アプリまたはクラウドサービスに保存または共有すると、その場所に別個のコピーが残る場合があります。機密情報が含まれているかどうかはユーザー自身で確認する必要があります。

## 9. ユーザーの権利と選択

ほとんどの情報はユーザーの端末上にのみ存在するため、開発者がリモートで閲覧、修正または削除することはできません。ユーザーは次の方法で情報を管理できます。

- アプリ内でメモ、フォルダ、完了記録を削除
- アプリロック、PIN、生体認証、言語、テーマ設定を変更
- アプリデータの削除またはアプリのアンインストール
- 作成したバックアップファイルや共有ファイルを保存場所から削除
- 適用される場合、アプリ内の Google 広告プライバシー選択画面で同意を変更
- 端末設定で広告 ID を削除・リセット、または広告パーソナライズを制限

開発者が保有する問い合わせメールなど、本人が直接提供した情報に関する請求は、下記連絡先へ送ることができます。法令上適用される場合、閲覧、訂正、削除、処理制限、同意撤回、監督機関への申立ての権利が認められることがあります。
