นโยบายความเป็นส่วนตัวฉบับนี้จัดทำขึ้นตามการพัฒนาและการใช้งานแอป QDiary ในปัจจุบัน โดย QDiary ให้บริการฟังก์ชันการเขียนไดอารี การสร้างและการทบทวนเควสต์ การเข้าสู่ระบบ การบันทึกข้อมูลบนคลาวด์แบบด้วยตนเอง การแสดงโฆษณา และการแจ้งเตือน และในกระบวนการดังกล่าวอาจมีการประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลที่อาจถือเป็นข้อมูลส่วนบุคคลเท่าที่จำเป็น

## 1. ฟังก์ชันที่ให้บริการ

QDiary ให้บริการฟังก์ชันดังต่อไปนี้

- เขียน แก้ไข และดูไดอารี
- จัดหมวดหมู่และดูผ่านปฏิทิน
- สร้างเควสต์ ทบทวนเควสต์ และจัดการการเสร็จสิ้นของเควสต์
- ล็อกแอปไดอารีภายในเครื่องและการเข้ารหัสภายในเครื่อง
- เข้าสู่ระบบด้วยอีเมล ยืนยันอีเมล เข้าสู่ระบบแบบไม่ระบุตัวตน (ผู้เยี่ยมชม) และรีเซ็ตรหัสผ่าน
- บันทึกและโหลดข้อมูลบนคลาวด์ที่ผู้ใช้เป็นผู้ดำเนินการเอง
- การแสดงโฆษณาและการจัดการตัวเลือกความเป็นส่วนตัวของโฆษณา
- การแจ้งเตือนเพื่อเตือนความจำเกี่ยวกับเควสต์

## 2. ประเภทของข้อมูลที่ประมวลผล

### 2-1. ข้อมูลที่ผู้ใช้กรอกโดยตรง

- ที่อยู่อีเมล
- รหัสผ่าน
- ชื่อเรื่อง เนื้อหา วันที่ หมวดหมู่ และระดับความยากของไดอารี
- คำตอบของเควสต์ เนื้อหาการทบทวน และข้อมูลเควสต์ที่เลือก
- ค่าที่เลือกที่เกี่ยวข้องกับโปรไฟล์เควสต์และข้อความสรุป
- วลีรหัสผ่านสำหรับการล็อกแอปไดอารี

### 2-2. ข้อมูลที่แอปจัดเก็บไว้ในอุปกรณ์

- ฐานข้อมูลไดอารีภายในเครื่อง (SQLite)
- ข้อมูลสถานะของเควสต์สำหรับไดอารีภายในเครื่อง
- ค่าสถานะที่เกี่ยวข้องกับการเช็กอิน การตั้งค่า ภาษา การแจ้งเตือน และโฆษณา
- ค่าตรวจสอบการล็อกแอป, salt และข้อมูลเมตาของการเข้ารหัส
- ข้อมูลการตั้งเวลาแจ้งเตือนเควสต์

### 2-3. ข้อมูลบัญชีและข้อมูลระบุตัวตน

ข้อมูลต่อไปนี้อาจถูกประมวลผลผ่าน Firebase Authentication

- Firebase UID
- ที่อยู่อีเมล
- สถานะการยืนยันอีเมล
- สถานะการเข้าสู่ระบบแบบไม่ระบุตัวตน

### 2-4. ข้อมูลเกี่ยวกับโฆษณาและการให้ความยินยอม

เมื่อใช้ Google AdMob และ UMP SDK ข้อมูลต่อไปนี้อาจถูกประมวลผล

- ตัวระบุโฆษณา (เช่น Android AD_ID)
- ที่อยู่ IP และข้อมูลเครือข่าย
- ข้อมูลอุปกรณ์ เวอร์ชันระบบปฏิบัติการ และข้อมูลแอป
- ข้อมูลการแสดงผลโฆษณา การคลิก และการประมวลผลรางวัล
- สถานะการให้ความยินยอมเกี่ยวกับโฆษณาและสถานะตัวเลือกความเป็นส่วนตัว

### 2-5. ข้อมูลที่เกี่ยวข้องกับการแจ้งเตือน

- สถานะการอนุญาตให้ส่งการแจ้งเตือน
- ค่าระบุไดอารีที่มีเควสต์กำลังดำเนินอยู่
- ข้อความแจ้งเตือนของเควสต์
- เวลาการแจ้งเตือนที่ตั้งไว้

## 3. วัตถุประสงค์ของการประมวลผล

แอปประมวลผลข้อมูลเพื่อวัตถุประสงค์ดังต่อไปนี้

- การสมัครสมาชิก การเข้าสู่ระบบ การยืนยันอีเมล และการรีเซ็ตรหัสผ่าน
- การเขียน บันทึก และดูไดอารี
- การสร้างเควสต์ การทบทวน และการตัดสินว่าเสร็จสมบูรณ์หรือไม่
- การเข้ารหัสและถอดรหัสภายในเครื่องที่เกี่ยวข้องกับการล็อกแอป
- การบันทึกและโหลดข้อมูลบนคลาวด์ตามที่ผู้ใช้ร้องขอ
- การแจ้งเตือนเกี่ยวกับเควสต์
- การให้บริการโฆษณา การประมวลผลรางวัลจากโฆษณา และการสะท้อนสถานะการให้ความยินยอมเกี่ยวกับโฆษณา
- ความปลอดภัย การจัดการข้อผิดพลาด และการดำเนินงานของบริการ

## 4. การจัดเก็บภายในเครื่อง การจัดเก็บบนคลาวด์ และการประมวลผลภายนอก

### 4-1. การจัดเก็บภายในเครื่อง

ข้อมูลไดอารีและเควสต์จะถูกจัดเก็บไว้ในฐานข้อมูลภายในเครื่องของอุปกรณ์เป็นหลัก

- หากไม่ได้เปิดใช้การล็อกแอป: จะจัดเก็บไว้ภายในเครื่องในรูปแบบทั่วไป
- หากเปิดใช้การล็อกแอป: ข้อมูลบางส่วน เช่น ชื่อเรื่องไดอารี เนื้อหา และสถานะเควสต์ อาจถูกเข้ารหัสและจัดเก็บไว้ภายในเครื่อง

### 4-2. การจัดเก็บบนคลาวด์

แอปจะบันทึกข้อมูลลงใน Firebase Firestore เฉพาะเมื่อผู้ใช้ดำเนินการใช้ฟังก์ชัน `Save` โดยตรงเท่านั้น

ตามการกำหนดค่าโครงการในปัจจุบัน

- ไม่ได้ใช้การซิงก์ข้อมูลทั้งหมดแบบอัตโนมัติ
- ข้อมูลจะถูกบันทึกลงใน Firestore `savedDiaries` เฉพาะเมื่อผู้ใช้บันทึกด้วยตนเองเท่านั้น
- เมื่อบันทึก ชื่อเรื่องไดอารี เนื้อหา และสถานะเควสต์ อาจถูกจัดเก็บในรูปแบบเข้ารหัสตามสถานะการล็อกแอปในขณะนั้น
- ข้อมูลจะถูกโหลดกลับมายังที่จัดเก็บภายในเครื่องเฉพาะเมื่อผู้ใช้ดำเนินการ `Load`

### 4-3. การประมวลผลภายนอกสำหรับการสร้างและการทบทวนเควสต์

เมื่อผู้ใช้ร้องขอการสร้างเควสต์หรือการทบทวน ข้อมูลต่อไปนี้อาจถูกใช้เพื่อการประมวลผลภายนอกผ่าน Firebase Functions

- ชื่อเรื่องไดอารี
- เนื้อหาไดอารีหรือเนื้อหาการทบทวน
- หมวดหมู่
- ระดับความยาก
- เควสต์ที่เลือก
- ข้อมูลสรุปโปรไฟล์เควสต์

ข้อมูลดังกล่าวใช้สำหรับการสร้างและประเมินเควสต์ผ่าน OpenAI API

ข้อสำคัญ

- เนื้อหาไดอารีที่เกี่ยวข้องจะถูกใช้เพื่อการประมวลผลภายนอกเฉพาะเมื่อมีการใช้งานฟังก์ชันเควสต์เท่านั้น
- ตามการกำหนดค่าโครงการในปัจจุบัน ไม่มีการใช้โค้ดที่บันทึกบันทึกเควสต์ลงในคอลเลกชันแยกชื่อ `questLogs`

## 5. บริการของบุคคลที่สามและการประมวลผลโดยผู้รับจ้าง

### 5-1. Google Firebase

วัตถุประสงค์

- การยืนยันตัวตน (Firebase Authentication)
- การจัดเก็บข้อมูลใน Firestore
- การทำงานของ Cloud Functions

ข้อมูลที่อาจถูกประมวลผล

- UID, ที่อยู่อีเมล และสถานะการยืนยันตัวตน
- ข้อมูลไดอารีที่ผู้ใช้บันทึกด้วยตนเอง
- ข้อมูลคำขอเกี่ยวกับเควสต์

### 5-2. OpenAI

วัตถุประสงค์

- การสร้างเควสต์
- การทบทวนเควสต์และการประเมินความสมบูรณ์

ข้อมูลที่อาจถูกประมวลผล

- ชื่อเรื่อง/เนื้อหาไดอารี
- ข้อความของเควสต์
- ระดับความยากและหมวดหมู่
- เนื้อหาการทบทวนที่ผู้ใช้กรอก
- ข้อมูลสรุปโปรไฟล์เควสต์

### 5-3. Google AdMob / UMP

วัตถุประสงค์

- การให้บริการโฆษณาแบบแบนเนอร์ โฆษณาคั่นหน้า และโฆษณาแบบมีรางวัล
- การจัดการความยินยอมเกี่ยวกับโฆษณาและตัวเลือกความเป็นส่วนตัว

ข้อมูลที่อาจถูกประมวลผล

- ตัวระบุโฆษณา
- ข้อมูลอุปกรณ์และเครือข่าย
- ข้อมูลการโต้ตอบกับโฆษณา
- สถานะการให้ความยินยอม

## 6. การแจ้งเกี่ยวกับการโอนข้อมูลไปต่างประเทศ

แอปอาจประมวลผลข้อมูลส่วนบุคคลหรือข้อมูลที่เกี่ยวข้องนอกประเทศของผู้ใช้ในกรณีดังต่อไปนี้

| รายการ | รายละเอียด |
|---|---|
| ผู้รับข้อมูล | Google LLC, OpenAI และผู้ให้บริการโครงสร้างพื้นฐานที่เกี่ยวข้อง |
| ประเทศปลายทาง | สหรัฐอเมริกา เป็นต้น |

## 7. ระยะเวลาในการเก็บรักษาและการใช้งาน

แอปเก็บรักษาข้อมูลตามหลักเกณฑ์ดังต่อไปนี้

- ข้อมูลไดอารี/การตั้งค่าภายในเครื่อง: จนกว่าผู้ใช้จะลบหรือถอนการติดตั้งแอป
- ข้อมูลบัญชี Firebase: ตลอดระยะเวลาที่ผู้ใช้ยังคงรักษาบัญชีไว้
- ข้อมูลที่เก็บใน Firestore: ตลอดระยะเวลาที่ผู้ใช้ยังคงเก็บรายการที่บันทึกไว้
- ข้อมูลการประมวลผลคำขอเควสต์: เท่าที่จำเป็นสำหรับการประมวลผลแบบ serverless
- ข้อมูลที่เกี่ยวข้องกับโฆษณา/ความยินยอม: เป็นไปตามนโยบายของผู้ให้บริการภายนอกแต่ละราย

นอกจากนี้ โครงการปัจจุบันยังรวมถึงตรรกะการล้างข้อมูลอัตโนมัติดังต่อไปนี้

- การล้างบัญชีผู้ใช้แบบไม่ระบุตัวตนและข้อมูล Firestore ในคอลเลกชันย่อยของผู้ใช้หลังจากระยะเวลาหนึ่ง
- การล้างบัญชีผู้ใช้ทั่วไปที่ไม่ได้ใช้งานเป็นเวลานานและข้อมูล Firestore ในคอลเลกชันย่อยของผู้ใช้

อย่างไรก็ตาม การที่สิ่งเหล่านี้จะถูกนำไปใช้จริงในสภาพแวดล้อมการใช้งานจริงหรือไม่นั้น อาจแตกต่างกันไปตามสถานะการปรับใช้และการตั้งค่าเซิร์ฟเวอร์

## 8. การแจ้งเกี่ยวกับการล็อกแอปและการเข้ารหัสภายในเครื่อง

แอปมีฟังก์ชันแยกต่างหากชื่อ `Diary App Lock`

- วลีรหัสผ่านสำหรับการล็อกแอปแยกจากรหัสผ่านของบัญชี
- วลีรหัสผ่านสำหรับการล็อกแอปใช้สำหรับการเข้ารหัสและถอดรหัสไดอารีภายในเครื่อง
- แม้จะป้อนวลีรหัสผ่านไม่ถูกต้อง ตัวแอปเองอาจไม่ได้ถูกล็อกอย่างสมบูรณ์เสมอไป แต่เนื้อหาไดอารีบางส่วนอาจไม่สามารถอ่านได้
- ไดอารีบางรายการอาจถูกเข้ารหัสแยกต่างหากตามวลีรหัสผ่านที่ใช้ในขณะเขียนหรือขณะปลดล็อกชั่วคราว

ผู้ใช้ควรเก็บวลีรหัสผ่านของตนไว้อย่างปลอดภัย และหากสูญหาย การกู้คืนข้อมูลภายในเครื่องบางส่วนอาจเป็นเรื่องยาก
