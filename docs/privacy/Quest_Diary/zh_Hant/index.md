# 隱私權政策（QDiary）

- 應用程式名稱：QDiary
- 開發者：frog-im
- 聯絡方式：[g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)
- 生效日期：2026-04-19
- 最後更新日期：2026-04-19

本隱私權政策係依據 QDiary 應用程式目前之實作內容編寫。QDiary 提供日記撰寫、任務生成與回顧、登入、手動雲端儲存、廣告及通知等功能，並於此過程中，在必要範圍內處理個人資料或可能構成個人資料之資訊。

## 1. 提供的功能

QDiary 提供以下功能：

- 日記的撰寫、編輯與查看
- 分類管理與日曆檢視
- 任務生成、任務回顧及任務完成處理
- 本地日記應用程式鎖定與本地加密
- 電子郵件登入、電子郵件驗證、匿名（訪客）登入及密碼重設
- 由使用者主動執行的雲端儲存與讀取
- 廣告顯示及廣告隱私選項處理
- 任務提醒通知

## 2. 處理之資訊類別

### 2-1. 使用者直接輸入的資訊

- 電子郵件地址
- 密碼
- 日記標題、內文、日期、分類與難度
- 任務回應、回顧內容及所選任務資訊
- 與任務設定檔相關的選擇值及摘要文字
- 用於日記應用程式鎖定的通行短語

### 2-2. 應用程式儲存在裝置中的資訊

- 本地日記資料庫（SQLite）
- 本地日記的任務狀態資訊
- 出席、設定、語言、通知及廣告相關狀態值
- 應用程式鎖定驗證值、salt 與加密中繼資料
- 任務通知排程資訊

### 2-3. 帳號與識別資訊

透過 Firebase Authentication，可能會處理以下資訊：

- Firebase UID
- 電子郵件地址
- 電子郵件驗證是否完成
- 是否使用匿名登入

### 2-4. 廣告與同意處理資訊

於使用 Google AdMob 與 UMP SDK 時，可能會處理以下資訊：

- 廣告識別碼（如 Android AD_ID）
- IP 位址與網路資訊
- 裝置資訊、作業系統版本與應用程式資訊
- 廣告展示、點擊及獎勵處理資訊
- 廣告同意狀態與隱私選項狀態

### 2-5. 通知相關資訊

- 是否已授予通知權限
- 含有進行中任務之日記識別值
- 任務通知文字
- 已排程之通知時間

## 3. 處理目的

本應用程式基於以下目的處理資訊：

- 註冊、登入、電子郵件驗證及密碼重設
- 日記撰寫、儲存與查看
- 任務生成、回顧及完成判定
- 與應用程式鎖定相關的本地加密與解密
- 處理使用者要求的雲端儲存與讀取
- 提供任務通知
- 提供廣告、處理廣告獎勵並反映廣告同意狀態
- 安全性、錯誤處理與服務營運

## 4. 本地儲存、雲端儲存與外部處理

### 4-1. 本地儲存

日記與任務資訊原則上儲存在裝置的本地資料庫中。

- 未啟用應用程式鎖定時：以一般形式進行本地儲存
- 啟用應用程式鎖定時：部分資訊（例如日記標題、內文及任務狀態）可能會在本地加密後儲存

### 4-2. 雲端儲存

本應用程式僅於使用者直接執行 `Save` 功能時，才會將資料儲存至 Firebase Firestore。

依目前專案設定：

- 不使用自動完整同步
- 僅於使用者手動儲存時，資料才會儲存至 Firestore `savedDiaries`
- 儲存時，日記標題、內文及任務狀態可能會依據目前應用程式鎖定狀態，以加密形式儲存
- 僅於使用者執行 `Load` 時，才會將 Firestore 中的儲存資料重新載入至本地

### 4-3. 任務生成與回顧時的外部處理

當使用者要求生成任務或進行回顧時，以下資訊可能會透過 Firebase Functions 用於外部處理：

- 日記標題
- 日記內文或回顧內文
- 分類
- 難度
- 所選任務
- 任務設定檔摘要資訊

上述資訊將用於透過 OpenAI API 進行任務生成與評估。

重要說明：

- 僅於使用任務功能時，相關日記內容才會用於外部處理。
- 依目前專案設定，不使用將任務記錄儲存至獨立 `questLogs` 集合的程式碼。

- 同意狀態

## 7. 保存與使用期間

本應用程式依以下標準保存資訊：

- 本地日記／設定資訊：直到使用者刪除或解除安裝應用程式為止
- Firebase 帳號資訊：於使用者維持帳號期間
- Firestore 儲存資料：於使用者持續保留已儲存項目期間
- 任務請求處理資料：於無伺服器處理所需範圍內
- 廣告／同意相關資料：依各外部服務提供者之政策而定

此外，目前專案尚包含以下自動清理邏輯：

- 於一定期間後清理匿名使用者帳號及其下屬 Firestore 資料
- 清理長時間未使用之一般使用者帳號及其下屬 Firestore 資料

惟上述邏輯是否實際套用於正式營運環境，仍可能依部署狀態及伺服器設定而有所不同。

## 8. 應用程式鎖定與本地加密說明

本應用程式提供獨立的 `Diary App Lock` 功能。

- 應用程式鎖定用通行短語與帳號密碼彼此獨立。
- 應用程式鎖定用通行短語將用於本地日記之加密與解密。
- 即使輸入錯誤的通行短語，應用程式本身亦不一定會始終完全鎖定；在某些情況下，會表現為部分日記內容無法讀取。
- 部分日記可能會依建立時或暫時解除鎖定時所使用的通行短語，而另行加密。

使用者應妥善保管通行短語；若遺失，部分本地資料可能難以復原。

## 9. 任務通知說明

當使用者啟用任務通知時，含有進行中任務的每篇日記皆可能排程本地通知。

- 通知排程主要透過裝置內部排程機制處理。
- 依目前專案設定，未確認存在僅為通知目的而定期將日記原文傳送至中央伺服器之架構。

## 10. 權限使用說明

本應用程式可能使用以下權限以提供相關功能：

- `INTERNET`：與 Firebase、OpenAI 及廣告 SDK 通訊
- `com.google.android.gms.permission.AD_ID`：使用廣告識別碼
- `POST_NOTIFICATIONS`：顯示任務通知
- `RECEIVE_BOOT_COMPLETED`：於裝置重新開機後還原已排程通知

相關權限僅於執行對應功能所必要之範圍內使用。
