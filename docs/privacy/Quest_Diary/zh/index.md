# 隐私政策（QDiary）

- 应用名称：QDiary
- 开发者：frog-im
- 联系方式：[g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)
- 生效日期：2026-04-19
- 最后更新日期：2026-04-19

本隐私政策根据 QDiary 应用当前的实现情况编写。QDiary 提供日记撰写、任务生成与回顾、登录、手动云端保存、广告及通知等功能，并在此过程中会在必要范围内处理个人信息或可能构成个人信息的相关信息。

## 1. 提供的功能

QDiary 提供以下功能：

- 日记的撰写、编辑与查看
- 分类管理及日历查看
- 任务生成、任务回顾及任务完成处理
- 本地日记应用锁及本地加密
- 邮箱登录、邮箱验证、匿名（访客）登录及密码重置
- 由用户主动发起的云端保存与读取
- 广告展示及广告隐私选项处理
- 任务提醒通知

## 2. 处理的信息类别

### 2-1. 用户直接输入的信息

- 电子邮箱地址
- 密码
- 日记标题、正文、日期、分类和难度
- 任务回复、回顾内容及所选任务信息
- 与任务档案相关的选择项及摘要文本
- 用于日记应用锁的口令短语

### 2-2. 应用在设备中存储的信息

- 本地日记数据库（SQLite）
- 本地日记的任务状态信息
- 出勤、设置、语言、通知及广告相关状态值
- 应用锁校验值、salt 及加密元数据
- 任务通知预约信息

### 2-3. 账户及识别信息

通过 Firebase Authentication，可能会处理以下信息：

- Firebase UID
- 电子邮箱地址
- 邮箱验证是否完成
- 是否使用匿名登录

### 2-4. 广告及同意处理信息

在使用 Google AdMob 和 UMP SDK 时，可能会处理以下信息：

- 广告标识符（如 Android AD_ID）
- IP 地址及网络信息
- 设备信息、操作系统版本及应用信息
- 广告展示、点击及奖励处理信息
- 广告同意状态及隐私选项状态

### 2-5. 通知相关信息

- 是否授予通知权限
- 含有进行中任务的日记标识值
- 任务通知文案
- 已预约的通知时间

## 3. 处理目的

本应用出于以下目的处理信息：

- 注册、登录、邮箱验证及密码重置
- 日记的撰写、保存与查看
- 任务生成、回顾及完成判定
- 与应用锁相关的本地加密与解密
- 处理用户请求的云端保存与读取
- 提供任务通知
- 提供广告、处理广告奖励并反映广告同意状态
- 安全保障、错误处理及服务运营

## 4. 本地存储、云端存储与外部处理

### 4-1. 本地存储

日记及任务信息原则上存储于设备本地数据库中。

- 未启用应用锁时：以一般形式进行本地存储
- 启用应用锁时：日记标题、正文、任务状态等部分信息可能会在本地加密后存储

### 4-2. 云端存储

本应用仅在用户主动执行 `Save` 功能时，才会将数据保存到 Firebase Firestore。

根据当前项目配置：

- 不使用自动全量同步
- 仅在用户手动保存时，数据才会保存到 Firestore `savedDiaries`
- 保存时，日记标题、正文及任务状态可能会根据当前应用锁状态以加密形式存储
- 仅在用户执行 `Load` 时，才会将 Firestore 中的保存数据重新加载到本地

### 4-3. 任务生成与回顾时的外部处理

当用户请求生成任务或进行任务回顾时，以下信息可能会通过 Firebase Functions 用于外部处理：

- 日记标题
- 日记正文或回顾正文
- 分类
- 难度
- 所选任务
- 任务档案摘要信息

上述信息将用于通过 OpenAI API 进行任务生成与评估。

重要说明：

- 仅在使用任务功能时，相关日记内容才会用于外部处理。
- 根据当前项目配置，不使用将任务日志保存到单独 `questLogs` 集合中的代码。

## 7. 保存及使用期限

本应用按照以下标准保存信息：

- 本地日记/设置信息：直至用户删除或卸载应用
- Firebase 账户信息：在用户持续保有账户期间
- Firestore 保存数据：在用户持续保留已保存项目期间
- 任务请求处理数据：在无服务器处理所需范围内
- 广告/同意相关数据：遵循各外部服务提供方的政策

此外，当前项目还包含以下自动清理逻辑：

- 在一定期限后清理匿名用户账户及其下属 Firestore 数据
- 清理长期不活跃的普通用户账户及其下属 Firestore 数据

但上述逻辑是否实际应用于生产环境，可能会因部署状态及服务器设置而有所不同。

## 8. 应用锁及本地加密说明

本应用提供单独的 `Diary App Lock` 功能。

- 应用锁口令短语与账户密码相互独立。
- 应用锁口令短语用于本地日记的加密与解密。
- 即使输入错误的口令短语，应用本身也不一定会始终被完全锁定；在某些情况下，表现为部分日记内容无法读取。
- 部分日记可能会根据创建时或临时解锁时使用的口令短语被单独加密。

用户应妥善保管口令短语，如遗失，部分本地数据可能难以恢复。

## 9. 任务通知说明

当用户启用任务通知时，含有进行中任务的每篇日记都可能会预约本地通知。

- 通知预约主要通过设备内部调度完成。
- 根据当前项目配置，未确认存在仅为通知目的而定期将日记原文发送至中央服务器的结构。

## 10. 权限使用说明

本应用可能会使用以下权限以提供相关功能：

- `INTERNET`：与 Firebase、OpenAI 及广告 SDK 通信
- `com.google.android.gms.permission.AD_ID`：使用广告标识符
- `POST_NOTIFICATIONS`：显示任务通知
- `RECEIVE_BOOT_COMPLETED`：设备重启后恢复已预约通知

相关权限仅在实现对应功能所必需的范围内使用。
