## 2. ประเภทของข้อมูลที่ประมวลผล

### 2-1) ข้อมูลที่เก็บบนอุปกรณ์ของคุณ (ที่จัดเก็บภายในเครื่อง)

แอปจะเก็บข้อมูลบางอย่าง **ไว้ภายในเครื่องบนอุปกรณ์ของคุณ** เพื่อให้บริการฟีเจอร์และเพิ่มความสะดวกในการใช้งาน  
ข้อมูลนี้โดยทั่วไป **จะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของผู้พัฒนา** และจะถูกลบเมื่อคุณลบข้อมูลแอปหรือถอนการติดตั้ง (ยกเว้นไฟล์ที่คุณส่งออกไปยังที่อื่น)

#### (1) การตั้งค่า (SharedPreferences)

| หมวดหมู่ | คีย์ (ตัวอย่าง) | วัตถุประสงค์ | ที่จัดเก็บ | การลบ |
|---|---|---|---|---|
| ตั้งค่าเสร็จสิ้น | `setup_done` | เก็บสถานะการตั้งค่าเริ่มต้น | SharedPreferences | ลบเมื่อ ลบข้อมูลแอป/ถอนการติดตั้ง |
| ประวัติประเทศ | `selected_countries` | เก็บประเทศที่เลือกล่าสุด | เช่นเดียวกัน | เช่นเดียวกัน |
| ประเทศที่ใช้งานอยู่ | `active_country` | เก็บประเทศที่เลือกปัจจุบัน | เช่นเดียวกัน | เช่นเดียวกัน |
| เกมที่เลือก | `selected_lotto_ids` | เก็บ ID เกมที่ติ๊กเลือก | เช่นเดียวกัน | เช่นเดียวกัน |
| เกมที่ใช้งานอยู่ | `active_lotto_id` | เก็บ ID เกมที่ใช้งานอยู่ | เช่นเดียวกัน | เช่นเดียวกัน |
| **การเลือกเวลา seed (ไม่บังคับ)** | `birth_datetime_iso` | เก็บเวลาอ้างอิง seed ที่ผู้ใช้เลือก (อาจใช้สำหรับ seeding/การปรับให้เหมาะกับผู้ใช้) | เช่นเดียวกัน | เช่นเดียวกัน |

> **หมายเหตุ:** “การเลือกเวลา seed (ไม่บังคับ)” จะถูกประมวลผลเฉพาะเมื่อผู้ใช้เลือกตั้งค่า และอาจไม่จำเป็นต่อการใช้งานหลักของแอป

#### (2) ข้อมูลล็อก (SQLite)

แอปอาจเก็บบันทึกที่สร้าง/บันทึกไว้ในฐานข้อมูล SQLite ภายในเครื่อง

- ตัวอย่างตาราง: `log_...`  
- ตัวอย่างฟิลด์:  
  - `id`, `date_id` หรือ `date_text` (เวลา/ไทม์สแตมป์), `choice1..choiceN` (ตัวเลขที่เลือก), `isFinger` (แฟล็กเกี่ยวกับลายนิ้วมือ เป็นต้น)

คุณสามารถดูล็อกในหน้ารายการ/รายละเอียดตาราง และลบได้ตามต้องการ (ระดับตารางหรือระดับแถว)

#### (3) ไฟล์ข้อมูล JSON (ต่อเกม)

แอปอาจเก็บข้อมูล JSON รายเกมในไดเรกทอรีเอกสารของแอป

- ตัวอย่าง: `game_json/<gameId>.json`  
- วัตถุประสงค์: ข้อมูลผล/งวดที่ผู้ใช้จัดการและแก้ไขได้ (เช่น เพื่อสถิติ/การแสดงผล)

ไฟล์เหล่านี้ถูกเก็บบนอุปกรณ์ และโดยทั่วไปจะถูกลบเมื่อถอนการติดตั้ง ทั้งนี้ขึ้นอยู่กับพฤติกรรมของ OS/การสำรองข้อมูล

### 2-2) โฆษณา ความยินยอม และข้อมูลที่เกี่ยวข้อง (SDK บุคคลที่สาม)

แอปใช้ **Google Mobile Ads SDK (AdMob)** และ **Google UMP** เพื่อ:

- แสดงโฆษณา (รวมถึง **โฆษณาแบบรับรางวัล**)  
- จัดการความยินยอมที่กฎหมายกำหนดสำหรับการโฆษณา

SDK เหล่านี้อาจเก็บรวบรวม/ประมวลผล ตัวอย่างเช่น:

- **รหัสโฆษณา** (เช่น AAID, IDFA)  
- ข้อมูลจาก IP, ตำแหน่งโดยประมาณ, ข้อมูลเครือข่าย  
- ข้อมูลอุปกรณ์/แอป (เวอร์ชัน OS, เวอร์ชันแอป, ภาษา, ข้อมูลวินิจฉัย)  
- การโต้ตอบกับโฆษณา (การแสดงผล การคลิก การรับรางวัลสำเร็จ)  
- ตัวเลือกความยินยอมที่บันทึกโดย UMP

ในบางภูมิภาค (เช่น EEA/UK/CH) อาจแสดงแบบฟอร์มความยินยอมของ UMP และอาจมีทางเข้า **Privacy Options** ตามที่กำหนด
