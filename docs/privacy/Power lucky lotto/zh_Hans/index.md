## 1. 目的与适用范围

Power lucky lotto 是一款用于管理彩票游戏并查看记录的应用。主要功能包括：

- 国家/游戏选择与设置（例如：KR 6/45、US Powerball）  
- 号码生成/保存与日志（历史）查看  
- 日志表查看与删除（表列表/详情）  
- 通过 JSON 编辑/管理游戏开奖数据（用于统计/可视化）  
- 广告（含激励广告）以及在需要时进行同意管理

本应用**不要求创建账号**，并且默认情况下**不会将您的数据上传至开发者服务器**。  
大多数处理均在**您的设备本地**完成。

但为了**广告展示**、**同意管理**及**法律合规**，第三方 SDK（例如  
**Google Mobile Ads SDK（AdMob）** 与 **Google UMP（User Messaging Platform）**）可能会收集并处理某些数据（例如广告标识符）。

## 2. 处理的数据类型

### 2-1）存储在设备上的数据（本地存储）

为提供功能与提升易用性，应用会将部分数据**本地存储在您的设备上**。  
这些数据通常**不会传输至开发者服务器**，并会在您删除应用数据或卸载应用时被移除（您导出到其他位置的文件除外）。

[Local Settings and Stored Values](https://frog-im.github.io/privacy/Power%20lucky%20lotto/en/local/)

### 2-2）广告、同意及相关数据（第三方 SDK）

应用使用 **Google Mobile Ads SDK（AdMob）** 与 **Google UMP** 来：

- 展示广告（包括**激励广告**）  
- 在法律要求时管理广告同意

这些 SDK 可能会收集/处理例如：

- **广告标识符**（例如 AAID、IDFA）  
- 基于 IP 的信息、粗略位置、网络信息  
- 设备/应用信息（系统版本、应用版本、语言、诊断信息）  
- 广告交互（展示、点击、激励完成）  
- 由 UMP 记录的同意选择

在部分地区（例如 EEA/UK/CH），可能会显示 UMP 同意表单，并在需要时提供 **Privacy Options** 入口。

## 3. 保留期限

- **本地设置（SharedPreferences）：** 直至删除应用数据或卸载  
- **日志数据（SQLite）：** 直至您删除，或卸载/清除应用数据  
- **JSON 文件：** 存储于应用文档目录；多数情况下卸载会移除，但导出/备份由用户自行管理  
- **广告/同意数据（第三方）：** 按 Google 政策与适用法律保留
