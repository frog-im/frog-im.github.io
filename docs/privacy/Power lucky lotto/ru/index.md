## 1. Цель и область применения

Power lucky lotto это приложение для управления лотерейными играми и просмотра записей. Основные функции включают:

- Выбор страны/игры и настройка (например, KR 6/45, US Powerball)  
- Генерация/сохранение чисел и просмотр журнала (истории)  
- Просмотр и удаление таблиц журнала (список таблиц/детали)  
- Редактирование/управление данными результатов через JSON (для статистики/визуализации)  
- Реклама (включая вознаграждаемую рекламу) и управление согласием (при необходимости)

Приложение **не требует создания учетной записи** и по умолчанию **не загружает ваши данные на серверы разработчика.**  
Большинство операций выполняется **на вашем устройстве**.

Однако для **рекламы**, **управления согласием** и **соблюдения законодательства** сторонние SDK, такие как  
**Google Mobile Ads SDK (AdMob)** и **Google UMP (User Messaging Platform)**, могут собирать и обрабатывать некоторые данные (например, рекламные идентификаторы).

## 2. Виды обрабатываемых данных

### 2-1) Данные, хранящиеся на вашем устройстве (локальное хранилище)

Приложение хранит определенные данные **локально на вашем устройстве** для предоставления функций и улучшения удобства.  
Как правило, эти данные **не передаются на серверы разработчика** и удаляются при очистке данных приложения или удалении приложения (за исключением файлов, которые вы экспортировали в другое место).

#### (1) Настройки (SharedPreferences)

| Категория | Ключ (пример) | Назначение | Хранилище | Удаление |
|---|---|---|---|---|
| Завершение настройки | `setup_done` | Хранение статуса первичной настройки | SharedPreferences | Удаляется при очистке данных/удалении приложения |
| История стран | `selected_countries` | Сохранение недавно выбранных стран | То же | То же |
| Активная страна | `active_country` | Сохранение текущей выбранной страны | То же | То же |
| Выбранные игры | `selected_lotto_ids` | Сохранение отмеченных ID игр | То же | То же |
| Активная игра | `active_lotto_id` | Сохранение активного ID игры | То же | То же |
| **Выбор времени seed (необязательно)** | `birth_datetime_iso` | Сохранение выбранного пользователем опорного времени seed (может использоваться для seeding/персонализации) | То же | То же |

> **Примечание:** “Выбор времени seed (необязательно)” обрабатывается только если пользователь решит его установить и может не требоваться для базового использования приложения.

#### (2) Данные журнала (SQLite)

Приложение может хранить созданные/сохраненные записи в локальной базе данных SQLite.

- Примеры таблиц: `log_...`  
- Примеры полей:  
  - `id`, `date_id` или `date_text` (временная метка), `choice1..choiceN` (выбранные числа), `isFinger` (флаг, связанный с отпечатком пальца, и т. п.)

Вы можете просматривать журналы на экранах списка/деталей таблиц и при желании удалять их (на уровне таблицы или строки).

#### (3) Файлы данных JSON (по игре)

Приложение может хранить данные JSON для каждой игры в каталоге документов приложения.

- Пример: `game_json/<gameId>.json`  
- Назначение: управляемые/редактируемые пользователем данные тиражей/результатов (например, для статистики/визуализации)

Эти файлы хранятся на устройстве и обычно удаляются при удалении приложения, в зависимости от поведения ОС/резервного копирования.

### 2-2) Реклама, согласие и связанные данные (сторонние SDK)

Приложение использует **Google Mobile Ads SDK (AdMob)** и **Google UMP** для:

- Показов рекламы (включая **вознаграждаемую рекламу**)  
- Управления юридически необходимым согласием для рекламы

Эти SDK могут собирать/обрабатывать, например:

- **Рекламный идентификатор** (например, AAID, IDFA)  
- Информацию на основе IP, примерное местоположение, сетевую информацию  
- Информацию об устройстве/приложении (версия ОС, версия приложения, язык, диагностическая информация)  
- Взаимодействия с рекламой (показы, клики, получение вознаграждения)  
- Выбор согласия, зафиксированный UMP

В некоторых регионах (например, EEA/UK/CH) может отображаться форма согласия UMP и предоставляться пункт **Privacy Options** там, где это требуется.

## 3. Сроки хранения

- **Локальные настройки (SharedPreferences):** до очистки данных приложения или удаления приложения  
- **Данные журнала (SQLite):** до удаления пользователем или очистки данных/удаления приложения  
- **Файлы JSON:** хранятся в каталоге документов приложения; часто удаляются при удалении приложения, но экспорт/резервные копии управляются пользователем  
- **Данные рекламы/согласия (сторонние):** хранятся в соответствии с политиками Google и применимым законодательством
