## 1. Finalidad y alcance

Power lucky lotto es una app para gestionar juegos de lotería y consultar registros. Funciones principales:

- Selección y configuración de país/juego (p. ej., KR 6/45, US Powerball)  
- Generación/guardado de números y consulta de historial (logs)  
- Consulta y eliminación de tablas de logs (lista/detalle)  
- Edición/gestión de datos de resultados mediante JSON (para estadísticas/visualización)  
- Publicidad (incluida publicidad recompensada) y gestión de consentimiento (cuando sea necesario)

La app **no requiere crear una cuenta** y, por defecto, **no sube tus datos a servidores del desarrollador**.  
La mayor parte del procesamiento se realiza **en tu dispositivo**.

No obstante, para **publicidad**, **gestión de consentimiento** y **cumplimiento legal**, SDKs de terceros como  
**Google Mobile Ads SDK (AdMob)** y **Google UMP (User Messaging Platform)** pueden recopilar y tratar ciertos datos (por ejemplo, identificadores publicitarios).

### 2-2) Publicidad, consentimiento y datos relacionados (SDKs de terceros)

La app utiliza **AdMob** y **Google UMP** para mostrar anuncios (incluidos recompensados) y gestionar el consentimiento cuando corresponda.  
Estos SDKs pueden recopilar/tratar:

- Identificador publicitario (AAID/IDFA)  
- Información basada en IP, ubicación aproximada, red  
- Información del dispositivo/app (versión del SO/app, idioma, diagnósticos)  
- Interacciones con anuncios (impresiones, clics, finalización recompensada)  
- Estado/elecciones de consentimiento (UMP)
