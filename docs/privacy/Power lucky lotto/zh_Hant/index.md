## 1. 目的與適用範圍

Power lucky lotto 是一款用於管理樂透/彩券遊戲並查看記錄的應用。主要功能包括：

- 國家/遊戲選擇與設定（例如 KR 6/45、US Powerball）  
- 號碼生成/保存與日誌（歷史）查看  
- 日誌表（表列表/詳情）的查看與刪除  
- 透過 JSON 編輯/管理開獎結果資料（用於統計/視覺化）  
- 廣告（含獎勵型廣告）顯示與同意管理（在需要的地區）

本應用 **不要求建立帳號**，且預設 **不會將您的資料上傳至開發者伺服器**。  
多數處理在 **您的裝置本機** 完成。

但出於 **廣告顯示**、**同意管理** 與 **合規** 需要，  
**Google Mobile Ads SDK（AdMob）** 與 **Google UMP（User Messaging Platform）** 等第三方SDK可能會蒐集並處理部分資訊（例如廣告識別碼）。

## 2. 處理的資料類型

### 2-1) 儲存在您裝置上的資料（本機儲存）

為提供功能並提升可用性，應用會在 **裝置本機** 儲存部分資料。  
這些資料通常 **不會傳送至開發者伺服器**，並會在您清除應用資料或解除安裝時刪除（但您匯出到其他位置的檔案除外）。

#### (1) 設定（SharedPreferences）

| 類別 | 鍵（範例） | 用途 | 儲存位置 | 刪除時點 |
|---|---|---|---|---|
| 完成設定 | `setup_done` | 保存初始設定完成狀態 | SharedPreferences | 清除資料/解除安裝時刪除 |
| 國家歷史 | `selected_countries` | 保留最近選擇的國家 | 同上 | 同上 |
| 目前國家 | `active_country` | 保存目前選擇的國家 | 同上 | 同上 |
| 已選遊戲 | `selected_lotto_ids` | 保存勾選的遊戲ID | 同上 | 同上 |
| 目前遊戲 | `active_lotto_id` | 保存目前啟用的遊戲ID | 同上 | 同上 |
| **seed 時間選擇（選用）** | `birth_datetime_iso` | 保存使用者選擇的 seed 參考時間（可能用於生成 seed/個人化） | 同上 | 同上 |

> **說明：**「seed 時間選擇（選用）」僅在使用者選擇設定時才會儲存，可能不是核心功能的必需項。

#### (2) 日誌資料（SQLite）

應用可能會將生成/保存的記錄儲存在裝置本機的 SQLite 資料庫中。

- 範例表：`log_...`  
- 範例欄位：  
  - `id`、`date_id` 或 `date_text`（時間戳）、`choice1..choiceN`（選擇號碼）、`isFinger`（指紋相關標記等）

您可以在應用的表列表/詳情畫面查看日誌，並可按需刪除（按表或按列）。

#### (3) JSON 資料檔（按遊戲）

應用可能會在應用文件目錄中儲存特定遊戲的 JSON 資料。

- 範例：`game_json/<gameId>.json`  
- 用途：使用者可管理/編輯的開獎/結果資料（例如用於統計/視覺化）

這些檔案儲存在裝置本機，通常在解除安裝時刪除，但可能受作業系統/備份機制影響而有例外。

### 2-2) 廣告、同意及相關資料（第三方SDK）

應用使用 **AdMob** 與 **Google UMP** 來：

- 顯示廣告（包含 **獎勵型廣告**）  
- 在法律要求下管理廣告相關同意

這些SDK可能會蒐集/處理（範例）：

- **廣告識別碼**（AAID、IDFA 等）  
- 基於 IP 的資訊、概略位置、網路資訊  
- 裝置/應用資訊（系統版本、應用版本、語言、診斷資訊）  
- 廣告互動資訊（曝光、點擊、獎勵完成）  
- UMP 記錄的同意選擇

在部分地區（例如 EEA/UK/CH），可能會顯示 UMP 同意表單，並在需要時提供 **Privacy Options** 入口。

## 3. 保存期限

- **本機設定（SharedPreferences）：** 直到清除應用資料或解除安裝

- **JSON 檔案：** 儲存在應用文件目錄；多數情況下解除安裝會刪除，但匯出/備份檔案由使用者自行管理
