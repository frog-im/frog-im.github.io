## 1. 目的与适用范围

Power lucky lotto 是一款用于管理彩票/乐透游戏并查看记录的应用。主要功能包括：

- 国家/游戏选择与设置（例如 KR 6/45、US Powerball）  
- 号码生成/保存与日志（历史）查看  
- 日志表（表列表/详情）的查看与删除  
- 通过 JSON 编辑/管理开奖结果数据（用于统计/可视化）  
- 广告（含激励广告）展示与同意管理（在需要的地区）

本应用 **不要求创建账户**，且默认 **不会将您的数据上传到开发者服务器**。  
绝大多数处理在 **您的设备本地** 完成。

但出于 **广告展示**、**同意管理** 和 **合规** 需要，  
**Google Mobile Ads SDK（AdMob）** 与 **Google UMP（User Messaging Platform）** 等第三方SDK可能会收集并处理部分信息（例如广告标识符）。

## 2. 处理的数据类型

### 2-1) 存储在您设备上的数据（本地存储）

为提供功能并提升可用性，应用会在 **设备本地** 存储部分数据。  
这些数据通常 **不会传输至开发者服务器**，并会在您清除应用数据或卸载应用时删除（但您导出到其他位置的文件除外）。

#### (1) 设置（SharedPreferences）

| 类别 | 键（示例） | 用途 | 存储位置 | 删除时点 |
|---|---|---|---|---|
| 完成设置 | `setup_done` | 保存初始设置完成状态 | SharedPreferences | 清除数据/卸载时删除 |
| 国家历史 | `selected_countries` | 保留最近选择的国家 | 同上 | 同上 |
| 当前国家 | `active_country` | 保存当前选择的国家 | 同上 | 同上 |
| 已选游戏 | `selected_lotto_ids` | 保存勾选的游戏ID | 同上 | 同上 |
| 当前游戏 | `active_lotto_id` | 保存当前激活的游戏ID | 同上 | 同上 |
| **seed 时间选择（可选）** | `birth_datetime_iso` | 保存用户选择的 seed 参考时间（可能用于生成 seed/个性化） | 同上 | 同上 |

> **说明：** “seed 时间选择（可选）”仅在用户选择设置时才会保存，可能并非应用核心使用所必需。

#### (2) 日志数据（SQLite）

应用可能会将生成/保存的记录存储在设备本地的 SQLite 数据库中。

- 示例表：`log_...`  
- 示例字段：  
  - `id`、`date_id` 或 `date_text`（时间戳）、`choice1..choiceN`（选择号码）、`isFinger`（指纹相关标记等）

您可以在应用的表列表/详情界面查看日志，并按需删除（按表或按行）。

#### (3) JSON 数据文件（按游戏）

应用可能会在应用文档目录中存储特定游戏的 JSON 数据。

- 示例：`game_json/<gameId>.json`  
- 用途：用户可管理/编辑的开奖/结果数据（例如用于统计/可视化）

这些文件存储于设备本地，通常在卸载时删除，但可能受操作系统/备份机制影响而存在例外。

### 2-2) 广告、同意及相关数据（第三方SDK）

应用使用 **AdMob** 与 **Google UMP** 来：

- 展示广告（包括 **激励广告**）  
- 在法律要求下管理广告相关同意

这些SDK可能会收集/处理以下信息（示例）：

- **广告标识符**（AAID、IDFA 等）  
- 基于 IP 的信息、粗略位置、网络信息  
- 设备/应用信息（系统版本、应用版本、语言、诊断信息）  
- 广告交互信息（展示、点击、激励完成）  
- UMP 记录的同意选择

在部分地区（例如 EEA/UK/CH），可能会显示 UMP 同意表单，并在需要时提供 **Privacy Options** 入口。

## 3. 保存期限

- **本地设置（SharedPreferences）：** 直到清除应用数据或卸载  
- **日志数据（SQLite）：** 直到您删除或清除数据/卸载  
- **JSON 文件：** 存于应用文档目录；卸载时多数情况下删除，但用户导出/备份文件由用户自行管理  
- **广告/同意数据（第三方）：** 按 Google 政策与适用法律保存
