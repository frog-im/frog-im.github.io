# إشعار نقل البيانات دولياً

تاريخ السريان: 2026-06-12
آخر تحديث: 2026-06-15

لا يرسل Lucky Pick Box مدخلات الألعاب أو نتائجها أو الصور المحددة إلى خادم يديره المطوّر. عند استخدام ميزات الإعلانات أو الموافقة، قد تعالج Google والمعالِجون المرتبطون بعض المعلومات خارج بلدك أو منطقتك.

1. المستلمون والدول

قد يشمل المستلمون Google LLC والشركات التابعة لـ Google والمعالِجين المستخدمين للإعلانات وإدارة الموافقة والأمان والقياس وتشغيل الخدمة. قد تتم المعالجة في الولايات المتحدة ودول أخرى توجد فيها بنية Google أو معالجيها التحتية.

2. المعلومات التي قد تُنقل

قد تشمل المعلومات معرّفات الإعلانات ومعرّفات نسخة التطبيق وعنوان IP والموقع التقريبي ومعلومات الجهاز والشبكة وإصدار التطبيق ونظام التشغيل واللغة ومرات ظهور الإعلانات والنقرات والتفاعلات ومعلومات التشخيص وإعدادات الموافقة أو خصوصية الإعلانات. لا يقدم المطوّر مدخلات الألعاب أو تسميات المشاركين أو نتائج الألعاب أو الصورة المحددة نفسها إلى خدمات إعلانات Google.

3. التوقيت والطريقة والغرض

قد يحدث النقل عبر اتصالات إنترنت مشفرة عندما يطلب التطبيق إعلانات أو يحدّث حالة الموافقة أو يفتح خيارات الخصوصية. تشمل الأغراض عرض الإعلانات، والإعلانات غير المخصصة، وتحديد التكرار، ومنع الاحتيال، وإدارة الموافقة، والقياس، وأمان الخدمة، والامتثال القانوني.

4. الاحتفاظ والاختيارات

تحتفظ Google ومعالجوها بالمعلومات وفقاً لسياسات الخصوصية والالتزامات التعاقدية والقانون المعمول به. حيثما يتاح ذلك، يمكنك اختيار الإعلانات غير المخصصة أو المعالجة المقيدة للبيانات لقوانين خصوصية الولايات الأمريكية المعمول بها أو خيارات خصوصية Google. يمكنك أيضاً تقييد معرّفات الإعلانات في إعدادات الجهاز أو قطع الاتصال بالشبكة أو التوقف عن استخدام التطبيق وإزالته.
