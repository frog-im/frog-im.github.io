## 1. 목적 및 적용 범위

Lucky Pick Box는 뽑기, 순서 정하기, 팀 나누기, 주사위, 동전, 사다리, 룰렛 등 일상적이거나 모임에서 쓰는 무작위 선택을 돕는 캐주얼 도구입니다. 앱은 실제 돈, 베팅, 도박, 금융 거래, 현금성 보상 또는 현금과 같은 가치를 제공하지 않습니다.

### A. 이 방침이 다루는 주요 기능

- 공통 항목 입력: 사용자가 직접 입력하거나 이미지에서 읽어 온 텍스트를 게임 항목으로 나눕니다.
- 뽑기 게임: 사다리, 룰렛, 플링코, 간단 뽑기, 주사위, 동전, 랜덤 숫자, 팀 나누기, 순서 정하기, 카드 뽑기, 폭탄 뽑기, 예/아니오 등 무작위 선택 기능을 제공합니다.
- 결과 기록: 각 게임 완료 후 게임 종류, 제목, 참가자/항목, 결과 요약, 생성 시각을 최근 기록으로 저장할 수 있습니다.
- 설정 슬롯: 일부 게임은 현재 참가자, 항목, 수량, 범위, 팀 수, 가중치 등 게임별 설정을 최대 3개 슬롯에 저장하고 다시 불러올 수 있습니다.
- 광고 및 동의 관리: Google AdMob 광고, UMP 동의 화면, 비개인 맞춤 광고 선택, 미국 주 개인정보 보호법 관련 제한적 데이터 처리 신호를 지원할 수 있습니다.

앱은 회원가입이나 로그인을 요구하지 않습니다. 개발자는 앱에서 이름, 전화번호, 이메일 주소, 연락처, 게임 입력 내용, 선택한 이미지 또는 게임 결과를 개발자가 운영하는 서버로 전송받지 않습니다.

앱 기능 제공을 위해 게임 입력 항목, 참가자 표시명, 최근 결과, 저장된 게임 설정, 연출 설정, 광고 개인정보 선택, 동의 관련 상태가 기기의 로컬 저장소에 보관될 수 있습니다. 최근 결과 기록은 앱에서 제한된 수만 보관되며 개발자 운영 서버로 전송되지 않습니다.

## 2. 처리하는 개인정보 항목

### 2-1) 사용자가 직접 입력하는 정보

앱은 회원가입이나 로그인을 요구하지 않습니다. 개발자는 앱에서 이름, 전화번호, 이메일 주소, 연락처, 게임 입력 내용, 선택한 이미지 또는 게임 결과를 개발자가 운영하는 서버로 전송받지 않습니다.

### 2-2) 기기에서 선택한 파일

이미지에서 텍스트를 읽는 기능을 사용하면 이용자가 사진 보관함에서 이미지를 직접 선택합니다. 선택한 이미지는 플랫폼 이미지 선택 기능과 Google ML Kit 텍스트 인식 구성요소를 통해 기기 내에서 처리됩니다. 개발자는 해당 이미지를 개발자 운영 서버로 업로드하지 않으며 원격 계정에 보관하지 않습니다.

### 2-3) 앱 내 로컬 저장 데이터

앱 기능 제공을 위해 게임 입력 항목, 참가자 표시명, 최근 결과, 저장된 게임 설정, 연출 설정, 광고 개인정보 선택, 동의 관련 상태가 기기의 로컬 저장소에 보관될 수 있습니다. 최근 결과 기록은 앱에서 제한된 수만 보관되며 개발자 운영 서버로 전송되지 않습니다.

### B. 기기 내 로컬 저장 위치 및 항목

| 저장 위치 또는 키 | 저장될 수 있는 정보 | 목적 | 삭제 방법 |
|---|---|---|---|
| `SharedPreferences` / `draw_results` | 결과 ID, 게임 종류, 화면 제목, 참가자/항목 목록, 결과 요약, 생성 시각. 최근 결과는 최대 50개까지 보관됩니다. | 홈 화면과 기록 화면에서 최근 결과를 보여주기 위해 사용합니다. | 앱의 기록 삭제 기능, 운영체제의 앱 데이터 삭제, 앱 제거 |
| `SharedPreferences` / `game_settings.<gameId>.slot_<n>` | 게임별 저장 슬롯. 예: 참가자 이름, 항목 목록, 숫자 범위, 선택 수량, 팀 수, 카드/폭탄/가중치 설정, 저장 시각 등. 각 게임당 최대 3개 슬롯을 저장할 수 있습니다. | 사용자가 같은 게임 설정을 다시 불러올 수 있도록 하기 위해 사용합니다. | 게임 설정 화면의 슬롯 비우기, 앱 데이터 삭제, 앱 제거 |
| `SharedPreferences` / `cinematic_motion_enabled`, `fullscreen_game_mode_enabled` | 박진감 모드와 전체화면 게임 모드 사용 여부 | 앱 연출 및 화면 표시 설정 유지 | 앱 설정 변경, 앱 데이터 삭제, 앱 제거 |
| `SharedPreferences` / `ad_non_personalized`, `ad_restricted_data_processing`, `ad_completed_game_count` | 광고 개인정보 선택, 제한적 데이터 처리 선택, 광고 표시 빈도 계산용 완료 게임 수 | 광고 요청에 사용자의 지역별 선택을 반영하고 전면 광고 빈도를 제어 | 앱 설정 변경, 앱 데이터 삭제, 앱 제거 |
| 이미지 선택 및 텍스트 인식 처리 | 사용자가 선택한 이미지 파일 경로와 인식된 텍스트가 처리될 수 있습니다. 앱은 선택 이미지를 개발자 서버에 업로드하지 않으며, 인식 후 이미지를 자체 원격 저장소에 보관하지 않습니다. | 이미지 속 텍스트를 공통 항목 입력란에 추가 | 사진 앱/운영체제 캐시 정책, 앱 종료, 앱 데이터 삭제 |

공통 항목 입력란의 텍스트는 사용자가 게임을 실행하거나 설정 슬롯/결과 기록에 저장하는 경우에만 위 저장 항목에 포함될 수 있습니다. 단순히 입력란에 표시된 임시 텍스트 자체를 개발자 서버로 전송하지 않습니다.

### 2-4) 광고 및 동의 처리 과정에서 자동으로 처리될 수 있는 정보

지원되는 플랫폼, 현재 Android에서 앱은 Google AdMob 및 Google User Messaging Platform(UMP)을 사용합니다. Google과 광고 파트너는 광고 식별자, 앱 인스턴스 식별자, IP 주소, 대략적인 위치, 기기 및 네트워크 정보, 앱 버전, 운영체제, 언어, 광고 노출, 클릭, 상호작용, 진단 정보, 동의 상태, 지역별 광고 개인정보 설정을 광고 제공, 빈도 제한, 부정 사용 방지, 동의 관리, 측정, 분석, 보안 및 법적 의무 준수를 위해 처리할 수 있습니다.

Google의 개인정보 처리 방식은 https://policies.google.com/privacy 및 https://policies.google.com/technologies/ads 에서 확인할 수 있습니다.
