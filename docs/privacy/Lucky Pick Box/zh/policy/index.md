# 国际数据传输说明

生效日期: 2026-06-12
最后更新: 2026-06-15

Lucky Pick Box 不会将游戏输入、游戏结果或所选图片发送到开发者运营的服务器。当使用广告或同意功能时，Google 及相关处理方可能在您所在国家或地区以外处理某些信息。

1. 接收方和国家

接收方可能包括 Google LLC、Google 关联公司，以及用于广告、同意管理、安全、衡量和服务运营的处理方。处理可能发生在美国以及 Google 或其处理方维护基础设施的其他国家。

2. 可能传输的信息

可能包括广告标识符、应用实例标识符、IP 地址、大致位置、设备和网络信息、应用版本、操作系统、语言、广告展示、点击和互动、诊断信息以及广告同意或隐私设置。游戏输入、参与者标签、游戏结果和所选图片本身不会由开发者提供给 Google 广告服务。

3. 时间、方式和目的

当应用请求广告、更新同意状态或打开隐私选项时，可能通过加密互联网通信进行传输。目的包括广告投放、非个性化广告、频次控制、防欺诈、同意管理、衡量、服务安全和法律合规。

4. 保留和选择

Google 及其处理方会按照其隐私政策、合同义务和适用法律保留信息。在可用时，您可以选择非个性化广告、适用于美国州隐私法的受限数据处理，或 Google 隐私选项。您也可以在设备设置中限制广告标识符、断开网络连接，或停止使用并卸载本应用。
