# 国外データ移転に関する通知

施行日: 2026-06-12
最終更新日: 2026-06-15

Lucky Pick Box は、ゲーム入力、ゲーム結果、選択した画像を開発者運営サーバーに送信しません。広告または同意機能を使用する場合、Google および関連処理者が一部の情報を利用者の国または地域外で処理することがあります。

1. 受領者および国

受領者には、Google LLC、Google 関連会社、広告、同意管理、セキュリティ、測定、サービス運営に使用される処理者が含まれる場合があります。処理は米国、および Google またはその処理者がインフラを維持するその他の国で行われることがあります。

2. 移転される可能性のある情報

広告識別子、アプリインスタンス識別子、IP アドレス、おおよその位置情報、端末およびネットワーク情報、アプリバージョン、OS、言語、広告表示、クリック、インタラクション、診断情報、広告同意またはプライバシー設定が含まれる場合があります。ゲーム入力、参加者ラベル、ゲーム結果、選択した画像自体は、開発者から Google 広告サービスに提供されません。

3. 時期、方法、目的

移転は、本アプリが広告を要求する、同意状態を更新する、またはプライバシーオプションを開く際に、暗号化されたインターネット通信を通じて行われることがあります。目的には、広告配信、非パーソナライズド広告、頻度制限、不正防止、同意管理、測定、サービスセキュリティ、法令遵守が含まれます。

4. 保存と選択

Google およびその処理者は、それぞれのプライバシーポリシー、契約上の義務、適用法に従って情報を保存します。利用可能な場合、非パーソナライズド広告、適用される米国州プライバシー法に基づく制限付きデータ処理、または Google プライバシーオプションを選択できます。また、端末設定で広告識別子を制限し、ネットワーク接続を切断し、または本アプリの使用を停止してアンインストールすることもできます。
