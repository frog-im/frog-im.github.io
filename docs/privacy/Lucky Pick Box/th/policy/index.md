# ประกาศการโอนข้อมูลระหว่างประเทศ

วันที่มีผล: 2026-06-12
อัปเดตล่าสุด: 2026-06-15

Lucky Pick Box ไม่ส่งรายการเกม ผลเกม หรือรูปภาพที่เลือกไปยังเซิร์ฟเวอร์ของผู้พัฒนา เมื่อใช้ฟีเจอร์โฆษณาหรือความยินยอม Google และผู้ประมวลผลที่เกี่ยวข้องอาจประมวลผลข้อมูลบางอย่างนอกประเทศหรือภูมิภาคของคุณ

1. ผู้รับและประเทศ

ผู้รับอาจรวมถึง Google LLC บริษัทในเครือ Google และผู้ประมวลผลที่ใช้สำหรับโฆษณา การจัดการความยินยอม ความปลอดภัย การวัดผล และการดำเนินงานบริการ การประมวลผลอาจเกิดขึ้นในสหรัฐอเมริกาและประเทศอื่นที่ Google หรือผู้ประมวลผลมีโครงสร้างพื้นฐาน

2. ข้อมูลที่อาจถูกโอน

ข้อมูลอาจรวมถึงรหัสโฆษณา รหัสอินสแตนซ์แอป ที่อยู่ IP ตำแหน่งโดยประมาณ ข้อมูลอุปกรณ์และเครือข่าย เวอร์ชันแอป ระบบปฏิบัติการ ภาษา การแสดงโฆษณา การคลิกและการโต้ตอบ ข้อมูลวินิจฉัย และการตั้งค่าความยินยอมหรือความเป็นส่วนตัวของโฆษณา รายการเกม ป้ายชื่อผู้เข้าร่วม ผลเกม และรูปภาพที่เลือกเองไม่ได้ถูกผู้พัฒนาส่งให้บริการโฆษณา Google

3. เวลา วิธี และวัตถุประสงค์

การโอนอาจเกิดผ่านการสื่อสารอินเทอร์เน็ตที่เข้ารหัสเมื่อแอปร้องขอโฆษณา อัปเดตสถานะความยินยอม หรือเปิดตัวเลือกความเป็นส่วนตัว วัตถุประสงค์รวมถึงการแสดงโฆษณา โฆษณาที่ไม่ปรับตามโปรไฟล์ การจำกัดความถี่ การป้องกันการฉ้อโกง การจัดการความยินยอม การวัดผล ความปลอดภัยของบริการ และการปฏิบัติตามกฎหมาย

4. การเก็บรักษาและตัวเลือก

Google และผู้ประมวลผลเก็บรักษาข้อมูลตามนโยบายความเป็นส่วนตัว ภาระผูกพันตามสัญญา และกฎหมายที่ใช้บังคับ เมื่อมีให้ใช้ คุณอาจเลือกโฆษณาที่ไม่ปรับตามโปรไฟล์ การประมวลผลข้อมูลแบบจำกัดสำหรับกฎหมายความเป็นส่วนตัวของรัฐสหรัฐที่เกี่ยวข้อง หรือ ตัวเลือกความเป็นส่วนตัวของ Google คุณยังสามารถจำกัดรหัสโฆษณาในการตั้งค่าอุปกรณ์ ตัดการเชื่อมต่อเครือข่าย หรือหยุดใช้และถอนการติดตั้งแอป
