# 國際資料傳輸說明

生效日期: 2026-06-12
最後更新: 2026-06-15

Lucky Pick Box 不會將遊戲輸入、遊戲結果或所選圖片傳送至開發者營運的伺服器。使用廣告或同意功能時，Google 與相關處理方可能在您所在國家或地區以外處理部分資訊。

1. 接收者與國家

接收者可能包括 Google LLC、Google 關係企業，以及用於廣告、同意管理、安全、衡量與服務營運的處理方。處理可能發生於美國，以及 Google 或其處理方維護基礎設施的其他國家。

2. 可能傳輸的資訊

可能包括廣告識別碼、應用程式執行個體識別碼、IP 位址、概略位置、裝置與網路資訊、應用程式版本、作業系統、語言、廣告曝光、點擊與互動、診斷資訊以及廣告同意或隱私設定。遊戲輸入、參與者標籤、遊戲結果和所選圖片本身不會由開發者提供給 Google 廣告服務。

3. 時間、方式與目的

當應用程式要求廣告、更新同意狀態或開啟隱私選項時，可能透過加密網際網路通訊進行傳輸。目的包括廣告投放、非個人化廣告、頻率限制、防詐欺、同意管理、衡量、服務安全與法律遵循。

4. 保留與選擇

Google 及其處理方會依其隱私權政策、契約義務與適用法律保留資訊。在可用時，您可以選擇非個人化廣告、適用於美國州隱私法的受限資料處理，或 Google 隱私選項。您也可以在裝置設定中限制廣告識別碼、斷開網路連線，或停止使用並解除安裝本應用程式。
