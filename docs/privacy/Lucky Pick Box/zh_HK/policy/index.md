# 跨境資料轉移通知

生效日期: 2026-06-12
最後更新: 2026-06-15

Lucky Pick Box 不會將遊戲輸入、遊戲結果或所選圖片傳送至開發者營運的伺服器。使用廣告或同意功能時，Google 及相關處理方可能在您所在國家或地區以外處理某些資料。

1. 接收者與國家

接收者可能包括 Google LLC、Google 關聯公司，以及用於廣告、同意管理、安全、量度和服務營運的處理方。處理可能在美國及 Google 或其處理方維持基礎設施的其他國家進行。

2. 可能轉移的資料

可能包括廣告識別碼、應用程式實例識別碼、IP 位址、概略位置、裝置與網絡資料、應用程式版本、作業系統、語言、廣告曝光、點擊與互動、診斷資料，以及廣告同意或私隱設定。遊戲輸入、參加者標籤、遊戲結果和所選圖片本身不會由開發者提供給 Google 廣告服務。

3. 時間、方式與目的

當應用程式要求廣告、更新同意狀態或開啟私隱選項時，可能透過加密互聯網通訊進行轉移。目的包括廣告投放、非個人化廣告、頻率限制、防詐騙、同意管理、量度、服務安全及法律合規。

4. 保留與選擇

Google 及其處理方會根據其私隱政策、合約義務和適用法律保留資料。在可用時，您可選擇非個人化廣告、適用於美國州私隱法的受限資料處理，或 Google 私隱選項。您亦可在裝置設定限制廣告識別碼、斷開網絡連線，或停止使用並解除安裝本應用程式。
