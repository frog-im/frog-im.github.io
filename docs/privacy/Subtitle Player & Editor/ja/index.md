# プライバシーポリシー（Subtitle Tool / Subtitle Player & Editor）

- **アプリ名:** Subtitle Player & Editor（本ポリシーでは **Subtitle Tool** とも表記します）
- **開発者:** frog-im
- **連絡先:** [g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)
- **適用開始日:** 2026-03-11

> 本ポリシーは、韓国個人情報保護法（PIPA）、GDPR / UK GDPR、スイスFADP、および関連する米国州法上のプライバシー法を参考に作成されています。地域の強行法規が適用される場合には、当該規則が優先されます。

## 1. 目的および適用範囲

本アプリは、以下の機能を提供します。

- 字幕の再生および編集
- ユーザーが選択したファイルによる動画 + 字幕の再生
- Android において他のアプリの上に表示されるフローティング字幕 / 歌詞オーバーレイ

対応する字幕処理形式には、以下が含まれる場合があります。

- `srt`
- `vtt`
- `ass`
- `ssa`
- `lrc`
- `txt`

本アプリは **ユーザーアカウントを作成せず**、また **ユーザーの字幕ファイルやメディアファイルを開発者自身のサーバーにアップロードしません**。字幕の解析、編集、プレビュー、および再生関連処理の大部分は、**端末上でローカルに**行われます。

ただし、広告配信、同意管理、法令遵守のために、**Google Mobile Ads SDK（AdMob）** や **Google UMP** などの第三者SDKが、広告識別子、端末シグナル、同意の選択内容などの情報を処理する場合があります。

## 2. 当社が処理する情報のカテゴリー

### 2-1) ユーザーが明示的に選択したファイル

本アプリは、ユーザーが明示的に選択した以下のファイルを取り扱います。

- **字幕ファイル**
  - 例: `.srt`, `.vtt`, `.ass`, `.ssa`, `.lrc`, `.txt`
  - 用途:
    - アプリ内での字幕再生
    - 字幕編集
    - オーバーレイ字幕の表示
    - 字幕の変換およびエクスポート

- **メディアファイル**
  - 例: ユーザーが選択したローカルの動画または音声ファイル
  - 用途:
    - 動画 + 字幕の再生
    - 再生中メディアに対するオーバーレイタイミングの同期

重要なポイント:

- ユーザーが選択したファイルは、端末上でローカルに処理されます。
- 本アプリは、これらのファイルを開発者自身のサーバーにアップロードしません。
- ファイルパスおよび内容は、再生、オーバーレイ、編集、保存、およびユーザーが要求した操作のためにのみ使用されます。

### 2-2) ローカル設定および保存される値

継続的な設定の提供および以前の状態の復元のため、本アプリは `SharedPreferences` またはOSが提供する同様のローカルストレージを用いて、いくつかの値を端末上にローカル保存します。

これらの値は、開発者自身のサーバーに送信されず、通常はアプリデータの消去またはアプリのアンインストール時に削除されます。

#### (1) オーバーレイ設定

例として、以下が含まれます。

- `overlay_box_x`
- `overlay_box_y`
- `overlay_text_font`
- `overlay_text_color`
- `overlay_outline_enabled`
- `overlay_outline_color`
- `overlay_outline_width`
- `overlay_force_landscape`
- `overlay_interstitial_count`

目的:

- オーバーレイ位置の復元
- オーバーレイおよびアプリ内字幕再生用の字幕スタイルの復元
- アウトライン / フォント / 画面向きの設定保持
- 一部のオーバーレイ関連フローにおける広告表示頻度ロジックの制御

#### (2) 最近の再生位置またはオーバーレイ位置

例として、以下が含まれます。

- `overlay_recent_positions`
- `video_subtitle_recent_position`

目的:

- 最近の字幕 / オーバーレイ開始位置の復元または提案
- 動画 + 字幕再生のより便利な再開

#### (3) 広告およびプライバシー設定値

例として、以下が含まれる場合があります。

- `pref_npa_always`
- `pref_us_rdp`
- `pref_child_directed`
- `pref_under_age`
- `pref_max_ad_rating`

目的:

- 広告プライバシー設定の保存
- UMP / AdMob のプライバシーおよび広告設定の適用

#### (4) ユーザーが作成した字幕出力

ユーザーが字幕ファイルを保存またはエクスポートする場合、本アプリはユーザーが選択した場所に新しい字幕ファイルを書き込むことがあります。例えば:

- ダウンロード
- システムピッカーで選択した別のフォルダ
- ユーザーが管理する保存場所

これらのユーザー保存ファイルは、ユーザーが手動で削除しない限り、アプリ削除後も端末上に残る場合があります。

#### (5) 一時ファイルおよびキャッシュ

本アプリおよび第三者ライブラリは、通常動作のために一時ファイルまたはキャッシュファイルを作成する場合があります。例えば:

- ファイルピッカーのキャッシュデータ
- 一時的な字幕変換データ
- 再生関連のキャッシュデータ

これらはローカル動作のみを目的としており、開発者自身のサーバーにはアップロードされません。

#### (6) UMP 同意状態キャッシュ

Google UMP が適用される地域では、SDK が同意状態を端末上にローカルキャッシュする場合があります。

通常、これは以下によってリセットできます。

- アプリデータの消去、または
- アプリ内にプライバシーオプション項目が存在する場合は、その中で同意内容を変更すること

### 2-3) Android オーバーレイおよび権限関連の処理

Android では、フローティング字幕オーバーレイが以下を使用する場合があります。

- `SYSTEM_ALERT_WINDOW` / 他のアプリの上に表示する権限
- `POST_NOTIFICATIONS` 権限
- オーバーレイサービスに必要なフォアグラウンドサービス通知

目的:

- 他のアプリの上に字幕オーバーレイを表示する
- オーバーレイサービスを継続して動作させる
- Android が必要なオーバーレイ / サービス通知を表示できるようにする
- 字幕進行サポートのために必要な場合、メディア通知情報を読み取る

これらの権限は、ユーザーが利用を選択したアプリ機能に対してのみ使用されます。

### 2-4) 広告、同意、および関連データ（第三者SDK）

本アプリは、以下を含む Google の広告 / 同意SDKを使用しています。

- **Google Mobile Ads SDK（AdMob）**
- **Google UMP**

本アプリは、以下を表示する場合があります。

- バナー広告
- インタースティシャル広告
- リワード広告またはリワード付きインタースティシャル広告

これらのSDKは、以下のようなデータを処理する場合があります。

- 広告識別子（例: AAID / IDFA、該当する場合）
- IPベースおよびネットワーク関連情報
- 端末およびアプリのメタデータ
- 広告とのインタラクションシグナル
- 同意の選択内容

目的には、以下が含まれる場合があります。

- 広告配信
- 広告計測およびレポート
- フリークエンシーキャップ
- 不正防止
- 法令遵守

開発者は、これらのSDKを、ユーザーの同意選択および適用法令に沿った形で設定するよう努めます。

## 3. データの処理方法および保持

- **ローカル設定および最近の位置データ**
  - アプリデータが消去されるか、アプリが削除されるまで端末上に保持されます

- **一時ファイル / キャッシュ**
  - 動作に必要な期間のみ保持され、その後、可能な範囲でアプリにより削除されるか、後にOSによって消去されます

- **ユーザーが保存した字幕ファイル**
  - ユーザーが削除するまで、ユーザーが選択した保存場所に残ります

- **第三者が取り扱う広告 / 同意データ**
  - Google のポリシーおよび適用法令に従って保持されます

| 項目 | 詳細 |

## 7. セキュリティ対策

アプリの構成上の範囲内で、開発者は以下に努めます。

- 字幕およびメディア処理の大部分を端末上で行うことで、収集を最小限にすること
- システムのファイルピッカーおよびユーザー主導のファイルアクセスを利用すること
- システム権限を透明性をもって使用すること
- 該当する場合、第三者SDKが使用する暗号化ネットワーク通信に依拠すること

保存または送信の方法に完全な安全性はありませんが、本アプリは、開発者による不要な収集を避けるよう設計されています。
