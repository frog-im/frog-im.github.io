# 隐私政策（Subtitle Tool / Subtitle Player & Editor）

- **应用名称：** Subtitle Player & Editor（在本政策中亦称为 **Subtitle Tool**）
- **开发者：** frog-im
- **联系方式：** [g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)
- **生效日期：** 2026-03-11

> 本政策参考适用法律制定，包括韩国《个人信息保护法》（PIPA）、GDPR / UK GDPR、瑞士 FADP 以及美国相关州隐私法律。如适用强制性的本地规定，则该等规定优先。

## 1. 目的与适用范围

本应用提供以下功能：

- 字幕播放与编辑
- 播放用户所选文件中的视频 + 字幕
- 在 Android 上显示于其他应用之上的悬浮字幕 / 歌词叠加层

支持处理的字幕格式可能包括：

- `srt`
- `vtt`
- `ass`
- `ssa`
- `lrc`
- `txt`

本应用**不会**创建用户账户，也**不会**将用户的字幕文件或媒体文件上传到开发者自有服务器。字幕解析、编辑、预览以及大多数与播放相关的处理均在**设备本地**完成。

但是，出于广告投放、同意管理以及法律合规目的，**Google Mobile Ads SDK（AdMob）** 和 **Google UMP** 等第三方 SDK 可能会处理某些信息，例如广告标识符、设备信号和同意选择。

---

## 2. 我们处理的信息类别

### 2-1）用户明确选择的文件

本应用会处理用户明确选择的文件，包括：

- **字幕文件**
  - 示例：`.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc`、`.txt`
  - 用途：
    - 在应用内播放字幕
    - 编辑字幕
    - 显示叠加字幕
    - 字幕转换与导出

- **媒体文件**
  - 示例：用户选择的本地视频或音频文件
  - 用途：
    - 播放视频 + 字幕
    - 使叠加层时间与当前播放媒体对齐

重要说明：

- 用户选择的文件在设备本地处理。
- 本应用不会将这些文件上传到开发者自有服务器。
- 文件路径和内容仅用于播放、叠加显示、编辑、保存以及用户请求的操作。

### 2-2）本地设置和存储的数值

为提供持久化设置并恢复先前状态，本应用会使用 `SharedPreferences` 或操作系统提供的类似本地存储，在设备本地保存某些数值。

这些数值不会发送到开发者自有服务器，通常会在清除应用数据或卸载应用时被删除。

#### （1）叠加层设置

示例包括：

- `overlay_box_x`
- `overlay_box_y`
- `overlay_text_font`
- `overlay_text_color`
- `overlay_outline_enabled`
- `overlay_outline_color`
- `overlay_outline_width`
- `overlay_force_landscape`
- `overlay_interstitial_count`

目的：

- 恢复叠加层位置
- 恢复叠加层及应用内字幕播放的字幕样式
- 保留描边 / 字体 / 屏幕方向偏好
- 控制某些叠加层相关流程中的广告显示频率逻辑

#### （2）最近的播放或叠加层位置

示例包括：

- `overlay_recent_positions`
- `video_subtitle_recent_position`

目的：

- 恢复或建议最近的字幕/叠加层起始位置
- 更方便地继续播放视频 + 字幕

#### （3）广告和隐私偏好数值

示例可能包括：

- `pref_npa_always`
- `pref_us_rdp`
- `pref_child_directed`
- `pref_under_age`
- `pref_max_ad_rating`

目的：

- 存储广告隐私选择
- 应用 UMP / AdMob 的隐私和广告配置设置

#### （4）用户创建的字幕输出文件

当用户保存或导出字幕文件时，本应用可能会将新的字幕文件写入用户所选择的位置，例如：

- 下载目录
- 通过系统文件选择器选择的其他文件夹
- 由用户管理的存储位置

除非用户手动删除，否则这些用户保存的文件在应用删除后仍可能保留在设备中。

#### （5）临时文件和缓存

本应用和第三方库可能会为正常运行创建临时文件或缓存文件，例如：

- 文件选择器缓存数据
- 临时字幕转换数据
- 与播放相关的缓存数据

这些内容仅用于本地运行，不会上传到开发者自有服务器。

#### （6）UMP 同意状态缓存

在适用 Google UMP 的地区，SDK 可能会在设备本地缓存同意状态。

通常可通过以下方式重置：

- 清除应用数据，或
- 在应用内可用的隐私选项入口中更改同意选择

### 2-3）Android 悬浮层与权限相关处理

在 Android 上，悬浮字幕叠加层可能使用：

- `SYSTEM_ALERT_WINDOW` / 在其他应用上层显示权限
- `POST_NOTIFICATIONS` 权限
- 叠加层服务所需的前台服务通知

目的：

- 在其他应用上方显示字幕叠加层
- 保持叠加层服务运行
- 允许 Android 显示所需的叠加层 / 服务通知
- 在需要支持字幕进度时读取媒体通知信息

这些权限仅用于用户主动选择使用的应用功能。

### 2-4）广告、同意及相关数据（第三方 SDK）

本应用使用 Google 的广告 / 同意 SDK，包括：

- **Google Mobile Ads SDK（AdMob）**
- **Google UMP**

本应用可能显示：

- 横幅广告
- 插页广告
- 激励广告或激励插页广告

这些 SDK 可能会处理如下数据：

- 广告标识符（例如适用时的 AAID / IDFA）
- 基于 IP 的信息及网络相关信息
- 设备和应用元数据
- 广告交互信号
- 同意选择

用途可能包括：

- 广告投放
- 广告衡量与报告
- 频次控制
- 欺诈预防
- 法律合规

开发者致力于按照用户同意选择和适用法律来配置这些 SDK。

## 3. 我们如何处理和保存数据

- **本地设置及最近位置数据**
  - 保存在设备上，直到应用数据被清除或应用被删除

- **临时文件 / 缓存**
  - 仅在运行所需期间保留，随后由应用在可行时删除，或由操作系统稍后清理

- **用户保存的字幕文件**
  - 保留在用户选择的保存位置，直到用户删除它们

- **由第三方处理的广告 / 同意数据**
  - 根据 Google 政策及适用法律保留

## 7. 安全措施

在本应用架构允许的范围内，开发者致力于：

- 通过将大多数字幕和媒体处理保留在设备本地来尽量减少收集

没有任何存储或传输方式是绝对安全的，但本应用的设计旨在避免开发者进行不必要的数据收集。
