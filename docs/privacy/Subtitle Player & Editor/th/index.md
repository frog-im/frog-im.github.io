## 1. วัตถุประสงค์และขอบเขต

แอปนี้ให้บริการดังต่อไปนี้:

- การเล่นและแก้ไขคำบรรยาย
- การเล่นวิดีโอพร้อมคำบรรยายจากไฟล์ที่ผู้ใช้เลือก
- โอเวอร์เลย์คำบรรยาย / เนื้อเพลงแบบลอยที่แสดงทับแอปอื่นบน Android

รูปแบบคำบรรยายที่รองรับอาจรวมถึง:

- `srt`
- `vtt`
- `ass`
- `ssa`
- `lrc`
- `txt`

แอปนี้ **ไม่** สร้างบัญชีผู้ใช้ และ **ไม่** อัปโหลดไฟล์คำบรรยายหรือไฟล์สื่อของผู้ใช้ไปยังเซิร์ฟเวอร์ของผู้พัฒนาเอง การแยกวิเคราะห์คำบรรยาย การแก้ไข การแสดงตัวอย่าง และการประมวลผลที่เกี่ยวข้องกับการเล่นส่วนใหญ่ จะดำเนินการ **ภายในอุปกรณ์ของผู้ใช้แบบภายในเครื่อง**

อย่างไรก็ตาม เพื่อวัตถุประสงค์ด้านโฆษณา การจัดการความยินยอม และการปฏิบัติตามกฎหมาย SDK ของบุคคลที่สาม เช่น **Google Mobile Ads SDK (AdMob)** และ **Google UMP** อาจประมวลผลข้อมูลบางอย่าง เช่น ตัวระบุโฆษณา สัญญาณของอุปกรณ์ และตัวเลือกความยินยอม

## 2. ประเภทของข้อมูลที่เราประมวลผล

### 2-1) ไฟล์ที่ผู้ใช้เลือกอย่างชัดเจน

แอปนี้ทำงานร่วมกับไฟล์ที่ผู้ใช้เลือกอย่างชัดเจน ซึ่งรวมถึง:

- **ไฟล์คำบรรยาย**
  - ตัวอย่าง: `.srt`, `.vtt`, `.ass`, `.ssa`, `.lrc`, `.txt`
  - การใช้งาน:
    - เล่นคำบรรยายภายในแอป
    - แก้ไขคำบรรยาย
    - แสดงคำบรรยายแบบโอเวอร์เลย์
    - แปลงและส่งออกคำบรรยาย

- **ไฟล์สื่อ**
  - ตัวอย่าง: ไฟล์วิดีโอหรือไฟล์เสียงภายในเครื่องที่ผู้ใช้เลือก
  - การใช้งาน:
    - เล่นวิดีโอพร้อมคำบรรยาย
    - จัดแนวเวลาของโอเวอร์เลย์ให้ตรงกับสื่อที่กำลังเล่นอยู่

ประเด็นสำคัญ:

- ไฟล์ที่ผู้ใช้เลือกจะถูกประมวลผลภายในอุปกรณ์แบบภายในเครื่อง
- แอปนี้จะไม่อัปโหลดไฟล์เหล่านั้นไปยังเซิร์ฟเวอร์ของผู้พัฒนาเอง
- เส้นทางไฟล์และเนื้อหาไฟล์จะถูกใช้เพื่อการเล่น การแสดงโอเวอร์เลย์ การแก้ไข การบันทึก และการดำเนินการที่ผู้ใช้ร้องขอเท่านั้น

### 2-2) การตั้งค่าในเครื่องและค่าที่จัดเก็บไว้

เพื่อให้สามารถเก็บการตั้งค่าแบบต่อเนื่องและกู้คืนสถานะก่อนหน้า แอปนี้จะจัดเก็บค่าบางอย่างไว้ภายในอุปกรณ์โดยใช้ `SharedPreferences` หรือระบบจัดเก็บข้อมูลในเครื่องลักษณะเดียวกันที่ระบบปฏิบัติการมีให้

ค่าเหล่านี้จะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของผู้พัฒนาเอง และโดยปกติจะถูกลบออกเมื่อมีการล้างข้อมูลแอปหรือถอนการติดตั้งแอป

#### (1) การตั้งค่าโอเวอร์เลย์

ตัวอย่างเช่น:

- `overlay_box_x`
- `overlay_box_y`
- `overlay_text_font`
- `overlay_text_color`
- `overlay_outline_enabled`
- `overlay_outline_color`
- `overlay_outline_width`
- `overlay_force_landscape`
- `overlay_interstitial_count`

วัตถุประสงค์:

- กู้คืนตำแหน่งของโอเวอร์เลย์
- กู้คืนรูปแบบคำบรรยายสำหรับโอเวอร์เลย์และการเล่นคำบรรยายภายในแอป
- เก็บค่าที่เกี่ยวข้องกับเส้นขอบ / แบบอักษร / การวางแนวหน้าจอ
- ควบคุมตรรกะความถี่ในการแสดงโฆษณาในบางขั้นตอนที่เกี่ยวข้องกับโอเวอร์เลย์

#### (2) ตำแหน่งการเล่นหรือโอเวอร์เลย์ล่าสุด

ตัวอย่างเช่น:

- `overlay_recent_positions`
- `video_subtitle_recent_position`

วัตถุประสงค์:

- กู้คืนหรือแนะนำตำแหน่งเริ่มต้นล่าสุดของคำบรรยาย/โอเวอร์เลย์
- เล่นวิดีโอพร้อมคำบรรยายต่อได้สะดวกยิ่งขึ้น

#### (3) ค่าการตั้งค่าด้านโฆษณาและความเป็นส่วนตัว

ตัวอย่างอาจรวมถึง:

- `pref_npa_always`
- `pref_us_rdp`
- `pref_child_directed`
- `pref_under_age`
- `pref_max_ad_rating`

วัตถุประสงค์:

- จัดเก็บตัวเลือกความเป็นส่วนตัวเกี่ยวกับโฆษณา
- ใช้การตั้งค่าความเป็นส่วนตัวและการกำหนดค่าโฆษณาของ UMP / AdMob

#### (4) ไฟล์คำบรรยายที่ผู้ใช้สร้างขึ้น

เมื่อผู้ใช้บันทึกหรือส่งออกไฟล์คำบรรยาย แอปอาจเขียนไฟล์คำบรรยายใหม่ไปยังตำแหน่งที่ผู้ใช้เลือก เช่น:

- Downloads
- โฟลเดอร์อื่นที่เลือกผ่านตัวเลือกไฟล์ของระบบ
- ตำแหน่งจัดเก็บข้อมูลที่ผู้ใช้จัดการเอง

ไฟล์ที่ผู้ใช้บันทึกเหล่านี้อาจยังคงอยู่ในอุปกรณ์แม้หลังจากลบแอป เว้นแต่ผู้ใช้จะลบออกด้วยตนเอง

#### (5) ไฟล์ชั่วคราวและแคช

แอปและไลบรารีของบุคคลที่สามอาจสร้างไฟล์ชั่วคราวหรือไฟล์แคชสำหรับการทำงานตามปกติ เช่น:

- ข้อมูลแคชของตัวเลือกไฟล์
- ข้อมูลชั่วคราวสำหรับการแปลงคำบรรยาย
- ข้อมูลแคชที่เกี่ยวข้องกับการเล่น

ข้อมูลเหล่านี้มีไว้เพื่อการทำงานภายในเครื่องเท่านั้น และจะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของผู้พัฒนาเอง

#### (6) แคชสถานะความยินยอมของ UMP

ในภูมิภาคที่ Google UMP มีผลบังคับใช้ SDK อาจเก็บแคชสถานะความยินยอมไว้ในอุปกรณ์แบบภายในเครื่อง

โดยทั่วไปสามารถรีเซ็ตได้โดย:

- ล้างข้อมูลแอป หรือ
- เปลี่ยนตัวเลือกความยินยอมภายในแอป หากมีเมนูตัวเลือกความเป็นส่วนตัวให้ใช้งาน

### 2-3) การประมวลผลที่เกี่ยวข้องกับโอเวอร์เลย์ Android และสิทธิ์การใช้งาน

บน Android โอเวอร์เลย์คำบรรยายแบบลอยอาจใช้:

- สิทธิ์ `SYSTEM_ALERT_WINDOW` / การแสดงผลทับแอปอื่น
- สิทธิ์ `POST_NOTIFICATIONS`
- การแจ้งเตือน foreground service ที่จำเป็นสำหรับบริการโอเวอร์เลย์

วัตถุประสงค์:

- แสดงโอเวอร์เลย์คำบรรยายเหนือแอปอื่น
- ทำให้บริการโอเวอร์เลย์ทำงานต่อเนื่อง
- อนุญาตให้ Android แสดงการแจ้งเตือนที่จำเป็นสำหรับโอเวอร์เลย์ / บริการ
- อ่านข้อมูลจากการแจ้งเตือนสื่อเมื่อจำเป็นสำหรับการรองรับการเลื่อนคำบรรยายตามการเล่น

สิทธิ์เหล่านี้จะถูกใช้เฉพาะสำหรับฟังก์ชันของแอปที่ผู้ใช้เลือกใช้งานเท่านั้น

### 2-4) โฆษณา ความยินยอม และข้อมูลที่เกี่ยวข้อง (SDK ของบุคคลที่สาม)

แอปนี้ใช้ SDK ด้านโฆษณา / ความยินยอมของ Google ซึ่งรวมถึง:

- **Google Mobile Ads SDK (AdMob)**
- **Google UMP**

แอปอาจแสดง:

- โฆษณาแบนเนอร์
- โฆษณาคั่นหน้า
- โฆษณาแบบมีรางวัล หรือโฆษณาคั่นหน้าแบบมีรางวัล

SDK เหล่านี้อาจประมวลผลข้อมูล เช่น:

- ตัวระบุโฆษณา (เช่น AAID / IDFA หากเกี่ยวข้อง)
- ข้อมูลที่อิงจาก IP และข้อมูลที่เกี่ยวข้องกับเครือข่าย
- ข้อมูลเมตาของอุปกรณ์และแอป
- สัญญาณการโต้ตอบกับโฆษณา
- ตัวเลือกความยินยอม

วัตถุประสงค์อาจรวมถึง:

- การแสดงโฆษณา
- การวัดผลและการรายงานโฆษณา
- การจำกัดความถี่
- การป้องกันการทุจริต
- การปฏิบัติตามกฎหมาย

ผู้พัฒนามุ่งมั่นที่จะกำหนดค่า SDK เหล่านี้ให้สอดคล้องกับตัวเลือกความยินยอมของผู้ใช้และกฎหมายที่ใช้บังคับ

## 3. วิธีที่เราประมวลผลและเก็บรักษาข้อมูล

- **การตั้งค่าในเครื่องและข้อมูลตำแหน่งล่าสุด**
  - จะถูกเก็บไว้ในอุปกรณ์จนกว่าจะมีการล้างข้อมูลแอปหรือแอปถูกลบออก

- **ไฟล์ชั่วคราว / แคช**
  - จะถูกเก็บไว้เท่าที่จำเป็นต่อการทำงาน จากนั้นจะถูกลบโดยแอปเมื่อทำได้ในทางปฏิบัติ หรือถูกระบบปฏิบัติการล้างในภายหลัง

- **ไฟล์คำบรรยายที่ผู้ใช้บันทึก**
  - จะยังคงอยู่ในตำแหน่งที่ผู้ใช้เลือกบันทึกจนกว่าผู้ใช้จะลบออก

- **ข้อมูลโฆษณา / ความยินยอมที่ดำเนินการโดยบุคคลที่สาม**
  - จะถูกเก็บรักษาตามนโยบายของ Google และกฎหมายที่ใช้บังคับ

## 4. การประมวลผลโดยบุคคลที่สามและการโอนข้อมูลข้ามพรมแดน

สำหรับโฆษณาและการจัดการความยินยอม ข้อมูลบางอย่างอาจถูกประมวลผลโดย Google และพันธมิตรที่เกี่ยวข้อง

| รายการ | รายละเอียด |
|---|---|
| ผู้รับข้อมูล | Google LLC และบริษัทในเครือ / ผู้ประมวลผลที่เกี่ยวข้อง |
| วัตถุประสงค์ | การแสดงโฆษณา การวัดผล การป้องกันการทุจริต การจัดการความยินยอม และการปฏิบัติตามกฎหมาย |
| ข้อมูลที่อาจถูกประมวลผล | ตัวระบุโฆษณา ข้อมูลอุปกรณ์/แอป ข้อมูลที่อิงจาก IP ข้อมูลการโต้ตอบกับโฆษณา สถานะความยินยอม |
| ปลายทาง | สหรัฐอเมริกาและภูมิภาคอื่นที่โครงสร้างพื้นฐานของ Google ดำเนินงานอยู่ |
| ระยะเวลาการเก็บรักษา | เป็นไปตามนโยบายของ Google และกฎหมายที่ใช้บังคับ |

ผู้พัฒนามุ่งมั่นที่จะทำให้การเปิดเผยข้อมูลความเป็นส่วนตัวในสโตร์แอปสอดคล้องกับพฤติกรรมจริงของ SDK

## 5. สิทธิและตัวเลือกของคุณ

ขึ้นอยู่กับเขตอำนาจศาลของคุณ คุณอาจมีสิทธิดังต่อไปนี้:

- การเข้าถึง
- การแก้ไข
- การลบ
- การจำกัดการประมวลผล
- การโอนย้ายข้อมูล
- การคัดค้าน
- การถอนความยินยอม ในกรณีที่ความยินยอมเป็นฐานทางกฎหมาย

การควบคุมในทางปฏิบัติรวมถึง:

- เปลี่ยนตัวเลือกโฆษณา / ความเป็นส่วนตัวภายในแอป หากมีให้ใช้งาน
- ล้างข้อมูลแอปเพื่อลบการตั้งค่าในเครื่องและค่ากำหนดที่ถูกแคชไว้
- ถอนการติดตั้งแอป
