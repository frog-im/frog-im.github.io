## 1. 목적 및 적용 범위

이 앱은 다음 기능을 제공합니다.

- 자막 재생 및 편집
- 사용자가 선택한 파일을 이용한 비디오 + 자막 재생
- Android에서 다른 앱 위에 표시되는 플로팅 자막 / 가사 오버레이

지원되는 자막 처리 형식에는 다음이 포함될 수 있습니다.

- `srt`
- `vtt`
- `ass`
- `ssa`
- `lrc`
- `txt`

이 앱은 **사용자 계정을 생성하지 않으며**, **사용자의 자막 파일이나 미디어 파일을 개발자 자체 서버에 업로드하지 않습니다**. 자막 파싱, 편집, 미리보기 및 대부분의 재생 관련 처리는 **기기 내에서 로컬로** 수행됩니다.

다만 광고, 동의 관리 및 법적 준수를 위해 **Google Mobile Ads SDK (AdMob)** 및 **Google UMP**와 같은 제3자 SDK가 광고 식별자, 기기 신호, 동의 선택값 등의 일부 정보를 처리할 수 있습니다.

## 2. 당사가 처리하는 정보의 범주

### 2-1) 사용자가 명시적으로 선택한 파일

이 앱은 사용자가 명시적으로 선택한 다음 파일을 처리합니다.

- **자막 파일**
  - 예시: `.srt`, `.vtt`, `.ass`, `.ssa`, `.lrc`, `.txt`
  - 사용 목적:
    - 앱 내 자막 재생
    - 자막 편집
    - 오버레이 자막 표시
    - 자막 변환 및 내보내기

- **미디어 파일**
  - 예시: 사용자가 선택한 로컬 비디오 또는 오디오 파일
  - 사용 목적:
    - 비디오 + 자막 재생
    - 현재 재생 중인 미디어에 맞춘 오버레이 타이밍 정렬

중요한 사항:

- 사용자가 선택한 파일은 기기 내에서 로컬로 처리됩니다.
- 이 앱은 해당 파일을 개발자 자체 서버에 업로드하지 않습니다.
- 파일 경로와 내용은 재생, 오버레이, 편집, 저장 및 사용자가 요청한 작업을 위해서만 사용됩니다.

### 2-2) 로컬 설정 및 저장 값

지속적인 설정 제공 및 이전 상태 복원을 위해, 이 앱은 `SharedPreferences` 또는 운영체제가 제공하는 유사한 로컬 저장소를 사용하여 일부 값을 기기에 로컬로 저장합니다.

이 값들은 개발자 자체 서버로 전송되지 않으며, 일반적으로 앱 데이터가 삭제되거나 앱이 제거되면 함께 삭제됩니다.

#### (1) 오버레이 설정

예시는 다음과 같습니다.

- `overlay_box_x`
- `overlay_box_y`
- `overlay_text_font`
- `overlay_text_color`
- `overlay_outline_enabled`
- `overlay_outline_color`
- `overlay_outline_width`
- `overlay_force_landscape`
- `overlay_interstitial_count`

목적:

- 오버레이 위치 복원
- 오버레이 및 앱 내 자막 재생용 자막 스타일 복원
- 외곽선 / 글꼴 / 화면 방향 설정 유지
- 일부 오버레이 관련 흐름에서 광고 표시 빈도 로직 제어

#### (2) 최근 재생 또는 오버레이 위치

예시는 다음과 같습니다.

- `overlay_recent_positions`
- `video_subtitle_recent_position`

목적:

- 최근 자막/오버레이 시작 위치 복원 또는 제안
- 비디오 + 자막 재생을 보다 편리하게 이어서 재생

#### (3) 광고 및 개인정보 설정 값

예시는 다음을 포함할 수 있습니다.

- `pref_npa_always`
- `pref_us_rdp`
- `pref_child_directed`
- `pref_under_age`
- `pref_max_ad_rating`

목적:

- 광고 개인정보 선택값 저장
- UMP / AdMob 개인정보 및 광고 설정 적용

#### (4) 사용자가 생성한 자막 출력물

사용자가 자막 파일을 저장하거나 내보내는 경우, 앱은 사용자가 선택한 위치에 새로운 자막 파일을 저장할 수 있습니다. 예를 들면 다음과 같습니다.

- 다운로드
- 시스템 파일 선택기를 통해 선택한 다른 폴더
- 사용자가 관리하는 저장 위치

이렇게 저장된 사용자 자막 파일은 사용자가 직접 삭제하지 않는 한, 앱 삭제 후에도 기기에 남아 있을 수 있습니다.

#### (5) 임시 파일 및 캐시

앱과 제3자 라이브러리는 정상적인 작동을 위해 다음과 같은 임시 파일 또는 캐시 파일을 생성할 수 있습니다.

- 파일 선택기 캐시 데이터
- 임시 자막 변환 데이터
- 재생 관련 캐시 데이터

이들은 로컬 작동만을 위한 것이며 개발자 자체 서버로 업로드되지 않습니다.

#### (6) UMP 동의 상태 캐시

Google UMP가 적용되는 지역에서는, SDK가 동의 상태를 기기에 로컬로 캐시할 수 있습니다.

일반적으로 이는 다음 방법으로 초기화할 수 있습니다.

- 앱 데이터 삭제, 또는
- 앱 내 개인정보 옵션 항목이 제공되는 경우 해당 메뉴에서 동의 선택 변경

### 2-3) Android 오버레이 및 권한 관련 처리

Android에서 플로팅 자막 오버레이는 다음을 사용할 수 있습니다.

- `SYSTEM_ALERT_WINDOW` / 다른 앱 위에 표시 권한
- `POST_NOTIFICATIONS` 권한
- 오버레이 서비스에 필요한 포그라운드 서비스 알림

목적:

- 다른 앱 위에 자막 오버레이 표시
- 오버레이 서비스 실행 유지
- Android가 필요한 오버레이 / 서비스 알림을 표시할 수 있도록 함
- 자막 진행 지원이 필요한 경우 미디어 알림 정보 읽기

이러한 권한은 사용자가 이용하기로 선택한 앱 기능에 대해서만 사용됩니다.

### 2-4) 광고, 동의 및 관련 데이터 (제3자 SDK)

이 앱은 다음을 포함한 Google 광고 / 동의 SDK를 사용합니다.

- **Google Mobile Ads SDK (AdMob)**
- **Google UMP**

이 앱은 다음 광고 형식을 표시할 수 있습니다.

- 배너 광고
- 전면 광고(Interstitial)
- 리워드 광고 또는 리워드형 전면 광고

이러한 SDK는 다음과 같은 데이터를 처리할 수 있습니다.

- 광고 식별자(예: 해당되는 경우 AAID / IDFA)
- IP 기반 정보 및 네트워크 관련 정보
- 기기 및 앱 메타데이터
- 광고 상호작용 신호
- 동의 선택값

처리 목적에는 다음이 포함될 수 있습니다.

- 광고 제공
- 광고 측정 및 보고
- 빈도 제한
- 부정행위 방지
- 법적 준수

개발자는 이러한 SDK가 사용자의 동의 선택 및 적용 법령에 부합하도록 구성되도록 노력합니다.
