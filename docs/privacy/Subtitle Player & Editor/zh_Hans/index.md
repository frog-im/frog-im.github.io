# 隐私政策（Subtitle Tool / Subtitle Player & Editor）

- **应用名称：** Subtitle Tool（商店中可能显示为“Subtitle Player & Editor”）  
- **开发者：** frog-im  
- **联系邮箱：** [g.ns.0700g@gmail.com](mailto:g.ns.0700g@gmail.com)  
- **生效日期：** 2025-12-12  

> 本隐私政策参考了包括韩国《个人信息保护法》（PIPA）、GDPR / UK GDPR、瑞士 FADP 以及相关美国州隐私法在内的适用法律。如果相关司法辖区有更严格或特殊的规定，将优先适用这些规定。

---

## 1. 适用范围与目的

本应用的主要功能是：  
- 对设备中保存的**音频文件元数据**（标题、艺术家等）进行编辑；  
- 在设备上显示**歌词/字幕浮动窗口（overlay）**。  

应用本身**不创建用户账号**，也**不会将用户内容上传到开发者自有服务器**。绝大部分处理都在**用户本地设备**上完成。

不过，为了**投放与衡量广告**以及**遵守相关法律要求**，本应用会集成第三方 SDK（例如 Google Mobile Ads SDK（AdMob）、Google UMP）。这些第三方可能会处理诸如**广告标识符**等信息。  
用户同意流程和隐私选项由 **Google UMP（User Messaging Platform）** 提示和管理。

---

## 2. 我们处理的信息类别

### 2-1) 用户明确选择的文件

- **音频 / 封面图像路径与内容：**  
  仅在本地用于读取、编辑元数据并重新保存。  
- **FFmpegKit** 仅在本地设备上运行，用于编码、元数据写入、封面提取等。  
- 应用**不会将这些文件内容上传到开发者服务器**。

### 2-2) 本地设置与存储值

为了提供核心功能和使用便利，本应用会在设备上本地保存以下信息。  
这些数据**不会发送给开发者服务器**，在用户删除应用或清空应用数据时一并删除。

#### (1) 偏好设置（`shared_preferences`）

| 类型 | 键 / 内容 | 目的 | 存储位置 | 删除方式 |
|---|---|---|---|---|
| 浮窗位置与字体 | `overlay_box_x`, `overlay_box_y`, `overlay_text_font` | 记住歌词浮窗位置与字号，便于下次使用 | 设备 SharedPreferences | 删除应用或清除应用数据时移除 |
| 广告 / 隐私设置 | `pref_npa_always`, `pref_us_rdp`, `pref_child_directed`, `pref_under_age`, `pref_max_ad_rating` | 非个性化广告标记、美国 RDP 设置、COPPA 标记、年龄标记、广告分级上限等 | 设备 SharedPreferences | 同上 |

#### (2) 临时文件（系统临时目录）

- **示例：** `cover_*.jpg`, `tmp_*.flac`  
- **用途：** 封面提取、FLAC 标签写入、转码过程中的中间文件  
- **位置：** 操作系统提供的临时文件夹（例如 `systemTemp`）  
- **保留期限：** 使用后尽量由应用自动删除；部分文件可能暂时保留在 OS 缓存中，之后由系统自行清理

#### (3) 用户选择的保存位置（SAF）

- 当用户使用“**另存为**”或类似功能时，最终的音频文件会保存到用户指定的位置（例如“下载”文件夹或云盘）。  
- 这些文件位于**外部存储空间**，即使卸载应用，也**不会自动删除**。如需删除，需用户自行操作。

#### (4) 同意状态（UMP SDK 缓存）

- 在 EEA / 英国 / 瑞士等地区，UMP SDK 会在本地缓存用户的广告同意状态。  
- 用户可通过删除应用数据或在应用内的**隐私选项（Privacy Options）**菜单中重置或调整设置（在提供该入口的情况下）。

---

### 2-3) 与广告及同意管理相关的第三方数据处理

- **Google Mobile Ads SDK（AdMob）和 Google UMP** 可能收集或处理以下信息：  
  - 广告标识符（AAID / IDFA）  
  - IP 地址或 IP 段  
  - 设备信息、应用版本信息  
  - 广告展示、点击等交互信号  
  - 同意状态与相关配置等  

- **用途包括：**  
  - 广告投放与展示  
  - 频次控制（frequency capping）  
  - 防止欺诈及滥用  
  - 广告效果统计与分析  
  - 遵守地区性隐私与同意相关法规  

- **地区差异：**  
  - 在 EEA / 英国 / 瑞士等需要事先同意的地区，会通过 UMP 弹窗收集同意，并在应用内提供**隐私选项入口**以便用户之后进行修改。  
  - 在没有这类要求的地区（如韩国），隐私选项界面可能**不会额外显示**。

## 3. 处理方式与保存期限

- **本地设置：**  
  存储在用户设备本地，直到用户删除应用数据或卸载应用。  
- **临时文件：**  
  在封面提取、转码等处理中生成，处理完成后尽量删除；剩余文件则可能保留在系统缓存中，由 OS 定期清理。  
- **广告 / 同意相关数据（第三方）：**  
  由相应的第三方（如 Google）按照其隐私政策中说明的期限与方式保存和处理。

## 4. 向第三方的传输与跨境数据流动

为了广告投放与同意管理，本应用会使相关信息在 Google 的基础设施上进行处理，这可能涉及跨境传输。

| 项目 | 内容 |
|---|---|
| **接收方** | Google LLC 及其关联公司/分包处理方 |
| **数据目的地** | 美国及 Google 部署基础设施的其他地区 |
| **处理目的** | 广告投放、效果测量、欺诈防护、合规管理、同意记录管理等 |
| **处理数据示例** | 广告标识符、IP 信息、设备与应用信息、广告交互信号、同意状态等 |
| **保留期限** | 依据 Google 自身政策 |
| **拒绝的影响** | 个性化广告功能可能受限，但可继续展示非个性化广告 |

我们会遵守 **Google Play“数据安全”披露**要求，并尽量保持披露内容与实际处理情况一致。

## 5. 您的权利及行使方式

- **退出个性化广告 / 调整同意设置**  
  - 在 EEA / 英国 / 瑞士：可通过应用内的 **“设置 → 隐私选项（Privacy Options）”** 调整。  
  - 其他地区：可通过操作系统设置重置广告 ID、限制广告跟踪或关闭个性化广告。  

- **重置本地信息**  
  - 通过删除应用数据或卸载应用，可以清除覆盖位置、字体大小以及其他本地设置。

- 根据 **GDPR / UK GDPR / 瑞士 FADP / 美国各州隐私法**，您可能享有访问、更正、删除、限制处理、数据可携带、撤回同意等权利。  
  与广告相关且由 Google 处理的数据，请通过 **Google 提供的机制**行使相关权利。

## 7. 安全措施

我们通过以下方式尽量降低风险：

- 尽量**最小化收集与存储**个人相关信息  
- 限制临时文件的使用范围，并在处理后尝试删除  
- 所有处理都在操作系统授权的权限范围内进行  
- 对第三方传输使用 **TLS 等加密方式**（依据第三方 SDK 的实现）
