## 1. Цель и сфера применения

Это приложение предоставляет:

- воспроизведение и редактирование субтитров
- воспроизведение видео + субтитров из файлов, выбранных пользователем
- плавающее наложение субтитров / текста песен, отображаемое поверх других приложений на Android

Поддерживаемая обработка субтитров может включать такие форматы, как:

- `srt`
- `vtt`
- `ass`
- `ssa`
- `lrc`
- `txt`

Приложение **не** создает учетную запись пользователя и **не** загружает пользовательские файлы субтитров или мультимедиа на собственные серверы разработчика. Разбор, редактирование, предварительный просмотр субтитров и большая часть обработки, связанной с воспроизведением, выполняются **локально на устройстве**.

Однако в целях показа рекламы, управления согласием и соблюдения законодательства сторонние SDK, такие как **Google Mobile Ads SDK (AdMob)** и **Google UMP**, могут обрабатывать определенную информацию, например рекламные идентификаторы, сигналы устройства и варианты выбора согласия.

## 2. Категории информации, которую мы обрабатываем

### 2-1) Файлы, явно выбранные пользователем

Приложение взаимодействует с файлами, которые пользователь явно выбирает, включая:

- **Файлы субтитров**
  - Примеры: `.srt`, `.vtt`, `.ass`, `.ssa`, `.lrc`, `.txt`
  - Использование:
    - воспроизведение субтитров внутри приложения
    - редактирование субтитров
    - отображение субтитров в наложении
    - преобразование и экспорт субтитров

- **Мультимедийные файлы**
  - Примеры: локальные видео- или аудиофайлы, выбранные пользователем
  - Использование:
    - воспроизведение видео + субтитров
    - синхронизация времени наложения с воспроизводимым в данный момент мультимедиа

Важные моменты:

- Файлы, выбранные пользователем, обрабатываются локально на устройстве.
- Приложение не загружает эти файлы на собственные серверы разработчика.
- Пути к файлам и их содержимое используются только для воспроизведения, наложения, редактирования, сохранения и действий, запрошенных пользователем.

### 2-2) Локальные настройки и сохраненные значения

Для предоставления постоянных настроек и восстановления предыдущего состояния приложение сохраняет некоторые значения локально на устройстве с использованием `SharedPreferences` или аналогичного локального хранилища, предоставляемого ОС.

Эти значения не отправляются на собственные серверы разработчика и обычно удаляются, если данные приложения очищаются или приложение удаляется.

#### (1) Настройки наложения

Примеры включают:

- `overlay_box_x`
- `overlay_box_y`
- `overlay_text_font`
- `overlay_text_color`
- `overlay_outline_enabled`
- `overlay_outline_color`
- `overlay_outline_width`
- `overlay_force_landscape`
- `overlay_interstitial_count`

Цель:

- восстановление положения наложения
- восстановление стиля субтитров для наложения и воспроизведения субтитров внутри приложения
- сохранение предпочтений контура / шрифта / ориентации
- управление логикой частоты показа рекламы в некоторых процессах, связанных с наложением

#### (2) Недавние позиции воспроизведения или наложения

Примеры включают:

- `overlay_recent_positions`
- `video_subtitle_recent_position`

Цель:

- восстановление или предложение недавних стартовых позиций субтитров/наложения
- более удобное возобновление воспроизведения видео + субтитров

#### (3) Значения предпочтений рекламы и конфиденциальности

Примеры могут включать:

- `pref_npa_always`
- `pref_us_rdp`
- `pref_child_directed`
- `pref_under_age`
- `pref_max_ad_rating`

Цель:

- хранение настроек конфиденциальности рекламы
- применение настроек конфиденциальности и конфигурации рекламы UMP / AdMob

#### (4) Созданные пользователем файлы субтитров

Когда пользователь сохраняет или экспортирует файлы субтитров, приложение может записывать новые файлы субтитров в место, выбранное пользователем, например:

- Загрузки
- другая папка, выбранная через системный проводник
- место хранения, управляемое пользователем

Эти сохраненные пользователем файлы могут оставаться на устройстве после удаления приложения, если пользователь не удалит их вручную.

#### (5) Временные файлы и кэш

Приложение и сторонние библиотеки могут создавать временные файлы или кэш-файлы для нормальной работы, например:

- кэш данных выбора файлов
- временные данные преобразования субтитров
- кэш-данные, связанные с воспроизведением

Они предназначены только для локальной работы и не загружаются на собственные серверы разработчика.

#### (6) Кэш состояния согласия UMP

В регионах, где применяется Google UMP, SDK может кэшировать состояние согласия локально на устройстве.

Обычно это можно сбросить путем:

- очистки данных приложения, или
- изменения выбора согласия внутри приложения, если доступен раздел параметров конфиденциальности

### 2-3) Обработка, связанная с Android Overlay и разрешениями

На Android плавающее наложение субтитров может использовать:

- разрешение `SYSTEM_ALERT_WINDOW` / отображение поверх других приложений
- разрешение `POST_NOTIFICATIONS`
- уведомление foreground service, необходимое для сервиса наложения

Цель:

- отображение наложения субтитров поверх других приложений
- поддержание работы сервиса наложения
- предоставление Android возможности показывать необходимые уведомления наложения / сервиса
- чтение информации из медиа-уведомлений при необходимости для поддержки продвижения субтитров

Эти разрешения используются только для функций приложения, которые пользователь выбирает использовать.

### 2-4) Реклама, согласие и связанные данные (сторонние SDK)

Приложение использует SDK Google для рекламы / согласия, включая:

- **Google Mobile Ads SDK (AdMob)**
- **Google UMP**

Приложение может показывать:

- баннерную рекламу
- межстраничную рекламу
- рекламу с вознаграждением или межстраничную рекламу с вознаграждением

Эти SDK могут обрабатывать такие данные, как:

- рекламные идентификаторы, например AAID / IDFA, где применимо
- информацию на основе IP и сетевую информацию
- метаданные устройства и приложения
- сигналы взаимодействия с рекламой
- варианты выбора согласия

Цели могут включать:

- показ рекламы
- измерение рекламы и отчетность
- ограничение частоты показа
- предотвращение мошенничества
- соблюдение законодательства

Разработчик стремится настраивать эти SDK в соответствии с выбором согласия пользователя и применимым законодательством.

## 3. Как мы обрабатываем и храним данные

- **Локальные настройки и данные о недавних позициях**
  - хранятся на устройстве до тех пор, пока данные приложения не будут очищены или приложение не будет удалено

- **Временные файлы / кэш**
  - хранятся только столько, сколько необходимо для работы, после чего удаляются приложением, где это практически возможно, либо очищаются ОС позднее

- **Сохраненные пользователем файлы субтитров**
  - остаются в месте сохранения, выбранном пользователем, до тех пор, пока пользователь их не удалит

- **Данные рекламы / согласия, обрабатываемые третьими лицами**
  - хранятся в соответствии с политиками Google и применимым законодательством
